# ميكانيك البناء — Construction Mechanics (Detailed)

> تفصيل كامل لآليات البناء: سير العمل، العمال، التوقيت، الإلغاء، التدمير.

---

## 1. سير عملية البناء (Construction Flow)

### 1.1. الرسم البياني الكامل
```
1. اختيار المبنى من قائمة البناء (B أو واجهة)
   │
2. التحقق من المتطلبات:
   ├── هل خيمة السيادة بالمستوى الكافي؟ ← لا → "طُلب ترقية خيمة السيادة أولاً"
   ├── هل تم فتح هذا المبنى؟ ← لا → "غير متاح بعد. أكمل المهمة X"
   ├── هل هناك حد مباني متاح؟ ← لا → "الحد الأقصى للمباني. رقِّ خيمة السيادة"
   └── نعم ← انتقل إلى الخطوة 3
   │
3. وضع المبنى:
   ├── المؤشر يتبع الفأرة مع أيقونة شبه شفافة
   ├── أخضر = موقع صالح
   ├── أحمر = موقع غير صالح (غير مستوٍ، عائق، خارج الحدود)
   ├── R = تدوير المبنى (90°)
   └── نقر أيسر ← تأكيد الموقع
   │
4. التحقق من الموارد:
   ├── هل الموارد كافية؟ ← لا → "موارد غير كافية: تحتاج X خشب، لديك Y"
   └── نعم ← صرف الموارد فوراً ← بدء البناء
   │
5. مرحلة البناء:
   ├── يظهر هيكل المبنى (مستوى 0 — تحت الإنشاء)
   ├── شريط تقدم (0% → 100%)
   ├── العمال يتوجهون إلى موقع البناء
   └── إذا توقف العمال (نقص): يتوقف البناء مؤقتاً
   │
6. اكتمال البناء:
   ├── تأثير بصري (تطاير غبار، وميض بناء)
   ├── صوت اكتمال (صوت نجاح)
   ├── المبنى جاهز للاستخدام
   ├── إشعار: "[اسم المبنى] اكتمل!"
   └── المبنى يظهر بمستوى 1
```

### 1.2. مراحل البناء البصرية
| نسبة الإنجاز | المظهر البصري |
|------------|-------------|
| 0% | مجرد أساسات (حفر في الأرض، أوتاد خشبية) |
| 25% | هيكل عظمي (أعمدة، جدران خشبية أولية) |
| 50% | هيكل نصف مكتمل (جدران، سقف جزئي) |
| 75% | هيكل شبه مكتمل (معظم التفاصيل موجودة) |
| 100% | المبنى كامل (يضاف اللون النهائي، الزخارف) |

## 3. إلغاء البناء (Cancel Construction)

### 3.1. القواعد
| في أي وقت يمكن الإلغاء؟ | بعد الاكتمال |
|------------------------|-------------|
| فقط أثناء مرحلة البناء (قبل 100%) | لا يمكن الإلغاء — يمكن الهدم |

### 3.2. استرداد الموارد
| وقت الإلغاء | نسبة الاسترداد |
|------------|---------------|
| 0-25% من وقت البناء | 80% من الموارد المنصرفة |
| 25-50% | 60% |
| 50-75% | 40% |
| 75-99% | 20% |
| 100% (مكتمل) | 0% (يمكن الهدم — استرداد 25%) |

### 3.3. إلغاء قسري (إذا حوصر المبنى)
إذا كان المبنى قيد الإنشاء وحوصر من قبل الأعداء (عدو ضمن 5 م):
- يمكن إلغاء فوري مع استرداد 50% من الموارد
- لا يمكن للعمال الوصول إلى الموقع الخطر

## 4. هدم المباني (Demolition)

### 4.1. هدم مبنى مكتمل
| الإجراء | النتيجة |
|---------|---------|
| اختر المبنى ← زر هدم (في قائمة المبنى) | المبنى يبدأ في الانهيار |
| مدة الهدم: 5 ثوانٍ (ثابتة لجميع المباني) | — |
| استرداد الموارد: 25% من التكلفة الإجمالية | — |
| خلال الهدم: يمكن إلغاء الهدم (لا يحدث شيء) | — |
| بعد الهدم: الموقع فارغ، يمكن البناء من جديد | — |

### 4.2. هدم تلقائي (إذا دُمّر المبنى بالهجوم)
إذا دُمّر مبنى بالهجوم (HP → 0):
- الأنقاض تبقى لمدة 30 ثانية
- يمكن للعمال إزالة الأنقاض (تكلفة: 10 ثوانٍ عمل)
- بعد الإزالة: استرداد 10% من التكلفة
- الموقع فارغ، يمكن البناء مجدداً

## 5. توزيع العمال على البناء (Worker Assignment)

### 5.1. آلية التوزيع
| عند بدء البناء: | عند اكتمال المبنى: |
|----------------|-------------------|
| أقرب عامل متاح يتوجه تلقائياً للمبنى | العامل يتحرر ويعود إلى أقرب نشاط |
| إذا كان هناك عدة مباني قيد الإنشاء: يوزع العمال تلقائياً (1 لكل مبنى) | — |
| يمكن للاعب سحب عامل من بناء (نقر على العامل + أمر آخر) | — |
| إذا لم يكن هناك عمال متاحون: البناء يتقدم ببطء (×1.0 بدون عامل) | — |

### 5.2. أولويات العمال
```
1. إصلاح المباني المتضررة (إذا كان هناك مبنى تحت 50% HP)
2. إكمال المباني قيد الإنشاء (الأقرب للاكتمال أولاً)
3. جمع الموارد (المنشرة → المنجم → المزرعة)
4. بناء مباني جديدة (إذا كانت هناك أوامر بناء معلقة)
```

## 6. إصلاح المباني (Repair)

### 6.1. آلية الإصلاح
| كيفية الإصلاح | التفاصيل |
|--------------|---------|
| يدوي: اختر المبنى ← زر إصلاح | يتوجه عامل لإصلاح المبنى |
| تلقائي: المباني تحت 50% HP | عامل يذهب تلقائياً (إذا كان متاحاً) |
| سرعة الإصلاح | 10 HP/ثانية لكل عامل |
| تكلفة الإصلاح | 20% من تكلفة المبنى الأصلي لكل 100% HP مستعادة |

### 6.2. حدود الإصلاح
- لا يمكن الإصلاح أثناء القتال (عدو ضمن 10 م)
- الإصلاح لا يعيد المبنى المدمر بالكامل (يحتاج إعادة بناء)
- الإصلاح يستهلك نفس موارد البناء (خشب للخشبي، حجر للحجري)

## 7. قيود الموقع (Placement Restrictions)

### 7.1. قواعد الموقع الصالح
| الشرط | سبب الرفض |
|-------|----------|
| الأرض مستوية | مائل جداً (>15°) — لا يمكن البناء |
| لا عوائق | صخرة/شجرة كبيرة في الموقع — ازل العائق أولاً |
| ضمن حدود الأوبا | خارج حدود الأوبا — وسّع الأوبا أولاً |
| لا تداخل مع مباني أخرى | المسافة غير كافية — ابعد المبنى |
| لا تداخل مع الطرق | يمنع المرور — ابعد 2 م عن الطريق |
| قرب كافٍ من خيمة السيادة | بعيد جداً (>50 م عن الخيمة) |

### 7.2. تدوير المبنى
- مفتاح R: تدوير المبنى 90° في كل ضغطة
- كل المباني يمكن تدويرها (حتى الأسوار)
- اتجاه المبنى يؤثر على:
  - اتجاه باب الدخول/الخروج
  - اتجاه إطلاق النار (للأبراج — 90° أمامي)
  - جانب التحميل/التفريغ (للمنشرة والمنجم)
