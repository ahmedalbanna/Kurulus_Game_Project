# التوازن الاقتصادي — Economy Balancing (Detailed)

> معادلات التوازن الاقتصادي، جداول الإنتاج/الاستهلاك، النسب الذهبية، وتحليل النقاط الحرجة.

---

## 1. النسب الذهبية (Golden Ratios)

### 1.1. وقت استرداد التكلفة (Return on Investment — RoI)
```
تكلفة بناء / (إنتاج المبنى في الدقيقة) = دقائق لاسترداد التكلفة

المبدأ: لا يتجاوز 5-8 دقائق لأي مبنى في مستوى اللعب العادي
```

| المبنى | تكلفة البناء (بالخشب) | الإنتاج/دقيقة | وقت الاسترداد |
|-------|---------------------|-------------|--------------|
| المنشرة 1 | 80 خشب | 15 خشب/دقيقة | 5.3 دقيقة |
| المنشرة 2 | 150 خشب + 30 حديد ≈ 210 خشب | 25 خشب/دقيقة | 8.4 دقيقة |
| المنشرة 3 | 250 خشب + 80 حديد ≈ 410 خشب | 40 خشب/دقيقة | 10.3 دقيقة |
| المنجم 1 | 100 خشب + 60 حجر ≈ 120 خشب | 8 حديد/دقيقة | 15 دقيقة (طويل لكن الحديد أثمن) |
| المنجم 2 | 200 خشب + 100 حجر + 40 حديد ≈ 260 خشب | 15 حديد/دقيقة | 17.3 دقيقة |
| المنجم 3 | 350 خشب + 200 حجر + 100 حديد ≈ 500 خشب | 25 حديد/دقيقة | 20 دقيقة (الأطول — استثمار طويل الأمد) |
| المزرعة 1 | 80 خشب | 12 طعام/دقيقة | 6.7 دقيقة |
| المزرعة 2 | 150 خشب + 30 حديد ≈ 210 خشب | 20 طعام/دقيقة | 10.5 دقيقة |
| المزرعة 3 | 250 خشب + 60 حديد ≈ 370 خشب | 35 طعام/دقيقة | 10.6 دقيقة |

### 1.2. نسب التكلفة إلى الفائدة
| المبنى | التكلفة الإجمالية (مستوى 1→3) | الفائدة التراكمية بعد 10 دقائق | التقييم |
|-------|--------------------------|------------------------------|---------|
| المنشرة | 480 خشب + 110 حديد | 800 خشب | ⭐⭐⭐⭐ ممتاز |
| المنجم | 650 خشب + 360 حجر + 140 حديد | 480 حديد | ⭐⭐⭐ جيد |
| المزرعة | 480 خشب + 90 حديد | 670 طعام | ⭐⭐⭐⭐ ممتاز |
| الإسطبل | 1250 خشب + 480 حديد + 150 ذهب | تدريب 20 فارساً | ⭐⭐⭐ جيد (استراتيجي) |
| ورشة الحصار | 1800 خشب + 1050 حديد + 50 ذهب | آلات حصار للمهمة | ⭐⭐⭐⭐⭐ لا يقدر بثمن (ضروري) |

## 2. منحنيات النمو الاقتصادي (Growth Curves)

### 2.1. بداية المهمة (أول 5 دقائق)
```
الدقيقة 0-2: جمع يدوي (3 عمال) ← ~36 خشب، ~18 طعام
الدقيقة 2-4: بناء منشرة + مزرعة ← ~30 خشب/د، ~20 طعام/د
الدقيقة 4-5: بداية بناء خيمة تدريب ← الاستعداد للتدريب
الإنتاج التراكمي بعد 5 دقائق: ~100 خشب، ~60 طعام
```

### 2.2. منتصف المهمة (5-15 دقيقة)
```
بعد بناء المنشرة 1 + المزرعة 1:
  إنتاج: ~27 خشب/د + ~22 طعام/د (مع عاملين)
  استهلاك: ~20 طعام/د (جيش 10 وحدات)
  فائض: ~7 طعام/د + ~27 خشب/د ← يتوسع

بعد بناء منجم + ترقية المنشرة:
  إنتاج: ~40 خشب/د + ~18 حديد/د + ~30 طعام/د
  استهلاك: ~40 طعام/د (جيش 20 وحدة)
  فائض/عجز: -10 طعام/د ← بناء مزرعة ثانية
```

### 2.3. نهاية المهمة (15-30 دقيقة)
```
اقتصاد متكامل:
  إنتاج: ~60 خشب/د + ~30 حديد/د + ~55 طعام/د + ~5 ذهب/د
  استهلاك: ~60 طعام/د (جيش 30 وحدة)
  فائض: ~0 طعام/د (توازن)، ~60 خشب/د، ~30 حديد/د
  
  إجمالي الاستثمار في المباني: ~2000 خشب، ~800 حديد
  إجمالي الجيش: 30 وحدة + 3 أبطال
```

## 3. نسب صعوبة الاقتصاد حسب المهمة

| المهمة | ميزانية البداية | موارد الخريطة | الضغط الاقتصادي | التوصية |
|-------|---------------|--------------|----------------|---------|
| م1: فجر السيادة | 400 خشب، 100 طعام | وفيرة (غابات كثيفة) | منخفض | ركز على جمع الخشب + بناء منشرة |
| م2: تثبيت السيادة | 300 خشب، 200 طعام، 50 حديد | متوسطة | متوسط | وازن بين الخشب والحديد |
| م3: كمين الممر | 200 خشب، 150 طعام | محدودة (منطقة جبلية) | مرتفع | لا تبني كثيراً — ركز على الكمين |
| م4: غارة ليلية | 500 خشب، 300 طعام، 100 حديد | متوسطة (معسكر) | منخفض | بناء سريع قبل الهجوم المغولي |
| م5: دومانيتش | 600 خشب، 400 طعام، 200 حديد | وفيرة | مرتفع جداً | بناء آلات حصار — استهلاك كبير |
| م6: يني شهير | 1000 خشب، 600 طعام، 400 حديد، 100 ذهب | وفيرة جداً | مرتفع | بناء كامل + جيش كبير + آلات حصار |

## 4. نقاط التعادل الاقتصادي (Break-Even Analysis)

### 4.1. الجيش والميزانية
```
نقطة التعادل = دخل الطعام = صيانة الطعام

إذا كان دخل الطعام = 50/دقيقة:
  يمكن صيانة: 25 مشاة خفيف (2 طعام/د لكل) = 50 طعام/د
  ← 25 وحدة هي الحد الأقصى لهذا الدخل

لتوسيع الجيش إلى 40 وحدة:
  دخل الطعام المطلوب = 40 × 2 = 80 طعام/دقيقة
  ← مزرعتان مستوى 2 (20×2=40) + مزرعة 1 (12) + مرعى 1 (10) = 62
  ← لا يزال ناقصاً — تحتاج مزرعة ثالثة أو مزرعة مستوى 3
```

### 4.2. البناء والميزانية
```
جمع الخشب لدورة بناء:
  تحتاج 300 خشب لبناء + ترقية
  إذا كان دخلك 40 خشب/د ← تحتاج 7.5 دقيقة من الجمع
  خلالها سينمو الجيش (يأكل طعاماً) ← قد تصل إلى عجز طعام
```

## 5. صعوبات الاقتصاد (خرائط الحرارة)

### 5.1. علامات التحذير للاعب
| المؤشر | المشكلة |
|--------|---------|
| الخشب < 50 | لا يمكن بناء أي شيء — توقف التوسع |
| الحديد < 20 | لا يمكن ترقية أي شيء |
| الطعام < صيانة الدقيقة الواحدة × 3 | سينفذ الطعام خلال 3 دقائق |
| الذهب < 10 | لا يمكن الشراء من السوق |
| كل الموارد قرب الامتلاء | وسّع المخازن — أنت تهدر الإنتاج |

### 5.2. انهيار الاقتصاد
إذا نفد الطعام بالكامل (0):
| التأثير الفوري | بعد 30 ثانية | بعد 60 ثانية |
|---------------|-------------|-------------|
| توقف التدريب | -5 معنويات لجميع الوحدات | -10 معنويات إضافية |
| توقف الإصلاح | فرصة 10% لهروب وحدة مدنية | فرصة 30% لهروب وحدة قتالية |
| — | — | بدء فقدان HP بمعدل 1%/دقيقة |

## 7. صيغ التوازن الأساسية (Core Balance Formulas)

### 7.1. تكلفة الوحدة القتالية
```
تكلفة_الوحدة = وقت_التدريب × دخل_الموارد_في_الثانية

مشاة خفيف (تدريب 8 ث):
  يكلف ≈ 8 × (2 طعام/ث) = 16 طعام

فارس ثقيل (تدريب 25 ث):
  يكلف ≈ 25 × (6 طعام/ث + 1 حديد/ث) = 150 طعام + 25 حديد
```

### 7.2. القوة الشرائية للذهب
```
1 ذهب = 2 خشب (في السوق) = 1 حديد = 4 طعام

لذا:
  سيف حديدي (يكلف 10 ذهب في السوق) = 20 خشب = 10 حديد
  ترقية خيمة السيادة (تتطلب 50 ذهب) = 100 خشب = 50 حديد
```

### 7.3. معادلة الضرائب (خيمة السيادة)
```
معدل الضرائب: 0% / 5% / 10% / 15% / 20%
  دخل الذهب من الضرائب = (إجمالي_قيمة_الأوبا) × (معدل_الضريبة / 100) / 60 (ذهب/دقيقة)
  عقوبة المعنويات = معدل_الضريبة × 1.5 (نقاط معنويات)

مثال: أوبا قيمتها 5000، ضريبة 10%:
  دخل = 5000 × 0.1 / 60 = 8.3 ذهب/دقيقة
  عقوبة = 10 × 1.5 = -15 معنويات
```

## 8. توصيات التوازن للاعبين (Player Balance Tips)

| المرحلة | النصيحة |
|---------|---------|
| أول 5 دقائق | ابنِ منشرة + مزرعة قبل أي شيء آخر. لا تبدأ التدريب إلا بعد أن يكون لديك 100+ طعام |
| 5-15 دقيقة | ابنِ منجماً في الدقيقة 7. وسّع المخازن قبل أن تملأ. ابنِ خيمة تدريب + جنود خفيف |
| 15-30 دقيقة | رقِّ المنشرة والمنجم. ابنِ إسطبل + فرسان. جهز آلات حصار إذا لزم الأمر |
| طوال الوقت | لا تخزن طعاماً أكثر من حاجتك (يفسد). وازن بين الجيش والمباني |
| نقطة حمراء | إذا رأيت "طعام < صيانة"، ابنِ مزرعة فوراً أو قلص جيشك |
