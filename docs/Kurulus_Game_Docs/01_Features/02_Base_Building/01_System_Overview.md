# نظام بناء القاعدة — Base Building System Specification

> مواصفات نظام بناء وتطوير الأوبا (المعسكر): المباني، الموارد، نظام البناء، والتوازن الاقتصادي.

---

## 1. نظرة عامة (Overview)

- **الغرض**: منح اللاعب القدرة على بناء وتطوير قاعدة القبيلة (الأوبا) لتوليد الموارد، تدريب الجنود، وفتح التقنيات.
- **تجربة اللاعب**: الأوبا ليست مجرد قاعدة — إنها قلب القبيلة وتمثيل بصري لتقدم اللاعب.
- **المبادئ الأساسية**:
  1. كل مبنى له دور واضح ولاستثمار فيه عائد مرئي
  2. الترقيات البصرية تعكس التطور (كل مستوى يغير شكل المبنى)
  3. التوازن بين التوسع الأفقي (مباني جديدة) والترقية العمودية (رفع المستوى)

---

## 2. تدفق نظام البناء (Construction Flow)

```
اللاعب يقرر البناء
    │
    ▼
┌──────────────────────────────────────┐
│ التحقق من صحة الموقع                 │
│ Site Validation                      │
│                                      │
│ • الأرض مستوية؟                     │
│ • لا يوجد عائق في الموقع؟           │
│ • الموقع ضمن حدود الأوبا؟            │
│ • لا يتداخل مع مباني أخرى؟           │
└──────────┬───────────────────────────┘
           │ (فشل → رسالة خطأ للموقع)
           ▼
┌──────────────────────────────────────┐
│ التحقق من صحة الموارد                │
│ Resource Check                       │
│                                      │
│ • هل لديك الموارد الكافية؟           │
│ • هل لديك عدد العمال/الوقت؟          │
└──────────┬───────────────────────────┘
           │ (فشل → رسالة "موارد غير كافية")
           ▼
┌──────────────────────────────────────┐
│ وضع المبنى (Placing)                 │
│                                      │
│ • أيقونة شبه شفافة تتبع المؤشر       │
│ • تظهر باللون الأحمر إذا غير صالح    │
│ • تظهر باللون الأخضر إذا صالح        │
│ • اللاعب يدور المبنى (اختياري)       │
└──────────┬───────────────────────────┘
           │ (تأكيد بالنقر)
           ▼
┌──────────────────────────────────────┐
│ بدء البناء (Construction)            │
│                                      │
│ • يظهر هيكل المبنى قيد الإنشاء       │
│ • شريط تقدم فوق المبنى               │
│ • يصرف الموارد فوراً عند التأكيد    │
│ • مدة البناء حسب نوع المبنى          │
└──────────┬───────────────────────────┘
           │ (اكتمال المؤقت)
           ▼
┌──────────────────────────────────────┐
│ اكتمال المبنى (Completed)            │
│                                      │
│ • تغير بسيط (تطاير غبار)             │
│ • صوت اكتمال البناء                  │
│ • المبنى جاهز للاستخدام              │
│ • إشعار للاعب                        │
└──────────────────────────────────────┘
```

### إلغاء البناء
- يمكن إلغاء المبنى أثناء الإنشاء فقط
- استرداد 50% من الموارد المنصرفة
- لا يمكن إلغاء المبنى بعد اكتماله (يمكن هدمه)

## 3. أنواع المباني (Building Catalog)

### تصنيف المباني

```
المباني
├── 🏗️ مباني أساسية (Core)
│   ├── خيمة السيادة (Command Tent)
│   ├── المخازن (Stockpile)
│   └── المسجد/المصلى (Prayer Grounds)
│
├── 👷 مباني تدريب (Training)
│   ├── خيمة التدريب (Training Tent) — المشاة
│   ├── الإسطبل (Stable) — الفرسان
│   └── ورشة الرماية (Archery Range) — الرماة
│
├── 🔧 مباني إنتاج (Production)
│   ├── خيمة الحدادة (Blacksmith)
│   ├── المنشرة (Sawmill)
│   ├── المنجم (Mine)
│   └── المزرعة/المرعى (Farm/Pasture)
│
├── 🛡️ مباني دفاعية (Defense)
│   ├── برج المراقبة (Watchtower)
│   ├── السور الخشبي (Wooden Wall)
│   └── بوابة الأوبا (Camp Gate)
│
└── ⚙️ مباني خاصة (Special)
    ├── السوق (Market)
    ├── خيمة العلاج (Medical Tent)
    └── ورشة الحصار (Siege Workshop)
```

### تفاصيل المباني

#### 🏗️ خيمة السيادة — Command Tent (المبنى الرئيسي)
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | خيمة جلدية متوسطة، علم على القمة. تكلفة: 100 خشب. يسمح ببناء 4 مباني. |
| **المستوى 2** | خيمة كبيرة، زخارف قبلية، راية الكايي كبيرة. تكلفة: 200 خشب + 100 حديد. يسمح ببناء 8 مباني. |
| **المستوى 3** | خيمة السيادة الفخمة، أعمدة خشبية مزخرفة، شعار IYI ذهبي. تكلفة: 400 خشب + 200 حديد + 50 ذهب. يسمح ببناء 12 مبنى. |
| **الوظيفة**: يتحكم في عدد المباني المسموح بها. إذا دُمّر، تنتهي المهمة بالخسارة. |

#### 👷 خيمة التدريب — Training Tent
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | خيمة بسيطة، ساحة تدريب ترابية. وحدات: ألب مشاة. |
| **المستوى 2** | خيمة أكبر، أسلحة تدريب خشبية. وحدات: ألب مشاة + رماة. |
| **المستوى 3** | ثكنة متكاملة، تماثيل تدريب. وحدات: ألب مشاة + رماة + مشاة ثقيلة. |
| **الوظيفة**: تدريب وحدات المشاة وتحسين جودتهم الابتدائية. |

#### 🔧 خيمة الحدادة — Blacksmith Tent
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | سندان خشبي، نار صغيرة. ترقيات: سيف حديدي (+10% ضرر). |
| **المستوى 2** | منفاخ كبير، سندان حجري. ترقيات: سيف دمشقي (+25% ضرر)، درع جلدي مضاعف (+15% دفاع). |
| **المستوى 3** | ورشة حدادة كاملة، مطرقة مائية. ترقيات: سلاح فولاذي (+40% ضرر)، درع صفائحي (+30% دفاع). |
| **الوظيفة**: ترقية أسلحة ودروع جميع الوحدات. كل مستوى يفتح ترقية جديدة. |

#### 🛡️ برج المراقبة — Watchtower
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | برج خشبي بسيط، رامٍ واحد. مدى رؤية: 30 م. |
| **المستوى 2** | برج حجري، راميان. مدى رؤية: 45 م. هجوم تلقائي على الأعداء القريبين. |
| **المستوى 3** | برج حجري كبير، 3 رماة، مصباح إشارة. مدى رؤية: 60 م. يكشف الأعداء المختبئين في نطاقه. |
| **الوظيفة**: كشف ضباب الحرب، دفاع محيطي، إنذار مبكر عن الغارات. |

#### ⚙️ ورشة الحصار — Siege Workshop
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | غير متاح إلا بعد المهمة 4. ينتج: سلالم تسلق. |
| **المستوى 2** | متاح بعد مهمة 5. ينتج: منجنيق خفيف، سلالم، كبش ضرب. |
| **المستوى 3** | متاح بعد مهمة 5 (تطوير). ينتج: منجنيق ثقيل، برج حصار. |
| **الوظيفة**: صناعة آلات الحصار اللازمة لفتح القلاع. |

#### 🛡️ السور الخشبي — Wooden Wall
| الخاصية | القيمة |
|---------|-------|
| **المستوى 1** | أسوار خشبية بسيطة، ارتفاع منخفض. صحة: 500. |
| **المستوى 2** | أسوار خشبية مقواة بالحجارة. صحة: 1000. |
| **المستوى 3** | جدار حجري كامل. صحة: 2000. يمكن للرماة الوقوف عليه. |
| **الوظيفة**: حماية الأوبا من الغارات. شريط السور يظهر متصلاً ببوابة. |

## 4. نظام الموارد (Resource System)

### أنواع الموارد
| المورد | الرمز | المصدر | الاستخدام الأساسي |
|--------|-------|-------|------------------|
| الخشب (Wood) | 🪵 | المنشرة، جمع يدوي، الغنائم | البناء، بعض الترقيّات |
| الحديد (Iron) | ⛏️ | المنجم، الغنائم، التجارة | الترقيّات، معدات الأبطال، آلات الحصار |
| الطعام (Food) | 🌾 | المزرعة/المرعى، الصيد، الغنائم | تدريب الجنود، صيانة الجيش، الشفاء |
| الذهب (Gold) |  | السوق، الغنائم، المكافآت | التجارة، قدرات خاصة، مباني نادرة |
| نقاط السيادة (SP) | 👑 | الأهداف الرئيسية، الإنجازات | شجرة التطوير، فتح التقنيات |

### الزيادة في سعة المخازن
```
المستوى 1: +0 (قاعدة)
المستوى 2 (ترقية المخازن): +50% سعة
المستوى 3 (ترقية كبرى): +100% سعة
```

## 5. العمال (Workers / Gatherers)

- **الوظيفة**: جمع الموارد من مصادرها الطبيعية (قطع الأشجار، التعدين) أو تشغيل المباني المنتجة.
- **التدريب**: يتم تدريب العمال من خيمة السيادة (مقابل طعام).
- **عدد البداية**: 3 عمال في المهمة الأولى، +1 كل مهمة (بحد أقصى 12).
- **الذكاء**: العمال يبحثون عن أقرب مصدر متاح ويجمعون منه تلقائياً.

### توزيع العمال المقترح
| النشاط | عامل واحد ينتج |
|--------|---------------|
| قطع الخشب (يدوي) | 15 خشب/دقيقة |
| التعدين (يدوي) | 8 حديد/دقيقة |
| الزراعة (يدوي) | 12 طعام/دقيقة |
| تشغيل المنشرة | 25 خشب/دقيقة |
| تشغيل المنجم | 15 حديد/دقيقة |
| إدارة المزرعة | 20 طعام/دقيقة |

## 6. مبادئ التوازن الاقتصادي (Economy Balance)

### النسبة الذهبية
```
تكلفة بناء أساسي (قبل منتصف اللعبة) ≈ 2-3 دقائق من جمع الموارد
تكلفة ترقية (مستوى 2) ≈ 4-5 دقائق من جمع الموارد
تكلفة ترقية (مستوى 3) ≈ 7-8 دقائق من جمع الموارد
تكلفة وحدة قتالية ≈ 30-45 ثانية من جمع الموارد
صيانة جيش من 20 وحدة ≈ يستهلك 50% من دخل الطعام
```

### معادلات العرض والطلب الأساسية
```
دخل الموارد في الدقيقة = (عمال × معدل الإنتاج) × (1 + ترقية المخازن%) + غنائم - صيانة

إجمالي الصيانة = (عدد الوحدات × 2 طعام/دقيقة) + (مستوى المباني × 1 طعام/دقيقة)

نقطة التعادل: دخل الطعام = صيانة الطعام
فوق نقطة التعادل ← فائض للتوسع
تحت نقطة التعادل ← استنزاف المخزون
```
