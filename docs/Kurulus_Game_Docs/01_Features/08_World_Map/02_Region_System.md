# Region System — Map Zones, Territories & Control

> **Description:** Defines the regional map system for *Kuruluş* campaign — how the world is divided into zones, how region control works, and what gameplay effects regions have.

---

## 1. Region Architecture

The campaign map is divided into **regions**, each representing a distinct geographical and strategic area. Each mission takes place within one or more regions.

```
CAMPAIGN MAP
│
├── Chapter 1: "Bithynia"
│   ├── Region 1: Kulucahisar Valley (Mission 01)
│   │   ├── Zone A: Forest Approach (stealth zones)
│   │   ├── Zone B: Fortress Outer (combat zone)
│   │   └── Zone C: Keep Interior (boss area)
│   │
│   └── Region 2: Yarhisar Pass (Mission 02)
│       ├── Zone A: Mountain Trail (ambush corridor)
│       ├── Zone B: Village (friendly)
│       └── Zone C: Fortified Camp (enemy base)
│
├── Chapter 2: "Marmara"
│   ├── Region 3: Bilecik Plains (Mission 03)
│   └── Region 4: Marmaracık Coast (Mission 04)
│
└── Chapter 3: "Anatolia"
    ├── Region 5: Byzantine Fortress (Mission 05)
    └── Region 6: Yenişehir Valley (Mission 06)
```

## 3. Zone Types (Within Missions)

Each mission map is divided into **zones** that affect gameplay:

| Zone Type | Description | Gameplay Effects |
|-----------|-------------|------------------|
| **Spawn** | Player starting area | Safe from enemy patrols, no stealth needed |
| **Forest** | Dense woodland | Stealth available, movement slowed, vision reduced |
| **Grassland** | Open field | No stealth, full speed, full vision |
| **Mountain** | High elevation | +vision range, -movement speed, ranged damage bonus |
| **River/Shallow** | Water crossing | Movement slowed, units vulnerable |
| **Village** | Friendly settlement | Passive gold income, healing over time |
| **Fortification** | Enemy base walled area | Stealth reduced, defenders get defensive bonuses |
| **Ambush Corridor** | Narrow path | Both sides can ambush, limited escape routes |
| **Hilltop** | Elevated strategic point | Vision bonus, ranged advantage, capture point |
| **Hideout** | Stealth-friendly structure | Enter to vanish from enemy sight instantly |

### 3.1 Zone Effects Table

| Effect | Forest | Grassland | Mountain | Fortification |
|--------|--------|-----------|----------|---------------|
| Move Speed | -20% | 0% | -30% | -10% |
| Vision Range | -40% | 0% | +50% | -20% |
| Stealth Rating | +60% | -100% | +20% | -50% |
| Ranged Accuracy | -25% | 0% | +20% | -15% |
| Detection Range | -50% | 0% | +30% | +40% |

### 7.2 تخطيط مدينة بورصة (Bursa City Layout)

تنقسم بورصة إلى 3 أحياء رئيسية، لكل منها طابعه المعماري وأهميته العسكرية.

#### 7.2.1 الحي 1: القلعة العليا (Upper Fortress — Hisar İçi)

| الجانب | التفاصيل |
|--------|---------|
| **الوصف** | أقدم جزء من بورصة، مبني على تلة صخرية تطل على بقية المدينة |
| **المساحة** | 300م × 200م (مستطيل غير منتظم) |
| **الجدران** | سور مزدوج بارتفاع 12م + 8م، مع 7 أبراج دفاعية |
| **المباني الرئيسية** | قصر الحاكم (التكفور)، الكنيسة الكبرى (آيا صوفيا بورصة لاحقاً — جامع)، ثكنة الحرس |
| **السكان** | 2,000 (النخبة — عسكريون، إداريون، رجال دين) |
| **نقاط الدخول** | بوابة رئيسية واحدة (جنوب)، بوابة خدمة (شمال — للمؤن) |
| **الدور في الحصار** | آخر موقع دفاعي — إذا سقطت القلعة العليا، سقطت بورصة |

**خريطة القلعة العليا:**
```
                    ┌──────────────────┐
                    │   البوابة الشمالية │
                    │   (بوابة الخدمة)  │
                    └────────┬─────────┘
                             │
             ┌───────────────┼───────────────┐
             │               │               │
      ┌──────┴──────┐ ┌─────┴──────┐ ┌──────┴──────┐
      │   الثكنة    │ │  القصر     │ │  الكنيسة    │
      │  (الحرس)    │ │ (التكفور)  │ │  الكبرى     │
      └──────┬──────┘ └─────┬──────┘ └──────┬──────┘
             │              │               │
             │     الساحة المركزية           │
             │     (آخر موقف)               │

      │             البوابة الجنوبية            │
      │          (البوابة الرئيسية)              │
```

**نقاط دفاعية في القلعة العليا:**
| الموقع | الدفاعات | ملاحظات |
|--------|---------|---------|
| البوابة الجنوبية | باب حديدي + جسر متحرك + 2 برج رمي | أقوى نقطة دفاع |
| البوابة الشمالية | باب حديدي + ممر ضيق | نقطة ضعف (هروب محتمل) |
| البرج المركزي (القصر) | 4 طوابق، رماة في كل طابق | آخر موقع دفاع — التكفور هنا |
| السور الغربي | 12م ارتفاع، منحدر صخري طبيعي | منيعة تقريباً — صعبة التسلق |

### 7.3 التضاريس المحيطة (Surrounding Terrain)

#### 7.3.1 جبل أولوداغ (Mount Uludağ — "الجبل العظيم")

| الخاصية | القيمة |
|---------|--------|
| **الارتفاع** | 2,543 م (أعلى جبل في المنطقة) |
| **الموقع** | جنوب بورصة — يطل على المدينة بالكامل |
| **الغطاء النباتي** | غابات كثيفة حتى 1,500م، ثم مروج ألبية |
| **الممرات** | 3 ممرات رئيسية (كلها وعرة — غير صالحة للآلات الحصار) |
| **الأهمية العسكرية** | يمكن تسلق الجبل لرؤية بورصة من الأعلى (مكافأة استطلاع هائلة) |
| **الأخطار** | ضباب كثيف بعد الظهر، حيوانات مفترسة (ذئاب، دببة)، برد قارس ليلاً |

**تأثير الجبل على القتال:**
| المنطقة على الجبل | التأثير |
|------------------|---------|
| الغابات الكثيفة (حتى 1,000م) | -40% رؤية، -30% سرعة، كمائن سهلة |
| المروج الألبية (1,000-1,500م) | +30% رؤية، -20% سرعة (منحدر)، رماة +25% ضرر |
| القمة (1,500م+) | +60% رؤية، تكشف خريطة بورصة بالكامل |

#### 7.3.2 ساحل مودانيا (Mudanya Coast)

| الخاصية | القيمة |
|--------|--------|
| **الموقع** | 15كم شمال غرب بورصة، على بحر مرمرة |
| **النوع** | ساحل رملي مع رصيف بحري طبيعي |
| **الأهمية** | بوابة بورصة البحرية — كل إمدادات بورصة تأتي من هنا |
| **الحصن** | قلعة صغيرة (20 جندياً) لحماية الميناء |
| **دورها في الحصار** | قطع الإمدادات عبر مودانيا = جوع لبورصة |

**مسارات الإمداد:**
```
ميناء مودانيا ← طريق معبد (15 كم) ← بوابة مودانيا الغربية ← حي الميناء ← بورصة
     │                                                         │
     │ (سفن من القسطنطينية)                           (توزيع داخلي)
     ▼                                                         ▼
بحر مرمرة                                                إلى الأسوار
```

**تأثير السيطرة على مودانيا:**
| الموقف | التأثير على الحصار |
|--------|-------------------|
| مودانيا تحت سيطرة بيزنطة | الإمدادات تصل بحراً — الحصار يستمر 3x أطول |
| مودانيا محاصرة من البر | الإمدادات تصل 50% فقط — الحصار أسرع |
| مودانيا محتلة من العثمانيين | الإمدادات مقطوعة بالكامل — الحصار يسرع 2x |

```
3. الاستيلاء على السفن الراسية (2-4 سفن)
4. إنشاء دفاعات ساحلية (لمنع هبوط تعزيزات بيزنطية)
```

| طريق مودانيا-بورصة | ميناء مودانيا → بوابة مودانيا | 15 كم | معبد (جيد) | شريان الحياة — كل الإمدادات البحرية |
| طريق إزنيق-بورصة | إزنيق → بوابة إزنيق | 25 كم | ترابي (ضعيف) | خط الإمداد البري الوحيد من الشرق |
| طريق كستل-بورصة | قلعة كستل → بوابة كستل | 5 كم | ممر جبلي (وعر) | بديل شرقي لكنه بطيء |
| طريق يني شهير-بورصة | يني شهير → جنوب بورصة | 20 كم | ترابي (سيئ) | الطريق العثماني — وصول الجيش العثماني |

**قطع طرق الإمداد — التأثير على الحصار:**
| عدد الطرق المقطوعة | التأثير على بورصة |
|-------------------|------------------|
| 0 (جميعها مفتوحة) | حصار غير فعال — بورصة تصمد لأشهر |
| 1 (طريق واحد مقطوع) | -20% إمدادات — الحصار يسرع 25% |
| 2 (طريقان مقطوعان) | -50% إمدادات — الحصار يسرع 50% |
| 3 (جميع الطرق مقطوعة) | -80% إمدادات — الحصار يسرع 100%، مجاعة تبدأ بعد 5 دقائق |

### 7.5 مناطق ساحل بحر مرمرة (Sea of Marmara Coastal Zones)

#### 7.5.1 المناطق الساحلية المؤثرة في حصار بورصة

| المنطقة | الوصف | التأثير على الحملة |
|---------|-------|-------------------|
| **مضيق مرمرة الشمالي** | الممر البحري من القسطنطينية إلى مودانيا | السيطرة عليه تمنع وصول التعزيزات البيزنطية |
| **خليج إزميت** | شرق مرمرة — قريب من إزنيق | نقطة إنزال بديلة للتعزيزات |
| **ساحل باليكسير-إدرميت** | جنوب مرمرة — أرض كراسي | أسطول كراسي يتمركز هنا |
| **جزر مرمرة (برينسيبي)** | جزر صغيرة في بحر مرمرة | قواعد بحرية بيزنطية — إذا سيطرت عليها، تمنع الإمدادات بالكامل |

#### 7.5.2 التحكم البحري وتأثيره

| مستوى التحكم البحري | التأثير على حصار بورصة |
|--------------------|----------------------|
| **بيزنطي كامل** | تعزيزات بحرية تصل كل 5 دقائق — حصار صعب جداً |
| **متنازع عليه** | تعزيزات تصل كل 10 دقائق — حصار قابل للإدارة |
| **عثماني + كراسي** | لا تعزيزات بحرية — حصار فعال |
| **عثماني كامل** | حصار بحري تام — بورصة تسقط بسرعة |

#### 7.6.5 تدفق اللاعب في خريطة الحصار (Player Flow)

```
1. يبدأ في معسكر الحصار (جنوب غرب)
   └─ يختار: أي موقع يبدأ منه الهجوم؟
   
2. يتقدم نحو الأسوار (اختيار بوابة أو سور)
   └─ تحت نيران رماة الأبراج
   
3. عند الوصول إلى السور:
   ├─ إذا اختار سلماً: يصعد، يقاتل على السور
   ├─ إذا اختار كبشاً: يكسر البوابة، يقتحم
   └─ إذا اختار منجنيقاً: يقصف حتى يحدث فتحة، ثم يقتحم

4. بعد الاختراق — داخل المدينة:
   ├─ يتجه إلى الحي الثاني (سوق — قتال شوارع)
   └─ أو يتجه إلى الحي الثالث (ميناء — قطع الإمدادات)

5. تطهير الأحياء:
   ├─ تطهير منزل منزل (بطيء، آمن)
   └─ اندفاع سريع نحو القلعة العليا (سريع، خطير)

6. الوصول إلى القلعة العليا:
   └─ المواجهة النهائية مع التكفور
```
