# خريطة العالم — World Map System Specification

> مواصفات خريطة العالم الاستراتيجية بين المهام: المناطق، ضباب الحرب، الفصائل، والأحداث الاستراتيجية.

---

## 1. نظرة عامة (Overview)

- **الغرض**: توفير طبقة استراتيجية بين المهام تتيح للاعب رؤية التقدم الإجمالي، التخطيط للمهام القادمة، وفهم تأثير كل انتصار.
- **تجربة اللاعب**: خريطة حية تظهر كيف تتغير الأناضول بفضل أفعالك — القرى تُحرر، القبائل تتحالف، والنفوذ يتوسع.
- **المبادئ الأساسية**:
  1. الخريطة ثنائية الوظيفة: تُظهر التقدم السابق وتكشف عن التحديات القادمة
  2. كل انتصار له تأثير مرئي على الخريطة (منطقة تتحول من عدو إلى حليف)
  3. الخريطة ليست مجرد ديكور — توفر معلومات استخباراتية تهم اللاعب

---

## 2. هيكل الخريطة (Map Structure)

### العرض البصري
- **التنسيق**: خريطة ثابتة مرسومة بأسلوب Low-Poly مائل (Isometric)، تُرى من الأعلى بزاوية.
- **الأسلوب الفني**: خريطة جلدية قديمة ذات حواف محروقة، تظهر فيها المناطق والجبال والغابات كرسوم توضيحية.
- **الحجم**: مناسبة لشاشة واحدة (لا تحتاج تمرير — لكن يمكن تكبير بعض المناطق للتفاصيل).

### العناصر الأساسية
| العنصر | الوصف البصري | التفاعل |
|--------|-------------|---------|
| **الأوبا (موقعك)** | خيمة زرقاء مع راية الكايي | تحدد حالتك الحالية |
| **قلعة العدو** | قلعة حمراء بعلامة نار | تظهر الأهداف القادمة |
| **منطقة مكشوفة** | أرض خضراء/بنية نظيفة | متاحة للمهام، مكشوفة بالكامل |
| **ضباب الحرب** | سحب رمادية داكنة | لم تُستكشف بعد — تظهر بعد إكمال مهمة |
| **طريق تجاري** | خط أصفر متقطع بين نقطتين | قوافل تسير هنا |
| **معسكر حليف** | خيمة خضراء | حليف يمكن استدعاؤه |
| **معسكر مغولي** | خيمة حمراء بعلامة قوس | غارات محتملة |

### المناطق على الخريطة
```
الفصل الأول:                         الفصل الثاني:
  [أوبا الكايي] 🟢                   [أوبا الكايي] 🟢 ← موسّعة
  [غابة سوغوت] 🟢 (مكشوفة)           [الممر الجبلي] 🟣 (مهمة 3)
  [قلعة كولاجا حصار] 🔴 (بعيدة)      [معسكر المغول] 🔴 (مهمة 4)
                                       [قلعة كولاجا حصار] 🔴 (ما زالت)

الفصل الثالث:
  [قلعة كولاجا حصار] 🟢 ← أصبحت لكم!
  [سهل كولاجا] 🔴 (مهمة 6 — المعركة النهائية)
  [قلعة بيليجك] ⚪ (محايدة — خارج النطاق)
```

## 3. ضباب الحرب ونظام الكشف (Fog of War)

### الحالات
| الحالة | اللون/المظهر | متى تحدث |
|--------|-------------|---------|
| **غير مكشوف (Unexplored)** | رمادي غامق، معتم | لم تصل أي وحدة إلى هناك بعد |
| **مكشوف (Explored)** | رمادي فاتح مع تفاصيل | سبق أن مرت وحدة من هنا |
| **مرئي (Visible)** | مضاء بالكامل مع ألوان | وحدة موجودة حالياً في هذه المنطقة |
| **مشتبه (Suspected)** | تموج خفيف | استخبارات: "يُعتقد أن هناك قوات عدو هنا" |

### آليات الكشف
- **وحدات عادية**: تكشف دائرة قطرها 15 م حولها.
- **أبراج المراقبة**: تكشف دائرة قطرها 30-60 م (حسب المستوى).
- **بوران (قدرة كشف)**: يكشف دائرة قطرها 30 م حتى في ضباب الحرب (قدرة سلبية).
- **حلم الشجرة (ألتميت عثمان)**: يكشف الخريطة بالكامل لمدة 10 ثوانٍ.

### مبدأ ضباب الحرب (حتمي لا عشوائي)
```
الرؤية حتمية — ما تراه وحداتك هو الواقع (لا تزييف).
الضباب يخفي تحركات العدو فقط.
الموارد الثابتة (جبال، أنهار، مباني) تبقى مرئية بعد اكتشافها.
الوحدات المتحركة تختفي عن الأنظار عندما تغادر دائرة الرؤية.
```

## 4. علاقات الفصائل (Faction Relations)

### مقياس العلاقة
```
العدو ——————————————│—————————————— الحليف
  -100      0       +50      +100
   عدو      محايد   صديق    حليف
```

### تغيرات العلاقة حسب المهمات
| المهمة | التأثير على البيزنطيين | التأثير على المغول | التأثير على القبائل المحايدة |
|--------|----------------------|-------------------|---------------------------|
| م1: فجر السيادة | -20 (عداوة مؤكدة) | 0 (لا تغيير) | +10 (عثمان يثبت نفسه) |
| م2: تثبيت السيادة | -10 | 0 | +15 (وحدة القبيلة) |
| م3: كمين الممر | -30 (خسارة كبيرة) | -5 | +10 (قوة تكتيكية) |
| م4: إنقاذ الأسرى | 0 | -30 (غضب مغولي) | +20 (تحرير الشيخ) |
| م5: فتح القلعة | -40 (إذلال) | +10 (احترام القوة) | +25 (هيبة الدولة) |
| م6: معركة الميدان | -100 (تدمير) | -60 (هزيمة) | +40 (قيام الدولة) |

## 5. الأحداث الاستراتيجية (Strategic Events)

### أحداث تلقائية
| الحدث | متى يحدث | التأثير |
|-------|---------|---------|
| غارة مغولية على أوبا الصديقة | بين م2 وم3 | إذا لم ترد، -10 علاقة مع القبائل المحايدة |
| وصول تاجر غامض | بين م3 وم4 | يبيع معدات نادرة — لكنه قد يكون جاسوساً (+15 صحة للبطل إذا اشتريت) |
| هدنة بيزنطية مقترحة | بين م4 وم5 | +30 ذهب هدية، لكن تحذير من كمين (خيار: اقبل/ارفض) |
| قافلة إمداد مغولية | أثناء م4 | إذا اعترضتها ← غنائم ضخمة لكن -20 علاقة إضافية مع المغول |

### أحداث اختيارية (تظهر كخيارات قبل المهمة)
```
أثناء شاشة ما قبل المهمة، قد يظهر حدث عشوائي:
───────────────────────────────────────────
حدث: تاجر سلاح في المخيم
"تاجر من حلب يمر بالمخيم. يعرض سيفاً دمشقياً نادراً."
[اشترِه: 50 ذهب ← +15% ضرر لعثمان لهذه المهمة]
[اطرده: مجاناً ← +5 معنويات (نزاهة القائد)]
───────────────────────────────────────────
```

## 6. التنقل بين المهام على الخريطة

### التدفق
```
1. إكمال مهمة ← العودة إلى خريطة العالم
2. الخريطة تُظهر التغييرات (مناطق جديدة مكشوفة، مواقع محررة)
3. اللاعب يختار المهمة التالية بالضغط على موقعها
4. تظهر شاشة ما قبل المهمة مع معلومات مستخلصة من الخريطة
```

### التقدم في الخريطة
```
مهمة 1 ← منطقة الأوبا (صغيرة)
         │
         ▼
مهمة 2 ← منطقة الأوبا موسّعة + أول معسكرات منشقة
         │
         ▼
مهمة 3 ← الممر الجبلي (منطقة جديدة تُكشف على الخريطة)
         │
         ▼
مهمة 4 ← معسكر المغول (منطقة جديدة)
         │
         ▼
مهمة 5 ← قلعة كولاجا حصار (الهدف الأكبر)
         │
         ▼
مهمة 6 ← سهل كولاجا (المواجهة النهائية — الخريطة بأكملها الآن مكشوفة)
```

## 7. معلومات الخريطة (Map Intelligence)

### عند التمرير فوق موقع مهمة:
```
قلعة كولاجا حصار
═══════════════════
نوع العدو: بيزنطي (نخبة)
القوة التقديرية: 40-50 جندي
التسليح: مشاة ثقيلة، رماة أبراج، منجنيق دفاعي
الموارد المتوقعة عند الفتح: 500+ ذهب، 300+ حديد
نصيحة: جهز آلات الحصار — الأسوار عالية!
═══════════════════
الحالة: ⚠️ مكشوفة — غير قابلة للهجوم بعد
(أكمل المهمة 4 أولاً)
```

### عند التمرير فوق موقع صديق:
```
معسكر قبيلة تشافدار (محايد)
═══════════════════
الموقف: يقبلون التحالف
الشروط: 50 ذهب + إثبات قوة (مهمة جانبية)
المكافأة المحتملة: +200 خشب، دعم 10 ألبا
═══════════════════
```
