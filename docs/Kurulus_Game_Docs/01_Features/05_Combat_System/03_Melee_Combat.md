# القتال المباشر — Melee Combat (Detailed)

> تفصيل كامل لآليات القتال المباشر: الاشتباك، التشكيلات، سرعة الهجوم، التطويق، والشحن.

---

## 1. آلية الاشتباك (Engagement Mechanics)

### 1.1. سير القتال المباشر
```
1. كشف (Detection)
   الوحدة تكتشف عدواً ضمن مدى هجومها القريب (1-3 م)
   
2. تأكيد (Lock-on)
   الوحدة تتجه نحو الهدف، تدخل حالة "اشتباك" (Engaged)
   
3. دورة الهجوم (Attack Cycle)
   ↓
   ┌─ بداية الدورة ──────────────────────────┐
   │  1. مبادرة (Wind-up): 0.2-0.5 ثانية     │
   │  2. الضربة (Strike): لحظة الضرر          │
   │  3. استعادة (Recovery): 0.3-0.8 ثانية    │
   └──────────────────────────────────────────┘
   ↓ (تتكرر حتى موت الهدف أو خروجه من المدى)
   
4. انتهاء (Resolution)
   - موت الهدف: الوحدة تبحث عن هدف جديد
   - انسحاب الهدف: الوحدة تطارده أو تنتظر أوامر
```

### 1.2. سرعة الهجوم (Attack Speed)

| السلاح/الوحدة | وقت المبادرة (Wind-up) | وقت الضربة | وقت الاستعادة | دورة كاملة | ضربات/ثانية |
|--------------|----------------------|-----------|--------------|-----------|------------|
| خنجر (بوران) | 0.15 ث | لحظي | 0.35 ث | 0.5 ث | 2.0 |
| سيف تركي (عثمان) | 0.25 ث | لحظي | 0.58 ث | 0.83 ث | 1.2 |
| سيف طويل (بيزنطي) | 0.35 ث | لحظي | 0.55 ث | 0.9 ث | 1.1 |
| رمح (مشاة بيزنطية) | 0.4 ث | لحظي | 0.7 ث | 1.1 ث | 0.9 |
| فأس خفيف (مشاة تركية) | 0.45 ث | لحظي | 0.55 ث | 1.0 ث | 1.0 |
| فأس ثقيل (تورغوت) | 0.8 ث | لحظي | 0.87 ث | 1.67 ث | 0.6 |
| صولجان (فارس ثقيل) | 0.5 ث | لحظي | 0.7 ث | 1.2 ث | 0.83 |
| أداة حصار (يدوي) | 1.5 ث | لحظي | 2.0 ث | 3.5 ث | 0.28 |

## 2. التطويق (Encirclement / Flanking)

### 2.1. المناطق (Zones)
```
                      أمام
                   (ضرر عادي)
                 ┌──────────┐
                 │          │
    جانب أيسر ← ─┤          ├─ → جانب أيمن
   (ضرر ×1.25)  │          │   (ضرر ×1.25)
                 └──────────┘
                      خلف
                   (ضرر ×1.5)
```

### 2.2. مكافآت التطويق
| زاوية الهجوم | مضاعف الضرر | تأثير إضافي |
|-------------|------------|------------|
| أمام (Front) — ±45° من الاتجاه | ×1.0 | يمكن للهدف صد الهجوم (درع كامل) |
| جانب (Side) — 45°-135° | ×1.25 | -15% فرصة صد للهدف |
| خلف (Back) — 135°-180° | ×1.5 | -30% فرصة صد، إلغاء الدرع الإضافي |
| تطويق كامل (عدوان على جانبين) | ×1.25 لكل مهاجم | -20% معنويات للهدف |

### 2.3. منع التطويق
| الطريقة | المدة | ملاحظات |
|---------|-------|---------|
| تشكيل تربيع (Square) | مستمر طالما التشكيل صامد | يمنع التطويق من الجوانب |
| ظهر إلى جدار (Back to Wall) | طالما قرب الجدار | يقضي على ضرر التطويق الخلفي |
| تشكيل هلال (Crescent) | مستمر | يحيط بالمهاجم بدلاً من أن يُطوَّق |

## 3. الشحن (Charge)

### 3.1. آلية الشحن
```
1. الشرط: الوحدة تتحرك باتجاه عدو لمسافة لا تقل عن 10 م في خط مستقيم
2. التفعيل: تلقائي للفرسان عند الوصول للمسافة. يدوي للمشاة (Shift + أمر هجوم)
3. التأثير:
   - أول ضربة بعد الشحن: ×2.0 ضرر
   - إذا كان المهاجم فارساً:
     - +100% ضرر إضافي + يرمي الهدف أرضاً (Knockdown) لمدة 1.5 ثانية
     - يكسر تشكيل العدو (تشتت مؤقت لمدة 2 ثانية)
4. سرعة الشحن:
   - فارس خفيف: 8 م/ث (مدى شحن فعال: 10-25 م)
   - فارس ثقيل: 6 م/ث (مدى شحن فعال: 15-35 م)
   - مشاة: 4.5 م/ث (مدى شحن فعال: 10-15 م)
```

### 3.2. صد الشحن (Countering Charge)
| الطريقة | ضد | الفعالية |
|---------|-----|---------|
| تشكيل تربيع (رماح) | فرسان | يمنع ضرر الشحن، يسبب ضرراً إضافياً للفارس (+50%) |
| شجيرات/أرض وعرة | جميع | -50% سرعة شحن، يمنع مكافأة الشحن |
| كمين أمامي | جميع | يقطع الشحن فوراً (ذعر للأعداء المشحونين) |
| جدار من حديد (تورغوت) | جميع | يقف أمام الشحن، يمتص الضرر (خصم 50% ضرر شحن) |

## 4. التشكيلات القتالية (Battle Formations)

### 4.1. تفصيل التشكيلات

#### خط (Line)
```
م: ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺
مكافآت: +15% ضرر، -10% ضرر وارد
عقوبات: -20% سرعة حركة
مقاومة التطويق: جيدة (الجوانب محمية)
الاستخدام: مواجهة مباشرة، صد هجوم
```

#### عمود (Column)
```
    ☺
    ☺
    ☺
    ☺
    ☺
مكافآت: +25% سرعة حركة
عقوبات: +25% ضرر وارد من الجوانب
مقاومة التطويق: ضعيفة جداً
الاستخدام: اختراق سريع، مسيرة إجبارية
```

#### تربيع (Square / Pike)
```
    ☺ ☺ ☺ ☺ ☺
    ☺ ☺ ☺ ☺ ☺
    ☺ ☺ ☺ ☺ ☺
مكافآت: +40% دفاع ضد الفرسان، يمنع التطويق
عقوبات: -30% سرعة، -15% ضرر
مقاومة التطويق: ممتازة
الاستخدام: صد فرسان، حماية الرماة
```

#### هلال (Crescent)
```
    ☺ ☺ ☺     ☺ ☺ ☺
  ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺ ☺
مكافآت: يحيط بالعدو، يمنع الهروب
عقوبات: يحتاج أعداداً كبيرة (15 وحدة+)
مقاومة التطويق: يطوق لا يطوَّق
الاستخدام: حصر العدو، منع الانسحاب
```

#### مبعثر (Scattered)
```
      ☺
  ☺        ☺
        ☺
    ☺        ☺
مكافآت: -30% ضرر من الرماة، صعب التطويق
عقوبات: -20% قوة هجومية
الاستخدام: ضد رماة، تضاريس وعرة
```

#### كمين (Ambush)
```
    ░░ ☺ ░░
  ░░ ☺ ☺ ☺ ░░
░░ ☺ ☺ ☺ ☺ ☺ ░░
مكافآت: ضرر مضاعف في أول اشتباك، ذعر للعدو
عقوبات: غير فعال في الأرض المكشوفة
الاستخدام: مفاجأة القوافل، نصب الفخاخ
```

### 4.2. التبديل بين التشكيلات
| التشكيل الحالي → الجديد | زمن التبديل | ملاحظات |
|------------------------|------------|---------|
| خط → عمود | 3 ثوانٍ | سريع — تحت النار |
| خط → تربيع | 5 ثوانٍ | متوسط — الشكل معقد |
| عمود → خط | 2 ثوانٍ | أسرع تبديل |
| تربيع → خط | 4 ثوانٍ | فك التربيع |
| أي تشكيل → مبعثر | 1 ثانية | فوري تقريباً (هروب) |
| مبعثر → أي تشكيل | 6 ثوانٍ | يحتاج إعادة تنظيم |

### 4.3. كسر التشكيل (Formation Break)
يحدث كسر التشكيل عندما:
| السبب | مدة الكسر | التأثير |
|-------|----------|---------|
| شحن فارس ناجح | 3 ثوانٍ | وحدات مبعثرة، ضرر وارد +25% |
| قتل 30% من الوحدات في 10 ثوانٍ | 5 ثوانٍ | ذعر، وحدات تهرب |
| كمين ناجح | 4 ثوانٍ | ذعر فوري، قفزات خلفية |
| ألتميت تورغوت (غضب الثور) | 3 ثوانٍ | قذف في الهواء + تشتت |

## 5. المبادرة والأسبقية (Initiative & Priority)

| الموقف | من يضرب أولاً؟ | ملاحظات |
|--------|---------------|---------|
| اشتباك مباشر | الأسرع في سرعة الهجوم | خنجر (2.0/ث) يسبق سيف (1.2/ث) |
| مهاجم من الخلف | المهاجم (هجمة خاطفة) | الهدف المنشغل لا يرد أول ضربة |
| شحن ← مشاة | الفارس يشحن أولاً | ثم يرد المشاة |
| كمين | المهاجم في الكمين | 3 ضربات كاملة قبل أن يرد العدو |
| عدو في تشكيل ← مشاة مبعثرة | العدو في التشكيل | النظام يهزم الفوضى |

## 6. ردود فعل القتال (Combat Reactions)

### 6.1. الصد (Block / Parry)
| العامل | فرصة الصد الأساسية |
|--------|-------------------|
| درع صفائحي | 15% فرصة صد |
| تشكيل منظم | +10% فرصة صد |
| فارس ثقيل (درع + تدريب) | 20% فرصة صد |
| مشاة خفيف | 5% فرصة صد |
| هجوم من الخلف | 0% (لا يمكن الصد) |
| كمين | 0% (لا يمكن الصد — مفاجأة) |

### 6.2. المراوغة (Dodge)
| العامل | فرصة المراوغة |
|--------|--------------|
| مشاة خفيف | 10% |
| فارس خفيف | 15% |
| بوران (خاص) | 25% (خفة الظل) |
| فارس ثقيل | 0% (لا يراوغ) |
| مشاة ثقيل | 0% (لا يراوغ) |

## 7. توزيع الأهداف (Target Priority)

### 7.1. أولويات الذكاء الاصطناعي للوحدات
| الأولوية | النوع | متى؟ |
|---------|-------|------|
| 1 | عدو يهاجم هذه الوحدة | دفاع عن النفس |
| 2 | أقرب عدو مرئي | افتراضي |
| 3 | عدو في مدى القوس/الرمح | للوحدات بعيدة المدى |
| 4 | عدو يهاجم بطلاً صديقاً | حماية القائد |
| 5 | عدو يهاجم قائداً صديقاً | حماية القائد (أولوية للوحدات قرب القائد) |

### 7.2. أوامر تخصيص الأهداف (لللاعب)
| الأمر | المفتاح | الوصف |
|-------|---------|-------|
| هجوم | A + فارة أيسر | هجوم عادي على الهدف |
| هجوم مركز | Ctrl + A + فارة أيسر | جميع الوحدات تهاجم هدفاً واحداً (Focus Fire) |
| هجوم متحرك | A + فارة أيمن على أرض | هاجم أول عدو في الطريق (Attack Move) |
| حماية البطل | H + فارة أيسر على بطل | احمن هذا البطل (Guard) |
| منطقة ممنوعة | P + فارة يمين على منطقة | الوحدات تتجنب هذه المنطقة |
