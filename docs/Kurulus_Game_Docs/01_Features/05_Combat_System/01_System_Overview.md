# نظام القتال — Combat System Specification

> مواصفات نظام القتال بالكامل: أنواع الضرر، والدروع، والمعنويات، والقتال المباشر، والقتال عن بعد، والحصار، والمشاجرة.

---

## 1. نظرة عامة (Overview)

- **الغرض**: نظام قتال تكتيكي يجمع بين القتال المباشر وغير المباشر، مع تركيز على القرارات التكتيكية قبل القوة الغاشمة.
- **تجربة اللاعب**: القتال ليس مجرد إرسال جيش إلى جيش — إنه لعبة شطرنج دموية حيث التموضع، التوقيت، والمفاجأة أهم من العدد.
- **المبادئ الأساسية**:
  1. الضعيف (تكتيكياً) يمكنه هزيمة القوي (عددياً) عبر المناورة والكمائن
  2. القتال ليس مجرد خفض نقاط صحة — المعنويات، التعب، والذعر عوامل حاسمة
  3. كل وحدة لها نقاط قوة وضعف واضحة — لا يوجد "جيش واحد يناسب الجميع"

## 2. أنواع الوحدات (Unit Archetypes)

| النوع | الدور | نقاط القوة | نقاط الضعف |
|-------|-------|-----------|-----------|
| **ألب مشاة خفيف** | قتال خط أمامي أساسي | رخيص، سريع، عدد كبير | ضرر منخفض، درع ضعيف |
| **ألب مشاة ثقيل** | قتال خط أمامي قوي | درع عالٍ، ضرر عالٍ | بطيء، غالي، محدود العدد |
| **رامٍ (قوس)** | قتال بعيد المدى | ضرر عالٍ من بعيد، فعال ضد المشاة | ضعيف في القتال القريب، دقيق ضد الأهداف الثابتة |
| **فارس خفيف** | استطلاع ومناورة | سريع جداً، مناورة عالية | ضعيف في الاشتباك المباشر |
| **فارس ثقيل** | هجوم صادم | قوة هائلة عند الشحن، يكسر التشكيلات | بطيء في المناورة، غالي جداً |
| **منجنيق/ألة حصار** | تدمير المباني | ضرر هائل ضد المباني | بطيء جداً، بلا دفاع، يحتاج حماية |
| **وحدة بطولية** | قيادة وتأثير استراتيجي | قدرات خاصة، معنويات عالية | فرد واحد فقط، لا يمكن استبداله في المهمة |

## 3. نموذج الضرر (Damage Model)

### أنواع الضرر
| النوع | الوصف | فعال ضد | غير فعال ضد |
|-------|-------|---------|------------|
| **قطع (Slash)** | ضرر السيوف والرماح | مشاة خفيف، دروع جلدية | دروع ثقيلة (صفائحية) |
| **ثَقب (Pierce)** | ضرر الأسهم والحراب | دروع متوسطة، فرسان (الخيول بلا درع) | دروع صفائحية ثقيلة |
| **سحق (Blunt/Crush)** | ضرر الفؤوس والصولجان | دروع ثقيلة صفائحية | مشاة خفيف (بطيء جداً ضدهم) |
| **نار (Fire)** | ضرر حارق (السهم المشتعل) | المباني، آلات الحصار، المعنويات | الوحدات المدرعة (الحديد لا يحترق) |
| **صدمة (Impact)** | ضرر الشحن والصدم | التشكيلات (يكسرها)، الرماة | المشاة الثقيلة المنظمة |
| **معنويات (Morale)** | ضرر نفسي يسبب الذعر | الوحدات الضعيفة، المغول | الأبطال، المشاة الثقيلة |

### معادلة الضرر الأساسية
```
الضرر الفعلي = (ضرر الهجوم × مُضاعِف النوع) - (درع الهدف × مُقاومة النوع)

حيث:
  مُضاعِف النوع: حسب فعالية الضرر ضد الدرع (من 0.5 إلى 2.0)
  مُقاومة النوع: نسبة مقاومة الدرع لهذا النوع من الضرر (من 0.0 إلى 1.0)

الحد الأدنى للضرر: 1 (لا يمكن أن يكون الضرر صفراً)
```

### مثال حسابي
```
سيف تركي (قطع) ضد مشاة بيزنطية ثقيلة (درع صفائحي):
  ضرر السيف: 25
  درع الهدف: 40 (ضد القطع)
  مُضاعِف القطع ضد الصفائح: 0.5
  مُقاومة الصفائح للقطع: 0.8

  الضرر الفعلي = (25 × 0.5) - (40 × 0.8) = 12.5 - 32 = -19.5 ← 1 (الحد الأدنى)
  → السيف عديم الجدوى تقريباً ضد المشاة الثقيلة
  → الحل: استخدم فأس تورغوت (سحق) أو التف حولهم من الخلف
```

### جدول فعالية الضرر
```
               ضد ↓    مشاة خفيف   مشاة ثقيل   فارس    رامٍ    مبنى/قلعة
نوع الضرر ↓
─────────────────────────────────────────────────────────
قطع (Slash)          1.5×        0.5×        1.0×    1.5×    0.1×
ثَقب (Pierce)        1.0×        0.8×        1.5×    1.2×    0.2×
سحق (Blunt/Crush)    0.8×        1.5×        0.8×    0.8×    2.0×
نار (Fire)           1.2×        0.5×        1.2×    1.5×    3.0×
صدمة (Impact)        1.5×        0.7×        1.0×    2.0×    0.5×
معنويات (Morale)     1.5×        0.5×        0.8×    1.5×    0.0×
```

## 4. المعنويات (Morale System)

### الحالات المعنوية
| الحالة | المؤشر | التأثير |
|--------|--------|---------|
| عالية (High) | 🔵 | +15% ضرر، +10% دفاع، لا ذعر |
| عادية (Normal) | 🟢 | لا تعديل |
| متذبذبة (Shaken) | 🟡 | -10% ضرر، فرصة ذعر 20% عند الخسارة |
| خائفة (Frightened) | 🟠 | -25% ضرر، فرصة ذعر 40% |
| ذعر (Panic/Rout) | 🔴 | تهرب عشوائي، تترك التشكيل، لا تستجيب للأوامر لـ 5-10 ثوانٍ |

### عوامل رفع المعنويات
| العامل | التأثير |
|--------|---------|
| قرب البطل عثمان (صيحة الحرب) | +30% معنويات مؤقتة |
| الانتصار في معركة | +20% لمدة 60 ثانية |
| التفوق العددي明顯 | +10% |
| الدفاع عن الأوبا | +15% |
| وجود الشيخ إده بالي (ترقية) | +10% دائم |

### عوامل خفض المعنويات
| العامل | التأثير |
|--------|---------|
| التعرض لكمين | -30% فوري |
| مقتل قائد (بطل حليف) في الجوار | -25% |
| خسارة 50% من الوحدة في 30 ثانية | -20% |
| التفوق العددي للعدو | -10% |
| الليل (للبعض فقط) | -10% (للبشر العاديين) |

## 5. القتال المباشر — المشاجرة (Melee Combat)

### آلية الاشتباك
```
1. تقترب الوحدات من بعضها ← كشف النية العدائية
2. الوصول إلى مدى السلاح ← بدء القتال
3. تناوب الضربات حسب سرعة الهجوم:
   - سيف عادي: 1.2 ضربة/ثانية
   - فأس ثقيل: 0.6 ضربة/ثانية
   - خنجر (بوران): 2.0 ضربة/ثانية لكن ضرر منخفض
4. حساب الضرر ← تحديث شريط الصحة
5. إذا وصلت الصحة للصفر ← الوحدة تسقط
```

### محددات القتال المباشر
| العامل | التأثير |
|--------|---------|
| التطويق (Encirclement) | مهاجمة وحدة من الخلف: +50% ضرر |
| تشكيل منظم | -20% ضرر وارد للمشاة المنظمة |
| أرض مرتفعة | +25% ضرر للرماة و+10% للمشاة |
| فجوة في الخط | الوحدات في الفجوة تتلقى ضرراً مزدوجاً |
| الشحن (Charge) | أول ضربة بعد شحن 10 أمتار: +100% ضرر |

## 6. التشكيلات (Formation System)

### التشكيلات القتالية
| التشكيل | الوصف | المكافآت | العقوبات |
|---------|-------|---------|---------|
| **خط (Line)** | صف واحد من المقاتلين جنباً إلى جنب | +15% ضرر، -10% ضرر وارد | بطيء في المناورة |
| **عمود (Column)** | تشكيل ضيق عميق | +25% سرعة، اختراق جيد | +25% ضرر وارد من الجوانب |
| **تربيع (Square/Pike)** | مربع دفاعي (الرماة في الوسط) | +40% دفاع ضد الفرسان | -30% سرعة، ضعيف ضد المشاة |
| **هلال (Crescent)** | تشكيل محدب يحيط بالعدو | يمنع هروب العدو | يحتاج أعداداً كبيرة |
| **مبعثر (Scattered)** | وحدات متفرقة | -30% ضرر من الرماة، صعب التطويق | -20% قوة هجومية |
| **كمين (Ambush)** | وحدات مختبئة في التضاريس | ضرر مضاعف في أول اشتباك، ذعر للعدو | غير فعال في الأرض المكشوفة |

## 7. القتال عن بعد (Ranged Combat)

### أنواع الرماة
| النوع | المدى | الضرر | سرعة الإطلاق | فعالية ضد |
|-------|-------|------|-------------|----------|
| رامٍ خفيف | 25 م | 10 | 1.5/ثانية | مشاة خفيف، رماة أعداء |
| رامٍ ثقيل | 35 م | 20 | 0.8/ثانية | مشاة ثقيل، فرسان |
| قناص/مخصص (شخصيات فقط) | 45 م | 35 | 0.5/ثانية | أهداف عالية القيمة (أبطال، قادة) |
| رامٍ على حصان (مغولي) | 20 م | 12 | 1.2/ثانية | كل ما يتحرك |

### عوامل دقة الرماية
| العامل | التأثير على الدقة |
|--------|------------------|
| ثبات الوحدة الرامية | إذا واقفة: 100%، إذا متحركة: 60% |
| سرعة الهدف | بطيء: 90%، سريع: 60%، يركض: 40% |
| مسافة الهدف | قريب (10 م): 95%، وسط (25 م): 75%، بعيد (35+ م): 50% |
| الليل | -20% دقة للجميع |
| غابة كثيفة | -40% دقة (المقذوفات تصطدم بالأشجار) |
| أرض مرتفعة | +15% دقة، +5 م مدى |

## 8. قتال الحصار (Siege Combat)

### آلات الحصار
| الآلة | الوظيفة | ضد الأهداف | سرعة الهجوم | الدروع |
|-------|---------|-----------|-----------|-------|
| **سلم التسلق** | يسمح للمشاة بتسلق الأسوار | الأسوار فقط | هجوم مباشر | سهل التدمير |
| **كبش الضرب (Battering Ram)** | تدمير البوابات | البوابات فقط | بطيء (0.2/ثانية) | مقبول (يحتاج حماية) |
| **منجنيق (Catapult)** | قذف حجارة لتحطيم الأسوار | أسوار وبوابات ومبانٍ | بطيء جداً (0.1/ثانية) | ضعيف جداً |
| **برج الحصار (Siege Tower)** | يحتضن رماة، يوفر حماية للاقتحام | الأسوار (نقل جنود) | لا يهاجم، يقترب ببطء | عالٍ جداً |

### دفاعات القلعة (للذكاء الاصطناعي)
| الدفاع | الوظيفة | الضرر ضد المهاجمين |
|--------|---------|-------------------|
| **الزيت المغلي** | يصب من فوق البوابة عند الاقتحام | ضرر نار هائل (200+) على منطقة صغيرة |
| **رمي السهام المركز** | من فوق الأسوار | 3-5 رماة لكل برج يرمون باستمرار |
| **السور المنهار (مصيدة)** | ينهار جزء من السور على المهاجمين (مرة واحدة) | قتل فوري لكل الوحدات تحته |
| **إصلاح الأسوار** | وحدات إصلاح تعيد بناء الأسوار أثناء الحصار | — |

### مراحل الحصار
```
1. الوصول: وصول الجيش إلى محيط القلعة، تطويقها
2. إعداد: بناء آلات الحصار، قطع خطوط الإمداد
3. تليين: قصف الأسوار بالمنجنيقات، إضعاف الدفاعات
4. اقتحام: اختراق البوابة، تسليم الأسوار، دخول ساحة القلعة
5. تطهير: القضاء على الحامية الداخلية، مواجهة التكفور (Boss)
6. احتلال: رفع الراية، انتهاء المهمة
```

## 9. التفاعل مع التضاريس (Terrain Interaction in Combat)

| التضاريس | التأثير على القتال |
|---------|------------------|
| **غابة كثيفة** | الرماة غير فعالين، المشاة يتلقون -15% ضرر (غطاء)، الكمائن ممكنة |
| **نهر/مياه** | الحركة بطيئة جداً، الوحدات المبللة تتلقى -10% درع مؤقت |
| **تل منخفض** | +10% ضرر للرماة من الأعلى، -10% للمهاجمين صعوداً |
| **طريق معبد** | +25% سرعة حركة، +10% ضرر لشحن الفرسان |
| **حقل زراعي** | -20% سرعة (أرض وعرة)، يحترق بالسهام النارية |
| **كهف/ممر ضيق** | قتال متسلسل (1 ضد 1)، مناسب للمشاة الثقيلة وغير مناسب للفرسان |
| **خيام/مبانٍ** | المبان توفر غطاء (-30% ضرر من بعيد) لكنها قابلة للاشتعال |

## الموسم السادس — Siege Combat Extensions

> **سياق الموسم**: حصار بورصة (1326) هو أكبر عملية حصار في اللعبة — ويستحق نظام قتال متخصص للتعامل مع القتال على الأسوار، في الشوارع، وفي الظلام. هذا القسم يوسع نظام القتال ليشمل 5 أنماط قتال جديدة خاصة بالحصار.

### 10. قتال الأسوار (Wall Combat Mechanics)

#### 10.1 نظام الارتفاع (Elevation Advantage)

| الجانب | التفاصيل |
|--------|---------|
| **المبدأ** | المقاتل على السور له أفضلية واضحة على المهاجم الذي يتسلق |
| **مكافأة المدافع على السور** | +30% ضرر، +25% دفاع (يغطيه نصف سور)، +50% مدى للرماية |
| **عقوبة المهاجم المتسلق** | -25% ضرر (يد واحدة للتسلق)، -30% دفاع (مكشوف)، -50% سرعة هجوم |
| **عقوبة المهاجم في قاعدة السور** | -20% ضرر (يرمي لأعلى)، +10% ضرر وارد (أهداف سهلة من فوق) |

**جدول مكافآت الارتفاع الكامل:**
| الموقع | ضرر صادر | ضرر وارد | مدى الرماية | سرعة الحركة |
|--------|---------|---------|------------|------------|
| المدافع على السور | +30% | -25% | +50% | 0% (ثابت) |
| المهاجم على السور (بعد التسلق) | 0% | +10% | 0% | -20% |
| المهاجم على السلم | -25% | +30% | -50% | -60% |
| المهاجم في قاعدة السور | -20% | +20% | -30% | -10% |
| رامٍ من الأرض إلى السور | -30% | — | -15% | 0% |
| رامٍ من السور إلى الأرض | +25% | — | +15% | 0% |

#### 10.2 تسلق الأسوار (Ladder Assaults)

**آلية وضع السلالم:**
```
1. الجندي يحمل سلماً (يحتاج يدان — لا قتال أثناء الحمل)
2. الجندي يصل إلى موقع السور المستهدف
3. وضع السلم: 3 ثوانٍ (الجندي مكشوف بالكامل — لا دفاع)
4. بعد وضع السلم، يبدأ التسلق تلقائياً
5. جنود آخرون يمكنهم استخدام نفس السلم (بفارق 1.5 ثانية)
```

**خصائص السلالم:**
| الخاصية | القيمة |
|---------|--------|
| الصحة | 150 (قابلة للتدمير) |
| السعة | 5 جنود في وقت واحد |
| سرعة التسلق | 3 ثوانٍ لكل جندي |
| سرعة النزول | 1.5 ثانية لكل جندي |
| مكافأة المدافع ضد السلم | +50% ضرر ضد السلم (يحاول كسره) |
| دفاع الجندي على السلم | -50% درع (مكشوف تماماً) |

**سلوك المدافع تجاه السلالم:**
```
1. الأولوية القصوى: تدمير السلالم (يضربها الرماة والمشاة)
2. إذا وصل جندي إلى قمة السور:
   - دفعه للأسفل: 40% فرصة (يموت الجندي فوراً)
   - طعنه أثناء الصعود: 60% فرصة (يقع الجندي ويصاب بجروح)
3. الزيت المغلي على السلالم: تدمير فوري للسلم وجميع المتسلقين
```

#### 10.3 القتال على قمة السور (Wall Top Combat)

عندما يصل المهاجمون إلى قمة السور، يبدأ قتال عنيف على مساحة ضيقة:

| العامل | التأثير |
|--------|---------|
| **المساحة الضيقة** | قتال 1 ضد 1 على طول السور (لا تطويق) |
| **خطر السقوط** | إذا انخفضت صحة الجندي إلى < 20%، فرصة 30% أن يسقط عن السور (موت فوري) |
| **الدفع** | المشاة الثقيلون يمكنهم دفع الخفيفين عن السور (+50% فرصة سقوط) |
| **الميزة الدفاعية** | المدافع لديه مساحة خلفية للتراجع — المهاجم لا يملكها |
| **تأثير الازدحام** | إذا كان أكثر من 10 جنود على مساحة سور 10م، -20% ضرر للجميع (فوضى) |

### 11. قتال الاختراق (Breach Combat)

عندما ينهار جزء من السور أو تُكسر البوابة، ينشأ "نقطة اختناق" (Chokepoint) حيث يندفع الطرفان.

#### 11.1 آليات نقطة الاختناق (Chokepoint Fighting)

```
                     العدو
        ┌────────────┘  ┌────────────┐
        │               │            │
        │    الفتحة     │←─── نقطة   │
        │    في السور   │    الاختناق│
        │               │            │
        └────────────┐  └────────────┘
                     المهاجمون
```

| العامل | التأثير |
|--------|---------|
| **تأثير القمع (Bottleneck)** | 3-5 جنود فقط يمكنهم المرور في وقت واحد |
| **مكافأة المدافع** | +40% ضرر (يرمي على المهاجمين وهم يتجمعون لدخول الفتحة) |
| **عقبة المهاجم** | -20% ضرر (يضطر للقتال وهم يتزاحمون في المدخل) |
| **الازدحام الخلفي** | المهاجمون يتجمعون خلف الفتحة — هدف مثالي للرماة والنار اليونانية |
| **وقت العبور** | 1.5 ثانية لكل جندي لاجتياز الفتحة |

#### 11.2 استراتيجيات الاختراق

| الاستراتيجية | الوصف | المكافأة | الخطر |
|-------------|-------|---------|-------|
| **الاندفاع الجماعي** | إرسال أكبر عدد من الجنود دفعة واحدة | تغلب على الدفاع بالعدد | خسائر فادحة (30-50% قبل العبور) |
| **التسلل التدريجي** | إرسال 3-5 جنود النخبة أولاً | فتح رأس جسر صغير | بطيء، قد يُصدّ |
| **الهجوم المشترك** | اختراق + تسلق أسوار مجاورة في نفس الوقت | تشتيت دفاع العدو | يحتاج تنسيقاً وتخطيطاً |
| **تطهير بالنار** | إشعال النار في المنطقة خلف الفتحة قبل الاقتحام | إجبار العدو على التفرق | قد يحرق غنائم ثمينة |

#### 11.3 تأثير الاختراق على المعنويات

| الحدث | التأثير على المدافعين | التأثير على المهاجمين |
|-------|---------------------|---------------------|
| انهيار السور الخارجي | -20% معنويات | +15% معنويات |
| كسر البوابة الرئيسية | -30% معنويات | +25% معنويات |
| اختراق السور الداخلي | -50% معنويات | +35% معنويات |
| وصول المهاجمين إلى القلعة الداخلية | -70% معنويات (فرصة ذعر 30%) | +50% معنويات |

### 12. القتال في الشوارع (Street Fighting / Urban Warfare)

بعد اختراق الأسوار، ينتقل القتال إلى شوارع بورصة — قتال منزل إلى منزل، حيث كل زاوية قد تخبئ عدواً.

#### 12.1 خصائص القتال الحضري

| العامل | التأثير |
|--------|---------|
| **الرؤية المحدودة** | مدى الرؤية في الشوارع 15-20م (بدلاً من 40م في الحقل المكشوف) |
| **الغطاء الوفير** | المباني توفر -40% ضرر من الرماية |
| **المباني القابلة للاحتلال** | بعض المباني يمكن اقتحامها وتطهيرها طابقاً طابقاً |
| **الحواجز** | يمكن بناء حواجز في الشوارع (300 صحة) لإبطاء التقدم |
| **المدنيون** | المدنيون في الشوارع يعيقون الحركة (يحتاجون 2 ثانية لتفاديهم) |
| **السقوف** | الرماة على السقوف يحصلون على مكافأة ارتفاع لكنهم مكشوفون |

#### 12.2 القتال من منزل إلى منزل (House-to-House)

**آلية اقتحام المباني:**
```
1. يقترب الجندي من باب المبنى
2. 2 ثانية لفتح الباب / كسره
3. إذا كان المبنى محتلاً من العدو: قتال داخلي (مساحة ضيقة جداً)
4. إذا كان المبنى فارغاً: يمكن استخدامه كموقع دفاعي
5. المباني الكبيرة (مساجد، مستودعات): تحتاج 3-4 غرف لتطهيرها بالكامل
```

| العامل في القتال الداخلي | التأثير |
|------------------------|---------|
| **مساحة ضيقة جداً** | قتال 1 ضد 1، لا مناورة |
| **مكافأة المدافع داخل المبنى** | +30% ضرر، +20% دفاع (يختبئ خلف الأثاث) |
| **خطر الحريق** | إذا اشتعل المبنى، 20 ثانية للخروج أو الموت حرقاً |
| **الرمي من النوافذ** | الرماة من النوافذ يحصلون على +25% ضرر لكن مكشوفون من الخلف |

#### 12.3 طرق القتال في الشوارع

| الطريق | الوصف | فعال ضد |
|--------|-------|---------|
| **التطهير المنهجي** | تطهير كل مبنى شارعاً شارعاً — بطيء لكن آمن | أي عدو |
| **الاندفاع السريع** | الركض في وسط الشارع باتجاه الهدف — سريع لكن خطير | العدو غير المنظم |
| **شق الجدران** | كسر الجدران بين المباني للتنقل دون استخدام الشوارع — مفاجأة | العدو المتمركز في الشارع |
| **حصار المباني** | تطويق مبنى وحرقه بدلاً من اقتحامه — وحشي لكن فعال | المدافع المتحصن |

#### 12.4 تأثير القتال الحضري على الوحدات

| الوحدة | الفعالية في الشوارع | الشرح |
|--------|-------------------|-------|
| مشاة خفيف (سيف/درع) | 8/10 | مثالي — سريع، مرن، يستخدم الغطاء |
| مشاة ثقيل (فأس/رمح) | 5/10 | بطيء جداً، عالق في الشوارع الضيقة |
| رامٍ (قوس) | 4/10 | قوس طويل غير عملي في الشوارع — استخدم القوس القصير |
| فارس | 1/10 | عديم الفائدة تماماً — لا يمكن المناورة |
| رامٍ على السطوح | 9/10 | موقع ممتاز — يرى الشارع بالكامل |
| مهندس (يكسر الجدران) | 10/10 | يفتح طرقاً جديدة، يخلق فرصاً للتطويق |

### 13. القتال الليلي (Night Combat)

#### 13.1 نظام الرؤية الليلية

| الجانب | القيمة |
|--------|--------|
| **مدى الرؤية الليلي الأساسي** | 10م (بدلاً من 30-40م نهاراً) |
| **مدى الرؤية الليلي للأبطال** | 15م (أورخان)، 20م (فاطمة — قدرة ظل الليل) |
| **دقة الرماية الليلية** | -40% (لجميع الوحدات) |
| **سرعة الحركة الليلية** | -15% بشكل عام |
| **فرصة الكمين الليلي** | +30% (المهاجم يرى أولاً) |
| **ذعر العدو الليلي** | +20% فرصة ذعر للوحدات غير المدربة |

#### 13.2 مكافآت التخفي الليلي

| الإجراء | التأثير الليلي |
|---------|---------------|
| التحرك بدون نار | -80% فرصة كشف |
| التحرك بنار (مشعل) | +50% فرصة كشف لكن +10% معنويات للوحدات القريبة |
| الوقوف ثابتاً | غير مرئي تماماً خارج مدى 5م |
| تسلق الأسوار ليلاً | -60% فرصة كشف من الحراس (مقارنة بـ -20% نهاراً) |
| فتح البوابات ليلاً | -80% فرصة كشف |

#### 13.3 وحدات النخبة الليلية

| الوحدة | التخصص الليلي | المكافأة |
|--------|--------------|---------|
| **فاطمة (ظل الليل)** | قائدة كمائن ليلية | غير مرئية حتى ضمن 5م، +50% ضرر ليلي |
| **بوران (كشاف)** | استطلاع ليلي | يرى 25م في الليل (ضعف العادي) |
| **كتيبة الظل (وحدة نخبة عثمانية)** | هجوم ليلي | لا تنخفض دقتها في الليل، تتحرك بصمت |
| **حراس الكتالونيون (العدو)** | لا يتأثرون بالليل | ليس لديهم عقوبة ليلية — يقاتلون في أي وقت |

#### 13.4 استراتيجيات القتال الليلي

| الاستراتيجية | الوصف | الفعالية |
|-------------|-------|---------|
| **التسلل** | إرسال مجموعة صغيرة لفتح البوابات من الداخل | ★★★★★ — الأفضل للحصار |
| **الهجوم المفاجئ** | هجوم شامل من اتجاه غير متوقع في الظلام | ★★★★ — ذعر العدو مضمون تقريباً |
| **الإرباك** | إشعال حرائق في عدة مواقع لتشتيت المدافعين | ★★★ — يخلق فرصاً لكن يستهلك موارد |
| **التموضع المسبق** | تحريك القوات ليلاً إلى مواقع هجومية أفضل للفجر | ★★★★ — تحضير لهجوم الفجر |

#### 13.5 دورة الليل والنهار في الحصار

| الوقت | المدة (بالدقائق الحقيقية) | التأثير |
|-------|-------------------------|---------|

### 14. قتال طواقم آلات الحصار (Siege Engine Crew Combat)

#### 14.1 أنواع الطواقم

| الآلة | حجم الطاقم | مهارة مطلوبة | سرعة التشغيل |
|-------|-----------|-------------|-------------|
| **منجنيق** | 4 جنود | عالية (مقذوفات دقيقة) | 0.1 إطلاق/ثانية (بطيء جداً) |
| **كبش الضرب** | 6 جنود | متوسطة (تنسيق الضربات) | 0.2 ضربة/ثانية |

| **سلالم** | جندي واحد لكل سلم | منخفضة | 3 ثوانٍ للوضع |

#### 14.2 نقاط ضعف الطواقم

| نقطة الضعف | التأثير |
|-----------|---------|
| **مقتل أحد الطاقم** | -25% سرعة تشغيل لكل فرد مفقود |
| **مقتل نصف الطاقم** | الآلة تتوقف عن العمل حتى وصول بديل |
| **مقتل الطاقم بالكامل** | الآلة تترك — يمكن للعدو تدميرها أو الاستيلاء عليها |
| **ذعر الطاقم** | إذا تعرضوا لهجوم مباشر، 50% فرصة هروب — تعطل الآلة 20 ثانية |

#### 14.3 حماية الطواقم

| إجراء الحماية | التأثير |
|--------------|---------|
| **وضع مشاة حول الآلة** | يحمي الطاقم من الهجمات المباشرة (يحتاج 5 جنود كحد أدنى) |
| **بناء حاجز حول المنجنيق** | -50% ضرر من الرماية على الطاقم |
| **تغطية رماة للآلة** | الرماة يردون على أي هجوم يستهدف الطاقم |
| **تشتيت الآلات** | وضع الآلات متباعدة 30م — يصعب استهدافها جميعاً |

#### 14.4 قتال الآلات (إذا اقتحمها العدو)

| الموقف | الوصف |
|--------|-------|
| **اقتحام موقع المنجنيق** | الطاقم يدافع بأدواتهم (مطارق، أزاميل) — ضرر ضعيف جداً |
| **الاستيلاء على الآلة** | العدو يمكنه استخدام المنجنيق ضد قواتك إذا استولى عليه |
| **تدمير الآلة** | إذا وصل العدو إلى الآلة، يسبب 200 ضرر/ثانية للأداة |
| **إنقاذ الآلة** | إرسال تعزيزات في غضون 10 ثوانٍ ينقذ الآلة من التدمير |

### 15. كيف يوسع الموسم السادس مثلث القتال (S6 Triangle Expansion)

#### 15.1 المثلث الأصلي (Seasons 1-5)

```
                    القتال المباشر (Melee)
                   /                    \
                  /                      \
                 /                        \
        القتال عن بعد (Ranged) ──────── حصار (Siege)
```

المثلث الأصلي كان يعتمد على: قتال مباشر > قتال عن بعد > حصار في علاقة "حجر-ورقة-مقص" تقليدية.

#### 15.2 المثلث الموسع (Season 6)

```
                    القتال المباشر (Melee)
                   /      \            \
                  /        \            \
                 /          \            \
        القتال عن بعد ──── حصار ────── قتال أسوار
        (Ranged)         (Siege)     (Wall Combat)
            \              /              /
             \            /              /
              \          /              /
               قتال شوارع ──────── قتال ليلي
              (Urban)             (Night)
```

#### 15.3 العلاقات الجديدة في المثلث الموسع

| العلاقة | الوصف |
|---------|-------|
| **قتال الأسوار > القتال المباشر** | المدافع على السور له أفضلية على المهاجم المتسلق |
| **قتال الشوارع < الحصار** | آلات الحصار غير فعالة في الشوارع — تحتاج مشاة |
| **القتال الليلي > قتال الأسوار** | الحراس الليليون أقل يقظة — التسلل الليلي فعال جداً |
| **القتال المباشر > قتال الشوارع** | المشاة المدربة تتفوق على المقاتلين العشوائيين في الشوارع |
| **القتال عن بعد > قتال الأسوار** | الرماة من الأرض يمكنهم إبعاد المدافعين عن الأسوار |
| **الحصار > القتال الليلي** | لا يمكن بناء آلات حصار فعالة في الظلام الدامس |

#### 15.4 مثال على سلسلة قرارات في حصار بورصة

```
ليل ← اختر التسلل (فاطمة تفتح البوابة من الداخل)
  ↓
فجر ← اقتحام البوابة الرئيسية مع كبش الضرب
  ↓
بعد الظهر ← اختراق السور الأول → بداية قتال الشوارع
  ↓
غسق ← تطهير الأحياء الشمالية
  ↓
ليل ← استغلال الظلام لاقتحام القلعة الداخلية
  ↓
فجر ← مواجهة التكفور — القتال النهائي
```
