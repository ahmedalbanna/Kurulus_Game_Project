# القتال عن بعد — Ranged Combat (Detailed)

> تفصيل كامل لآليات القتال بعيد المدى: أنواع الرماة، المقذوفات، الدقة، التصويب، الغطاء.

---

## 1. أنواع الرماة (Archer Types)

| النوع | مثال | المدى (م) | الضرر | سرعة الإطلاق | دقة الأساسية | الذخيرة |
|-------|------|---------|------|-------------|------------|---------|
| **رامٍ خفيف** | ألب رامٍ (تركي) | 25 | 10-15 ثَقب | 1.5/ثانية | 75% | 30 سهماً |
| **رامٍ ثقيل** | رامٍ بيزنطي (حامية) | 35 | 18-25 ثَقب | 0.8/ثانية | 85% | 20 سهماً |
| **رامٍ على حصان** | فارس مغولي | 20 | 10-14 ثَقب | 1.2/ثانية | 65% (يتحرك) | 40 سهماً |
| **قناص متخصص** | بوران | 45 | 25-35 ثَقب/نار | 0.5/ثانية | 95% (ثابت) | غير محدود (قدرات) |
| **رمّاح** | مشاة برمح قصير | 15 | 15-20 ثَقب | 0.7/ثانية | 90% | 5 رماح |

## 2. المقذوفات (Projectile Physics)

### 2.1. خصائص المقذوف
| الخاصية | السهم (Arrow) | الرمح (Javelin) | الحجر (Stone — منجنيق) |
|---------|-------------|----------------|----------------------|
| سرعة المقذوف | 25 م/ث | 18 م/ث | 15 م/ث |
| مسار | منحني (Arced) | مستقيم (مسطح) | منحني جداً (High Arc) |
| وقت الوصول (عند 25 م) | 1.0 ثانية | 1.4 ثانية | 1.7 ثانية |
| يتأثر بالجاذبية؟ | نعم | قليلاً | كثيراً |
| يتأثر بالرياح؟ | لا (v1) | لا | قليلاً (سقوط عشوائي ±1 م) |

### 2.2. سرعة المقذوف مقابل الوقت للوصول للهدف
```
المسافة   سهم (25 م/ث)   رمح (18 م/ث)   حجر (15 م/ث)
────────────────────────────────────────────────
10 م       0.4 ث          0.56 ث         0.67 ث
20 م       0.8 ث          1.11 ث         1.33 ث
30 م       1.2 ث          1.67 ث         2.0 ث
40 م       1.6 ث          —              —
```

### 2.3. التصويب والمسار (Aiming & Trajectory)
- المقذوفات تصوب نحو موقع الهدف الحالي (وليس المتوقع — لا Leading).
- إذا تحرك الهدف أثناء طيران المقذوف، قد يفوته (Dodge by Movement).
- المقذوفات التي تخطئ الهدف: تسقط في أقرب بقعة خلفه (تأثير أرضي).

## 3. نظام الدقة (Accuracy System)

### 3.1. معادلة الدقة الأساسية
```
فرصة_الإصابة الفعلية = دقة_الرامي الأساسية × عوامل_الرامي × عوامل_الهدف × عوامل_المسافة × عوامل_التضاريس
```

### 3.2. عوامل الرامي (Shooter Factors)
| العامل | المضاعف | ملاحظات |
|--------|---------|---------|
| الرامي واقف (ثابت) | ×1.0 | |
| الرامي يتحرك (يمشي) | ×0.6 | |
| الرامي يركض | ×0.3 | |
| الرامي على حصان (ثابت) | ×0.85 | الرماية من على صهوة جواد |
| الرامي على حصان (يتحرك) | ×0.5 | |
| الرامي على أرض مرتفعة | ×1.15 | |
| الرامي متعب (تحت 30% HP) | ×0.8 | |
| الرامي في تشكيل منظم | ×1.1 | الرماة في تشكيل يطلقون بشكل منسق |
| الرامي في تخفي | ×1.2 | وقت أطول للتصويب |

### 3.3. عوامل الهدف (Target Factors)
| العامل | المضاعف | ملاحظات |
|--------|---------|---------|
| هدف واقف (ثابت) | ×1.0 | |
| هدف يمشي | ×0.85 | |
| هدف يركض | ×0.7 | |
| هدف صغير (قائد، طفل) | ×0.6 | |
| هدف كبير (فيل حرب، مبنى) | ×2.0 (أصاب دائمًا تقريبًا) | |
| هدف في غطاء (خلف جدار) | ×0.3 | |
| هدف في غابة كثيفة | ×0.5 | |

### 3.4. عوامل المسافة (Distance Factors)
| المسافة | مضاعف الدقة |
|---------|------------|
| قريب جداً (0-10 م) | ×1.0 (95% حد أقصى) |
| قريب (10-20 م) | ×0.9 |
| متوسط (20-30 م) | ×0.75 |
| بعيد (30-40 م) | ×0.55 |
| أقصى مدى (40-45 م) | ×0.35 |

### 3.5. عوامل التضاريس والطقس (Terrain & Weather Factors)
| العامل | المضاعف |
|--------|---------|
| نهار صاف | ×1.0 |
| غسق/فجر | ×0.85 |
| ليل | ×0.65 |
| مطر خفيف | ×0.9 |
| مطر غزير/عاصفة | ×0.7 |
| غبار/دخان في المنطقة | ×0.6 |

### 3.6. مثال حسابي لدقة الرماية
```
بوران (مستوى 5، دقة أساسية 95%)
يرمي على فارس مغولي يركض (×0.7) على مسافة 20 م (×0.9)
في النهار (×1.0)، من أرض مرتفعة (×1.15)، وهو في تخفي (×1.2)

فرصة الإصابة = 0.95 × 1.15 × 1.2 × 0.7 × 0.9 × 1.0
              = 0.824 → 82.4% فرصة إصابة
```

## 4. الغطاء (Cover System)

### 4.1. أنواع الغطاء
| النوع | تخفيض الضرر | فرصة تفادي السهم | ملاحظات |
|-------|------------|-----------------|---------|
| **غطاء صلب** (جدار حجري) | -90% ضرر | 100% (السهم لا يخترق) | دائم، لا يُدمر |
| **غطاء خشبي** (برميل، باب) | -50% ضرر | 70% | يُدمر بعد 100 ضرر |
| **غطاء طبيعي** (شجرة كثيفة) | -30% ضرر | 50% | 3-5 سهام قبل التدمير |
| **غطاء منخفض** (جدار صغير) | -40% ضرر | 60% | ينحني للرماية — يمكن إصابة الرأس |
| **غطاء متحرك** (درع كبير) | -60% ضرر | 80% | فقط للوحدات المجهزة بدروع كبيرة |

### 4.2. نظام الانحناء والغطاء (Peek & Cover)
- الوحدات خلف غطاء تطلق النار بشكل دوري (تنحني خارج الغطاء، تطلق، تعود).
- أثناء الانحناء: الوحدة معرضة للخطر بنسبة 30% من الوقت.
- فرصة إصابة وحدة منحنية: 40% (مقارنة بـ 70% لوحدة مكشوفة).

## 5. الذخيرة والإمداد (Ammunition & Supply)

### 5.1. نظام الذخيرة الأساسي
| الوحدة | الذخيرة الابتدائية | إعادة التموين |
|--------|-------------------|--------------|
| رامٍ خفيف (تركي) | 30 سهماً قرب الأوبا | — |
| رامٍ ثقيل (بيزنطي) | 20 سهماً قرب القلعة | — |
| رامٍ على حصان | 40 سهماً قرب الأوبا | — |
| بوران | غير محدود (قدرات) + 20 سهماً عادياً | — |
| منجنيق | 5 قذائف حجرية قرب الأوبا | تصنيع (تكلفة 50 خشب/قذيفة) |

### 5.2. استنزاف الذخيرة
- الرماة يستهلكون سهماً واحداً لكل طلقة.
- عند نفاد الذخيرة:
  - الرماة يتحولون إلى سلاح قريب (خنجر/سيف قصير) ضرر 5.
  - الرماة على حصان: ينسحبون لإعادة التموين تلقائياً.
  - بوران: لا ينفد سهمه أبداً (قدرة خارقة).

## 6. نيران صديقة (Friendly Fire — Ranged)

عند إطلاق المقذوفات عبر وحدات صديقة:
| الوضع | فرصة إصابة صديق | الضرر للصديق |
|-------|----------------|------------|
| رامٍ يطلق من خلف خط صديق (خط مستقيم) | 15% | 100% الضرر العادي |
| رامٍ يطلق من أرض مرتفعة فوق الأصدقاء | 0% (يطلق من فوقهم) | لا ضرر |
| رامٍ على حصان (زاوية منخفضة) | 25% عبر الأصدقاء | 100% الضرر العادي |
| منجنيق يسقط على أصدقاء | 80% (إذا أخطأ الهدف) | ضرر سحق 100% |
