# تكتيكات الكر والفر — Hit & Run Tactics (Detailed)

> تفصيل كامل لتكتيكات الكر والفر: الهجوم المباغت، الانسحاب، إعادة الاشتباك، حرب العصابات.

---

## 1. مبادئ الكر والفر (Principles of Hit & Run)

| المبدأ | الوصف |
|--------|-------|
| **لا اشتباك مباشر** | اضرب من بعيد أو من الظل — لا تقف في وجه العدو أبداً |
| **الحركة الدائمة** | لا تبقى في مكان واحد أكثر من 15 ثانية بعد الهجوم |
| **استنزاف وليس تدمير** | الهدف ليس قتل كل الأعداء دفعة واحدة — بل إضعافهم تدريجياً |
| **التفوق العددي عكسي** | كلما كان العدو أكثر عدداً، كلما كان الكر والفر أكثر فعالية (العدو يبطئ نفسه) |
| **المعرفة قوة** | اعرف تضاريس الخريطة أفضل من العدو — استخدم كل مخرج هروب |

## 2. دورة الكر والفر (Hit & Run Cycle)

```
┌──────────────────────────────────────────────────┐
│              دورة الكر والفر                      │
├──────────────────────────────────────────────────┤
│                                                    │
│  [كشف] → [اقتراب] → [هجوم] → [انسحاب] → [اختفاء] → [تقييم] → [كرر]  │
│                                                    │
│  1. اكتشف موقع ضعف العدو                           │
│  2. اقترب من التخفي/من بعيد                        │
│  3. أطلق وابلاً سريعاً من الهجمات                   │
│  4. انسحب قبل أن يرد العدو                         │
│  5. اختفي في التضاريس/الظلام                        │
│  6. قيّم: هل أضعفت العدو بما يكفي؟                 │
│  7. عد من جهة أخرى ← كرر                           │
│                                                    │
└──────────────────────────────────────────────────┘
```

## 3. مراحل الكر والفر

### 3.1. الكشف (Reconnaissance)
| الطريقة | المدة | مستوى الأمان | المعلومات المكتسبة |
|---------|-------|-------------|-------------------|
| بوران — استطلاع | 10-20 ثانية | آمن (مخفي) | عدد الأعداء، نوعهم، توزيعهم، نقاط ضعف |
| فارس طعم — تمشيط | 5-10 ثوانٍ | متوسط (مكشوف) | مواقع الدوريات، سرعة رد الفعل |
| نار اختبارية | 5 ثوانٍ | منخفض (يكشف) | هل هناك أعداء مختبئون (يخرجون عند النار) |
| صافرة (اختبار صوت) | 2 ثانية | آمن (من بعيد) | هل هناك أعداء في المنطقة (يأتون للتحقق) |

### 3.2. الاقتراب (Approach)
| النوع | الوصف | مضاعف سرعة الهجوم الأولى |
|-------|-------|------------------------|
| **من التخفي** | الاقتراب عبر غابة/شجيرات — أبطأ لكن آمن | ×1.5 |
| **من الخلف** | الالتفاف حول العدو — أطول طريق لكن الأكثر فعالية | ×2.0 |
| **من بعيد (رماة)** | رماة يطلقون من أقصى مدى — آمن لكن ضرر أقل | ×1.0 |
| **بوران — اغتيال** | يقترب من الخنجر فقط — يقتل هدفاً فردياً | ×3.0 (اغتيال) |

### 3.3. الهجوم (Strike)
| التكتيك | المدة المثالية | الوحدات المشاركة | الضرر المتوقع |
|---------|--------------|----------------|-------------|
| **وابل رماة** | 3-5 ثوانٍ | 4-8 رماة | 300-600 ضرر إجمالي |
| **قنص بوران** | 1-2 ثانية | بوران فقط | 50-150 ضرر + اغتيال محتمل |
| **هجوم خاطف مشاة** | 5-8 ثوانٍ | 4-6 مشاة خفيف | 200-400 ضرر |
| **إطلاق نار — انسحاب** | تناوب | مجموعتا رماة | 600-900 ضرر إجمالي (دورتان) |

### 3.4. الانسحاب (Withdrawal)
| طريقة الانسحاب | السرعة | مستوى الأمان | ينكشف الكمين؟ |
|---------------|--------|-------------|--------------|
| **جري إلى غابة قريبة** | سريع | آمن (عند الوصول) | لا — طالما الوصول سريع |
| **غطاء دخاني (قدرة بوران)** | فوري | آمن جداً | لا — الدخان يغطي الانسحاب |
| **فارس يغطي الانسحاب** | متوسط | متوسط | لا — لكن الفارس قد يصاب |
| **تفرق في كل اتجاه** | سريع | آمن للبعض | لا — يصعب تتبع وحدات متفرقة |
| **الاختفاء في العراء (بوران فقط)** | فوري | آمن (قدرة) | لا — يختفي فوراً |

### 3.5. قواعد الانسحاب
```
1. قبل الهجوم: حدد طريق الانسحاب (Shift + أمر تحرك بعد الهجوم)
2. أثناء الهجوم: لا تنتظر حتى يرد العدو — اضرب وانسحب فوراً
3. بعد الانسحاب: لا تعود فوراً — انتظر 10-15 ثانية على الأقل
4. إذا طاردك العدو:
   - لا تركض في خط مستقيم ← استخدم التعرج (خاصة بوران)
   - لا تدخل طريقاً مسدوداً ← اعرف الخريطة
   - استخدم قدرات الإعاقة (السهم المشتعل يحرق الأرض ويبطئ المطاردين)
```

## 4. تكتيكات الكر والفر المتقدمة

### 4.1. النار والانسحاب (Fire & Retreat)
```
1. مجموعة رماة (6 وحدات) تطلق وابلاً مركزاً على هدف
2. بعد 3 ثوانٍ من الإطلاق: جميع الرماة يركضون إلى موقع الانسحاب
3. العدو يرد: سهام/مطاردة
4. بعد 15 ثانية: الرماة يعودون من موقع مختلف ويكررون

الميزة: لا يرى العدو مصدر النيران الدائم — دائماً من زاوية مختلفة
العيب: يستغرق وقتاً طويلاً لاستنزاف العدو
```

### 4.2. المطرقة والسندان (المتحركة) (Mobile Hammer & Anvil)
```
التطبيق الهجومي:
1. السندان: مشاة ثقيل يثبتون العدو في مكانهم (يدافعون)
2. المطرقة: رماة/فرسان خفيف يهاجمون من الخلف/الجوانب
3. عندما يحاول العدو ملاحقة المطرقة: السندان يمسك بهم
4. عندما يحاول العدو مهاجمة السندان: المطرقة تضرب من الخلف

التطبيق الدفاعي (انسحاب):
1. السندان يتراجع ببطء، المطرقة تغطي الانسحاب
2. المطرقة تضرب وتتراجع، تضرب وتتراجع — تؤخر تقدم العدو
3. السندان يصل إلى موقع آمن، ثم يغطي انسحاب المطرقة
```

### 4.3. تكتيك الذئاب المنفردة (Lone Wolves)
```
بوران وحده في عمق خطوط العدو:

1. استطلاع: يكشف مواقع الأعداء والطرق الآمنة
2. اغتيال: يقتل قائد دورية — يحدث فراغاً قيادياً
3. تخريب: يحرق خيمة إمداد — يضعف العدو قبل المعركة
4. إرباك: يطلق سهماً مشتعلاً في جهة — يجذب العدو إليها
5. تسلل: يفتح بوابة خلفية — يسمح بدخول الجيش الرئيسي

الخطر: بوران وحيد — إذا كشف، لا يوجد من ينقذه
المكافأة: كل ما سبق دون إنذار عام — العدو يضعف دون أن يعرف لماذا
```

### 4.4. التبادل الدائري (Rotation Tactics)
```
تناوب مجموعتين من الرماة:

           مجموعة أ (تطلق)          مجموعة ب (تستعد)
               ↓                         ↓
          [تطلق لمدة 5 ثوانٍ]       [تتجه إلى موقع جديد]
               ↓                         ↓
          [تنسحب إلى موقع جديد]     [تطلق لمدة 5 ثوانٍ]
               ↓                         ↓
          [تستعد في الموقع الجديد]   [تنسحب...]
               ↓                         ↓
          (تتكرر الدورة)

النتيجة: نيران مستمرة على العدو دون توقف — العدو لا يرى مصدراً ثابتاً
```

## 7. حدود الكر والفر (Limitations)

| المحدد | السبب | التأثير على التكتيك |
|--------|-------|-------------------|
| **نفاد الذخيرة** | الرماة لديهم 30 سهماً فقط | اضرب بدقة — لا تطلق عشوائياً |
| **تعب الوحدات** | الركض المستمر يقلل HP بنسبة 1%/دقيقة من الركض | توقف للراحة بين الدورات |
| **تعلم العدو** | العدو يتعلم أنماط الكر والفر — يبدأ في نصب كمائن للمهاجم | غير نمط هجومك باستمرار |
| **نقاط سيادة** | الكر والفر لا يبني نقاط سيادة (البناء والفتح يبنيها) | وازن بين التكتيكات |
| **تقييم المهمة** | الكر والفر يستغرق وقتاً — قد يخفض تقييم السرعة | خطط لوقتك بعناية |
