# تولي أورخان — Orhan's Accession (M48-M49)

> مواصفات مرحلة انتقال الحكم من عثمان إلى أورخان: التغييرات في أسلوب اللعب، نظام الولاء، والنهايات الأربع.

---

## 1. ما يتغير عند تولي أورخان (What Changes)

### إيجابيات
| العنصر | التغيير |
|--------|---------|
| **أورخان يصبح البطل الرئيسي** | F1 يتحول إلى أورخان — عثمان يختفي من قائمة الأبطال |
| **وراثة ترقيات الجيش** | جميع ترقيات عثمان للجيش تنتقل إلى أورخان |
| **الخزينة** | كل الذهب المتبقي ينتقل |
| **العلاقات** | جميع مقاييس البايلكات تبقى |

### سلبيات
| العنصر | التغيير |
|--------|---------|
| **مستوى أورخان** | يبدأ من مستواه الحقيقي (1-12) — بغض النظر عن مستوى عثمان |
| **فقدان قدرات عثمان** | صيحة الحرب، حلم الشجرة، قلب الأسد — كلها ترحل مع عثمان |
| **انخفاض ولاء الأمراء مؤقتاً** | -10 ولاء (فترة انتقالية) |
| **فقدان عثمان كبطل مقاتل** | لا يمكن استخدام عثمان في المعارك بعد م47 |

### نقاط المهارة المجانية
كل وصية من عثمان (م47) تمنح +3 نقاط مهارة مجانية لأورخان:
- الإرث العسكري (أ أو ب): +3 SP
- الإرث السياسي (أ أو ب): +3 SP
- الإرث الديني (أ أو ب): +3 SP
- الكلمة الأخيرة (أ أو ب): +3 SP
- **المجموع**: حتى +12 SP إضافية لأورخان

## 2. نظام الولاء أثناء الانتقال (Loyalty System — M48)

### فصائل البيعة الخمس
| الفصيل | الولاء الأساسي | المطلب الرئيسي |
|--------|---------------|----------------|
| **جيش الكايي (تورت بك)** | 90 | استمرار الفتوحات |
| **علماء يني شهر (علاء الدين)** | 85 | العدل والاستقرار |
| **تجار بورصة (بيندير بك)** | 70 | أمان التجارة |
| **أمراء الحدود** | 50 | حماية من جيرميان |
| **قبائل التركمان** | 40 | احترام استقلالهم |

### خطبة البيعة — 3 أولويات
أورخان يلقي خطاب البيعة ويختار 3 أولويات من 4:

| الأولوية | المكافأة | التأثير الجانبي |
|----------|----------|----------------|
| **العدل** | +20 ولاء العلماء | -20% فساد |
| **القوة** | +20 ولاء الجيش | +10% هجمات جيرميان |
| **التجارة** | +20 ولاء التجار | +30% دخل ذهب |
| **الوحدة** | +20 ولاء القبائل | +10% معنويات |

### التمرد المحتمل
- إذا ولاء أي فصيل < 30 عند البيعة → تمرد ميني (مهمة جانبية)
- إذا ولاء فصيلين < 30 → حرب أهلية مصغرة
- إذا جميع الفصائل > 50 → بيعة موحدة (+20% لجميع المقاييس)

## 3. النهايات الأربع (4 Possible Endings — M49)

تعتمد النهاية على مجموعة الخيارات عبر جميع مواسم اللعبة — مع تركيز خاص على الموسم الخامس.

### النهاية 1 — الإمبراطورية العادلة (العدل العالمي)
| الشرط | خيار م49 |
|-------|---------|
| الإرث السياسي (ب) + العدل في م48 | "نحكم بالعدل — مسلماً ومسيحياً ويهودياً" |
| **الراية**: بيضاء + زرقاء |
| **الوصف**: أورخان يبني إمبراطورية تقوم على التسامح والعدالة — جميع الأديان تحت راية واحدة |

### النهاية 2 — الإمبراطورية المقدسة (الفتح المقدس)
| الشرط | خيار م49 |
|-------|---------|
| الإرث العسكري (أ) + القوة في م48 | "سنمضي حتى تشرق الشمس" |
| **الراية**: حمراء + ذهبية |
| **الوصف**: أورخان يواصل فتوحات والده — التوسع نحو أوروبا بلا توقف |

### النهاية 3 — إمبراطورية العلم (الحضارة والعلم)
| الشرط | خيار م49 |
|-------|---------|
| الإرث الديني (ب) + التجارة في م48 | "مدننا ستكون منارات العلم" |
| **الراية**: زرقاء + فضية |
| **الوصف**: علاء الدين يقود نهضة علمية — بورصة تصبح مركزاً للثقافة والفنون |

### النهاية 4 — إمبراطورية الشعوب (وحدة الشعوب)
| الشرط | خيار م49 |
|-------|---------|
| الإرث السياسي (أ) + الوحدة في م48 | "كل الأعراق — تحت ظل دولتنا" |
| **الراية**: خضراء + بيضاء |
| **الوصف**: أورخان يبني دولة متعددة الأعراق والأديان — نموذج للتعايش |

### نهاية سرية (إذا تحققت كل الشروط)
| الشرط | المكافأة |
|-------|---------|
| جميع وصايا عثمان + جميع فصائل م48 > 70 + علاقات البايلكات كلها > 50 | **نهاية البطل الأسطوري** — مشهد يجمع عثمان (كظل) مع أورخان على عرش بورصة |
