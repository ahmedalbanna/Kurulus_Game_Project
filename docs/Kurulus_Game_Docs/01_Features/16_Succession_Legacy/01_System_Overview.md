# نظام الميراث والخلافة — Succession & Legacy System

> مواصفات نظام انتقال الحكم من عثمان إلى أورخان: الوصايا الأربع، الميراث الدائم، وتأثير الخيارات عبر الحملة.

---

## 1. نظرة عامة (Overview)

- **تفعيل النظام**: م47 — وصية السلطان (عثمان على فراش الموت)
- **الغرض**: تحديد ما يتركه عثمان لأورخان — ليس فقط جيشاً ودولة، بل رؤية وقيماً.
- **تأثير دائم**: اختيارات الوصية تؤثر على كل مهمة متبقية (م48, م49) وجودة الخاتمة.

### متى يُفعّل النظام

| المهمة | الحدث | النظام الفرعي |
|--------|-------|--------------|
| **م47** | عثمان يملي وصيته — 4 وصايا بخيارين لكل منها | الميراث (Legacy) |
| **م48** | بيعة أورخان — إدارة الفصائل وولائها | الخلافة (Succession) |
| **م49** | الخاتمة — 4 نهايات ممكنة حسب الخيارات عبر الموسم الخامس | النهاية (Ending) |

---

## 2. وصايا عثمان الأربع (Osman's Four Testaments)

| الوصية | الخيار (أ) | الخيار (ب) |
|--------|-----------|-----------|
| **1. الإرث العسكري** | "تابعوا الفتوحات — السيف لا يصدأ" | "ابنوا البلاد — الحكم بالعدل أقوى من السيف" |
| **2. الإرث السياسي** | "تحالفوا مع البيزنطيين بالذهب" | "أخضعوهم بالقوة — لا صديق دائم في السياسة" |
| **3. الإرث الديني** | "الإيمان — سراج الدولة" | "العلم — قوة الدولة" |
| **4. الكلمة لأورخان** | "كن كسيفك — لا ينكسر أبداً" | "كن كالماء — يجد طريقه دائماً" |

كل وصية تمنح تأثيراً دائماً على الحملة المتبقية.

## 3. الميراث: ما ينتقل من عثمان إلى أورخان (What Carries Over)

### ينتقل بالكامل
| العنصر | التفاصيل |
|--------|----------|
| **الجيش** | جميع ترقيات الجيش (الأسلحة، الدروع، التدريب) |
| **الخزينة** | الذهب المتبقي (بحد أقصى 2,000) |
| **العلاقات الدبلوماسية** | جميع مقاييس البايلكات (مع تعديل بسيط للولاء) |
| **الأبطال** | علاء الدين، فاطمة، الناجون من الجيل القديم |

### لا ينتقل
| العنصر | السبب |
|--------|-------|
| **مستوى عثمان** | عثمان يرحل — خبرته تذهب معه |
| **قدرات عثمان** | قدرات فريدة لعثمان لا يمكن لأورخان استخدامها |
| **معدات عثمان** | تُدفن معه أو تبقى كتذكارات (تأثير معنوي فقط) |

### ينتقل جزئياً (حسب خيارات الوصية)
| الوصية | ما ينتقل |
|--------|---------|
| عسكري (أ) | +50 XP لكل بطل من الجيل الجديد |
| عسكري (ب) | +30% دخل ذهب شهري |
| سياسي (أ) | +10 علاقة مع بيزنطة |
| سياسي (ب) | +10 قوة عسكرية |
| ديني (أ) | جميع المهمات تبدأ بمعنويات كاملة |
| ديني (ب) | +20% خبرة مكتسبة |
| كلمة لأورخان (أ) | +15 شجاعة لأورخان (+10% ضرر) |
| كلمة لأورخان (ب) | +15 حكمة لأورخان (+10% فعالية دبلوماسية) |

## 4. شاشة الإرث (Legacy Screen UI)

| العنصر | الوصف |
|--------|-------|
| **شجرة الإرث** | رسم بياني يظهر جميع الوصايا المختارة |
| **مؤشرات الميراث** | ما ينتقل إلى أورخان (قائمة مرئية) |
| **توقعات الخاتمة** | بناءً على الخيارات الحالية — "مسار الإمبراطورية" |
| **ذكريات عثمان** | مشاهد سينمائية قصيرة لكل وصية |
| **لقب أورخان** | يتغير حسب الخيارات: "الفاتح", "الحكيم", "العادل", "المؤسس" |
