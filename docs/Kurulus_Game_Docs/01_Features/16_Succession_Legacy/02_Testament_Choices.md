# خيارات الوصية — Testament Choices (M47)

> تفصيل وصايا عثمان الأربع — كل وصية بخيارين، 8 تفرعات محتملة، وتأثيراتها الدائمة على الحملة.

---

## 1. نظرة عامة (Overview)

في م47 — وصية السلطان — يملي عثمان 4 وصايا. لكل وصية خياران. إجمالي التفرعات: 2^4 = **16 مساراً ممكناً** لخيارات الوصية.

### توقيت الاختيار
- تظهر كل وصية كمشهد درامي منفصل.
- لا يمكن تغيير الاختيار بعد اتخاذه.
- تظهر تأثيرات الوصية فوراً في شاشة الإرث.

## 6. مكافآت التكامل (Synergy Rewards)

| إذا اختار اللاعب | المكافأة المخفية |
|-----------------|-----------------|
| **3 وصايا من نفس النوع (عسكري/سياسي/ديني)** | لقب خاص لأورخان + قدرة ألتميت إضافية |
