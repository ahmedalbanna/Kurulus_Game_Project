# سلوك البايلكات الذكي — AI Beylik Behavior

> مواصفات سلوك الإمارات التركمانية التي يتحكم بها الذكاء الاصطناعي: أنماط الشخصية، أشجار القرار، وصعوبة الدبلوماسية.

---

## 1. جيرميان — إمارة العداء القديم (Aggressive Power)

**الشخصية**: يعقوب بك — حاكم عجوز فخور، يرى نفسه الوريث الشرعي للسلاجقة.

### النمط الأساسي
| البعد | القيمة |
|-------|--------|
| **العدوانية** | عالية (7/10) |
| **الصبر الدبلوماسي** | منخفض (3/10) |
| **الولاء للتحالفات** | متوسط (5/10) |
| **المكر** | عالٍ (8/10 — بمساعدة سعادت خاتون) |

### شجرة قرارات جيرميان
```
إذا (علاقة جيرميان < 0) {
    → إرسال غارات على القرى الحدودية
    → إذا (القوة العسكرية > قوة عثمان) {
        → شن حرب شاملة (م42)
    } وإلا {
        → مهاجمة القوافل التجارية (م36)
    }
}
إذا (علاقة جيرميان 0-50) {
    → مراقبة حذرة
    → مناوشات محدودة
    → محاولة تجنيد أمراء حدود
}
إذا (علاقة جيرميان > 50) {
    → اقتراح تحالف (مشروط)
    → طلب جزية رمزية
}
```

### تصعيد جيرميان
| مستوى التصعيد | الإجراء | يحدث في |
|--------------|---------|--------|
| 1 — دبلوماسي | رسائل تهديد، مطالب | م35 |
| 2 — اقتصادي | قطع طرق التجارة | م36 |
| 3 — عسكري محدود | غارات حدودية | م37 |
| 4 — حرب شاملة | جيش نظامي يغزو | م42 |
| 5 — حرب استنزاف | حصار القلاع | م43، م45 |

## 2. قرمان — الإمارة الانتهازية (Opportunistic Ally)

**الشخصية**: أمير قرمان — حاكم واقعي، يبحث عن مصلحته أولاً.

| البعد | القيمة |
|-------|--------|
| **العدوانية** | متوسطة (5/10) |
| **الصبر الدبلوماسي** | عالٍ (7/10) |
| **الولاء للتحالفات** | منخفض (3/10 — ينقلب إذا عرض جيرميان أكثر) |

### شجرة قرارات قرمان
```
إذا (علاقة قرمان > 60) {
    → اقتراح تحالف ضد جيرميان
    → إذا (قبل عثمان) → إرسال 200 جندي
    → إذا (رفض عثمان) → -10 علاقة
}
إذا (علاقة قرمان 0-60) {
    → مراقبة الصراع
    → عدم التدخل
}
إذا (علاقة جيرميان > علاقة قرمان + 20) {
    → قرمان تميل لجيرميان
    → تفعيل: "قرمان تتحالف مع جيرميان"
}
```

## 3. تصعيد الصعوبة (Difficulty Scaling)

| مستوى الصعوبة | ذكاء جيرميان | ذكاء قرمان | أحداث عشوائية إضافية |
|--------------|-------------|-----------|---------------------|
| **سهل** | يستجيب فقط للتهديدات المباشرة | يقبل أي تحالف | بدون |
| **عادي** | يخطط غارة كل 3 مهمات | يتفاوض بذكاء متوسط | حدث واحد |
| **صعب** | ينسق هجمات مع بيزنطة | يلعب على الإمارتين | حدثان |
| **ملحمي** | يحاول اختراق يني شهر بالجواسيس | يتحالف مع جيرميان إذا فازت في م42 | 3 أحداث + تمرد داخلي |

### متغيرات الصعوبة
- **سرعة انحدار العلاقات**: في الصعوبة العالية، تنخفض العلاقات أسرع بنسبة 50%
- **فعالية الهدايا**: في الصعوبة العالية، فعالية الهدايا تنخفض بنسبة 30%
- **التبريد الدبلوماسي**: يزداد بمقدار مهمة واحدة في الصعوبة العالية

## 4. الإمارات الصغرى (Minor Beyliks)

|---------|-----------------|-------|
