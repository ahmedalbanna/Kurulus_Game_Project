## 1. مقياس علاقة جيرميان (Germiyan Relation)

**النطاق**: -100 (حرب شاملة) إلى +100 (تحالف كامل)  
**يبدأ عند**: 50 (حذر دبلوماسي)

| النطاق | التصنيف | التأثيرات |
|--------|---------|-----------|
| **80 إلى 100** | تحالف | + تجارة حرة، + دعم عسكري محدود، - زواج سياسي محتمل |
| **50 إلى 79** | علاقات جيدة | + تجارة طبيعية، + جواسيس أقل |
| **0 إلى 49** | محايد | - تجارة محدودة، - مناوشات حدودية نادرة |
| **-1 إلى -49** | توتر | - هجمات حدودية متكررة، - حظر تجاري جزئي |
| **-50 إلى -79** | عداء | - قطع العلاقات، - غارات جيرميان على القرى |
| **-80 إلى -100** | حرب شاملة | - جيش جيرميان يغزو، - كل الموارد للحرب |

### التغييرات الرئيسية
- **فقدان النقاط**: رفض مطالب يعقوب بك، مهاجمة قوات جيرميان، تحالف مع قرمان
- **كسب النقاط**: قبول التنازلات، إرسال الهدايا، الزواج السياسي (غونجا)

## 2. مقياس علاقة قرمان (Karaman Relation)

**النطاق**: -100 إلى +100  
**يبدأ عند**: 30 (حليف محتمل)

| النطاق | التصنيف | التأثيرات |
|--------|---------|-----------|
| **70 إلى 100** | تحالف عسكري | + جيش قرماني مساعد، + تنسيق هجومي (م44) |
| **40 إلى 69** | علاقات جيدة | + تجارة، + معلومات استخباراتية عن جيرميان |
| **0 إلى 39** | محايد | لا تفاعل يذكر |
| **-1 إلى -49** | برود دبلوماسي | - قرمان تميل لجيرميان |
| **-50 إلى -100** | عداء | - قرمان تتحالف مع جيرميان ضدك |

### التغييرات الرئيسية
- **فقدان النقاط**: التنازل لجيرميان، رفض تحالف تجاري
- **كسب النقاط**: اتفاق تجاري، هدايا، تحالف ضد جيرميان (م44)

## 3. مقياس ولاء الأمراء الأتراك (Turkish Lord Loyalty)

**النطاق**: 0 إلى 100  
**يبدأ عند**: 70 (ولاء جيد مبدئياً)

| النطاق | التأثيرات |
|--------|-----------|
| **80 إلى 100** | + جميع الأمراء يرسلون قواتهم للدعم، + 20% جيش إضافي في المعارك الكبرى |
| **60 إلى 79** | + معظم الأمراء موالون، + دعم محدود |
| **40 إلى 59** | ± بعض الأمراء يتذمرون، - تأخير في الإمدادات |
| **20 إلى 39** | - أمراء يرفضون الأوامر، - تمردات محلية |
| **0 إلى 19** | - حرب أهلية محتملة (م48)، - انشقاق الأمراء لجيرميان |

## 4. مقياس الاستقلال (Independence)

**النطاق**: 0 إلى 100  
**يبدأ عند**: 80 (استقلال عالٍ)

| النطاق | التأثيرات |
|--------|-----------|
| **80 إلى 100** | + قرارات مستقلة بالكامل، + احترام الإمارات الأخرى |
| **50 إلى 79** | ± حرية قرار، + بعض الضغوط الخارجية |
| **20 إلى 49** | - إمارة تابع فعلية، - يدفع جزية، - خيارات دبلوماسية محدودة |
| **0 إلى 19** | - تحت الوصاية، - كل القرارات يمليها يعقوب بك، - نهاية سيئة في م49 |

## 5. التغيير التلقائي (Decay & Drift)

| المقياس | الانحدار الطبيعي | الشرط |
|---------|------------------|-------|
| جيرميان | -2 لكل مهمة لا يتم فيها تفاعل | العلاقة > 50 |
| قرمان | -1 لكل مهمة لا يتم فيها تفاعل | العلاقة > 30 |
| ولاء الأمراء | -1 لكل مهمة بدون انتصار | لا يشترط |
| الاستقلال | لا انحدار تلقائي | — |
