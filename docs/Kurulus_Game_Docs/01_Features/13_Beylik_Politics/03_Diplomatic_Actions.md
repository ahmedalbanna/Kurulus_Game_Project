# الإجراءات الدبلوماسية — Diplomatic Actions

> قائمة الإجراءات المتاحة بين المهمات: التكلفة، التأثير على المقاييس، وفترة التبريد.

---

## 1. الإجراءات الأساسية (Core Actions)

### إرسال سفير (Send Envoy)
| الخاصية | القيمة |
|---------|--------|
| **التكلفة** | 50 ذهب |
| **التأثير** | +5 علاقة مع الإمارة المستهدفة |
| **التبريد** | مهمتان |
| **الوصف** | ترسل رسولاً يحمل رسالة دبلوماسية — تحية، اقتراح، أو استفسار |

### إهداء هدية (Offer Gift)
| الخاصية | القيمة |
|---------|--------|
| **التكلفة** | 200-500 ذهب (حسب قيمة الهدية) |
| **التأثير** | +10 إلى +20 علاقة (حسب قيمة الهدية) |
| **التبريد** | 3 مهمات |
| **ملاحظة** | الهدية المكررة تنخفض فعاليتها بنسبة 50% |

### اقتراح زواج (Propose Marriage)
| الخاصية | القيمة |
|---------|--------|
| **التكلفة** | 500-1000 ذهب (مهر) |
| **التأثير** | +30 علاقة مع الإمارة |
| **التبريد** | مرة واحدة فقط لكل إمارة |
| **الشرط** | وجود أعزب/عزباء مناسب(ة) من البيتين |

### تهديد بالحرب (Threaten War)
| الخاصية | القيمة |
|---------|--------|
| **التكلفة** | — |
| **التأثير** | -20 علاقة (الهدف)، +10 احترام (إذا كان الجيش أقوى) |
| **التبريد** | 4 مهمات |
| **الخطر** | إذا كانت القوة العسكرية أقل من 50% من قوة الهدف — +30 علاقة (خضوع) |

### اتفاق تجاري (Trade Agreement)
| الخاصية | القيمة |
|---------|--------|
| **التكلفة** | — (يبدأ بموافقة) |
| **التأثير** | +15 علاقة، +100 ذهب/شهر |
| **التبريد** | دائم (ينتهي فقط بقطع العلاقات) |
| **الشرط** | علاقة > 40 |

## 2. الأحداث العشوائية (Random Events)

بين المهمات، يمكن أن تحدث أحداث عشوائية تغير المقاييس:

### قائمة الأحداث
| الحدث | التأثير | الاحتمال |
|-------|---------|----------|
| "يصل رسول من جيرميان — يعقوب بك يريد تجديد التحالف" | +10 جيرميان (إذا قبلت) / -15 (إذا رفضت) | 15% |
| "تُنهب قافلة عثمانية على الحدود مع قرمان" | -10 قرمان، -100 ذهب | 10% |
| "أمراء الحدود يشتكون من إهمال يني شهر" | -5 ولاء الأمراء | 20% |
| "جاسوس جيرميان يُكشف في يني شهر" | -5 جيرميان، +5 أمن | 8% |
| "رسول من قرمان: 'السلاجقة القدامى يريدون لقاءك'" | فتح مهمة جانبية دبلوماسية | 5% |
| "زواج سياسي مقترح من إمارة تيكه" | +10 تيكه (إمارة جديدة) | 10% |

### نظام الاستجابة للأحداث
1. يظهر إشعار على الشاشة: "حدث دبلوماسي!"
2. يعرض نص الحدث مع خيارين أو ثلاثة.
3. يختار اللاعب الرد.
4. يتغير المقياس (المقاييس) فوراً.
5. يُسجل القرار في سجل الأحداث.
