# حالات الأبطال — Hero States (Detailed)

> جميع الحالات الممكنة للأبطال: الانتقالات، المدد، التأثيرات، والقيود.

---

## 1. حالات الأبطال الأساسية (Core States)

### 1.1. مصفوفة الحالات (State Matrix)

```
                    ┌─────────────┐
                    │   خامل     │
                    │   Idle     │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ متحرك   │ │ مهاجم   │ │ مستخدم │
        │ Moving  │ │Attacking│ │Ability  │
        └────┬─────┘ └────┬─────┘ └────┬─────┘
             │            │            │
             ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ جري     │ │ اشتباك  │ │ قناة    │
        │Running  │ │Engaged  │ │Channeling│
        └──────────┘ └──────────┘ └──────────┘

                    ┌──────────────┐
                    │   خارج القتال  │
                    │  狀態: ساقط    │
                    │   Knocked Out  │
                    └──────────────┘
                           │
                    ┌──────┴──────┐
                    ▼             ▼
              ┌──────────┐  ┌──────────┐
              │ يتعافى  │  │  ميت    │
              │Recovering│  │  Dead   │
              └──────────┘  └──────────┘
```

### 1.2. تفصيل الحالات الأساسية

| الحالة | الوصف | المدة | القيود |
|--------|-------|-------|--------|
| **خامل (Idle)** | واقف، لا يفعل شيئاً، ينتظر الأوامر | غير محدودة | يمكنه تلقي الأوامر في أي وقت |
| **متحرك (Moving)** | يسير نحو نقطة محددة | حتى الوصول أو أمر جديد | لا يمكنه الهجوم، يمكنه استخدام القدرات أثناء الحركة |
| **جري (Running)** | يتحرك بأقصى سرعة | حتى الوصول أو التعب (غير مطبق في v1) | +20% ضرر وارد (ظهر مكشوف) |
| **مهاجم (Attacking)** | في منتصف دورة هجوم | دورة الهجوم (حسب سرعة السلاح) | لا يمكنه التحرك أثناء الضربة |
| **مستخدم قدرة (Ability)** | يستخدم قدرة نشطة | مدة استخدام القدرة | لا يمكنه فعل أي شيء آخر |
| **قناة (Channeling)** | قدرة تحتاج قناة مستمرة (مثل حلم الشجرة) | مدة القناة | لا يمكنه التحرك، ينقطع إذا تضرر |
| **ساقط (Knocked Out)** | فقد الوعي بعد استنزاف HP | 30 ثانية | لا يمكنه فعل أي شيء، عرضة للضربة القاضية |
| **يتعافى (Recovering)** | يستعيد وعيه بعد السقوط | 5 ثوانٍ (انتقال) | 20% HP عند العودة، لا يمكنه الهجوم |
| **ميت (Dead)** | مات فعلياً في المهمة | باقي المهمة | لا يمكن استخدامه، يعود في المهمة التالية |

## 2. الحالات الخاصة (Special States)

### 2.1. حالات القتال
| الحالة | الوصف | المدة | المصدر |
|--------|-------|-------|--------|
| **مشتبك (Engaged)** | في قتال مباشر مع عدو | طالما هناك عدو في مدى الاشتباك | تلقائي عند الهجوم/التعرض للهجوم |
| **مطوَّق (Flanked)** | يتعرض للهجوم من الخلف/الجوانب | طالما بقي الموقف | عند هجوم عدو من 90° خلفية |
| **مصدوم (Stunned)** | مشلول مؤقتاً، لا يتحرك ولا يهاجم | 1-3 ثوانٍ | ضربة الأرض (تورغوت)، صدمة |
| **أعمى (Blinded)** | لا يرى شيئاً، مدى كشف = 0 | 3 ثوانٍ | خطف البصر (بوران) |
| **مذعور (Panicked)** | يركض عشوائياً، لا يستجيب للأوامر | 5-10 ثوانٍ | فشل فحص المعنويات |
| **مشتعل (Burning)** | يتلقى ضرر نار/ثانية | 6 ثوانٍ | السهم المشتعل (بوران) |
| **نازف (Bleeding)** | يتلقى ضرراً إضافياً/ثانية | 3-5 ثوانٍ | نزيف (أسلحة معينة) |
| **مبطأ (Slowed)** | سرعة الحركة -X% | 3-5 ثوانٍ | حلم الشجرة (ب) |
| **مُمنع درع (Armored)** | دفاع +X% | متغير | جدار من حديد (تورغوت) |
| **مستفز (Taunted)** | يجبر على مهاجمة المصدر | 3 ثوانٍ | زلزال التحدي (تورغوت) |

### 2.2. حالات التخفي
| الحالة | الوصف | المدة | المصدر |
|--------|-------|-------|--------|
| **مخفي (Hidden)** | غير مرئي للعدو | طالما بقي في منطقة تخفي أو شرطه | تضاريس، تخفي نشط |
| **مخفي كلياً (Hidden — Undetectable)** | لا يظهر حتى في رادار العدو | طالما ساكن | خفة الظل (بوران شق أ) |
| **مكتشف (Detected)** | كشفه العدو، لكنه لا يزال في تخفي جزئي | لحظي | عند الاقتراب من العدو |
| **مكشوف (Revealed)** | خرج من التخفي تماماً | طالما بقي خارج التخفي | هجوم، حركة في العراء |

### 2.3. حالات خاصة بالبطل
| الحالة | البطل | الوصف | المدة |
|--------|-------|-------|--------|
| **ملهم (Inspired)** | عثمان | +30% ضرر، +20% سرعة | 10 ثوانٍ (صيحة الحرب) |
| **غاضب (Enraged)** | تورغوت | +100% سرعة هجوم، +40% ضرر، -30% دفاع | 12 ثانية (غضب الثور) |
| **مرهق (Exhausted)** | تورغوت | -50% سرعة (بعد غضب الثور) | 5 ثوانٍ |
| **مركز (Focused)** | بوران | +15% دقة، +10% ضرر | طالما في تخفي |
| **صامت (Silenced)** | أي بطل | لا يمكنه استخدام قدرات | 2-4 ثوانٍ |

## 3. انتقالات الحالات (State Transitions)

### 3.1. جدول الانتقالات
```
من → إلى                   الشرط
────────────────────────────────────────
خامل → متحرك               أمر تحرك
خامل → مهاجم               أمر هجوم (أو عدو في المدى)
خامل → قدرة                أمر قدرة
خامل → ساقط                HP = 0
خامل → مخفي                دخول منطقة تخفي (أو تفعيل تخفي)

متحرك → خامل               وصول إلى الهدف
متحرك → جري                 أمر جري (مفتاح Shift + تحرك)
متحرك → مهاجم               أمر هجوم (أو عدو يهاجمه)
متحرك → ساقط               HP = 0 أثناء الحركة

مهاجم → خامل                انتهاء دورة الهجوم (بدون أهداف)
مهاجم → متحرك               أمر تحرك (بعد الضربة الحالية)
مهاجم → ساقط               HP = 0 أثناء الهجوم

قدرة → خامل                انتهاء القدرة (أو انقطاعها)
قدرة → ساقط                HP = 0 أثناء استخدام القدرة

ساقط → يتعافى              مرور 30 ثانية (لم يضرب أثناء السقوط)
ساقط → ميت                 ضربة قاضية أثناء السقوط (HP يصل -Max HP)
يتعافى → خامل              اكتمال التعافي (5 ثوانٍ)

مخفي → مكشوف               هجوم أو خروج من منطقة التخفي
مكشوف → مخفي               دخول منطقة تخفي والبقاء ساكناً 3 ثوانٍ
```

### 3.2. أولويات المقاطعة (Interruption Priority)
عند تلقي أمر أثناء حالة أخرى:
```
1. أمر التحرك → يلغي الهجوم/القدرة بعد الضربة/القناة الحالية
2. أمر القدرة → يُنفَّذ بعد اكتمال دورة الهجوم الحالية (إذا كان في هجوم)
3. أمر التوقف (S) → يلغي كل شيء فوراً
4. ضرر مميت → يلغي كل شيء فوراً ويدخل حالة ساقط
```

## 4. الموت والإحياء — Death & Recovery

### 4.1. سلسلة الموت
```
HP → 0
  ↓
يدخل حالة "ساقط" (Knocked Out)
  ↓
[نافذة 30 ثانية]
  ├── إذا لم يتعرض للضربة القاضية → "يتعافى" → 20% HP
  └── إذا تعرض للضربة القاضية → "ميت" (للمهمة)
       ↓
  [يختفي من الخريطة، لا يمكن استدعاؤه]
       ↓
  [يعود في المهمة التالية بنسبة 100% HP]
```

### 4.2. قواعد الضربة القاضية (Death Blow Rules)
| العامل | فرصة الضربة القاضية | ملاحظات |
|--------|--------------------|---------|
| وحدة عادية تهاجم ساقطاً | 15% | الضربة العادية |
| بطل/قائد يهاجم ساقطاً | 40% | القادة يعرفون كيف ينهون الخصوم |
| قدرة ألتميت تصيب ساقطاً | 75% | قدرات خاصة |
| بوران (خنجر + تخفي) | 100% | اغتيال صامت — إذا كان الهدف ساقطاً وليس لديه حماية |

### 4.3. عقوبات الموت
| العنصر | العقوبة |
|--------|---------|
| تقييم المهمة | -1 نجمة (خصم 10% من نقاط التقييم) |
| خبرة المهمة | لا تفقد الخبرة المتراكمة، لكن لا تكسب مكافأة "بدون خسائر" |
| المعنويات | -15 معنويات في بداية المهمة التالية للفريق بأكمله |
| خاص إذا عثمان | -20% ضرر للحلفاء في أول 60 ثانية من المهمة التالية |
| خاص إذا تورغوت | لا عقوبة إضافية (الجدار العاطفي) |
| خاص إذا بوران | -5% دقة رماية في المهمة التالية |

### 4.4. الإحياء بين المهام (Cross-Mission Recovery)
- كل الأبطال يعودون بـ 100% HP في بداية كل مهمة.
- إذا مات البطل في مهمة سابقة، يعود بشكل طبيعي — **لا موت دائم**.
- الموت لا يمحو المهارات/المعدات المكتسبة.

## 5. حدود الأبطال (Hero Limits)

| المحدد | القيمة |
|--------|--------|
| عدد الأبطال في المهمة الواحدة | حتى 3 (كل الأبطال المتاحين) |
| استدعاء البطل الميت أثناء المهمة | لا يمكن |
| تبديل البطل في منتصف المهمة | غير ممكن (اختر قبل بدء المهمة) |
| ترقية البطل خارج المهام | نعم — تبقى الخبرة والمستوى |
| مشاركة الخبرة بين الأبطال | لا — كل بطل له XP خاص به |
| الحصول على XP للبطل غير المستخدم | 50% من XP المكتسبة في المهمة |

## 6. ردود فعل الأبطال حسب الحالة (State-Based Reactions)

| الحالة | رد فعل عثمان | رد فعل تورغوت | رد فعل بوران |
|--------|------------|-------------|------------|
| **خامل (طويل — 10 ثوانٍ)** | ينظر إلى الأفق، يتأمل | يسن فأسَه، يفحص سلاحه | يجلس القرفصاء، يرمش بسرعة |
| **وصول إلى وجهة** | يمسح الأرض بقدمه، "هنا نقف." | يحط فأسَه على الأرض | يتفحص المحيط بصمت |
| **يدخل تخفي** | — | — | يخفض رأسه، يختفي في الظل |
| **يكتشف عدداً كبيراً من الأعداء** | يربت على لحيته، يحسب | يبتسم ابتسامة شرسة | "واو... حظنا سيئ اليوم." |
| **HP منخفض (<30%)** | يتنفس بصعوبة لكنه ثابت | يزأر ألماً وغضباً | يتنفس بسرعة، يتحرك بتوتر |
| **مذعور (نادر جداً)** | لا يحدث (لا يذعر أبداً) | لا يحدث تقريباً (5% فرصة تحت 10% HP) | يركض مذعوراً، يصرخ "إلى الخلف!" |
| **انتصار** | يجمع الوحدات، يبحث عن الجرحى | يرفع فأسَه إلى السماء | يعد السهام المتبقية |
