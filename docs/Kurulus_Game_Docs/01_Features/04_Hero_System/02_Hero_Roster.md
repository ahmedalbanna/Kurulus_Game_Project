## 5. مبدأ ازدواجية الأدوار (Anti-Snowflake Rule)

لا يوجد بطل يؤدي دور بطل آخر. إذا احتاج اللاعب:
- **هجوماً مركزاً** ← عثمان (صيحة الحرب يضخم ضرر الكل)
- **دبابة تمتص الضرر** ← تورغوت (جدار من حديد يمنع 40% ضرر)
- **استطلاعاً وتخريباً** ← بوران (خطف البصر يسحب الأعداء للكمين)

الجمع بين اثنين يخلق تآزراً، لكن كل بطل يبقى ضرورياً لدوره الفريد.
