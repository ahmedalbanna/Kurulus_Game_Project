# نظام المعدات — Equipment System (Detailed)

> كتالوج كامل للمعدات: العناصر، الندرة، التصنيع، المصادر، والتأثيرات.

---

## 1. أنواع المعدات (Equipment Slots)

| الفتحة | العدد الأقصى | الوظيفة | أمثلة |
|--------|------------|---------|-------|
| **السلاح** (Weapon) | 1 | يحدد ضرر البطل ونوعه | سيف، فأس، قوس، خنجر |
| **الدرع** (Armor) | 1 | يحدد دفاع البطل ومقاومته | جلد، مضاعف، صفائحي |
| **الإكسسوار 1** (Accessory) | 1 | قدرة إضافية أو إحصاءات | قلادة، خاتم، حزام |
| **الإكسسوار 2** (Accessory) | 1 | قدرة إضافية (يُفتح عند المستوى 7) | رداء، جزمة، خوذة |

## 6. نظام التصنيع (Crafting System)

### ورشة الحدادة (Blacksmith Workshop)
يُبنى في الأوبا (Opba — المعسكر الرئيسي).

**المواد الخام:**
| المادة | المصدر | ندرة |
|--------|--------|------|
| حديد (Iron) | مناجم الحديد | عادي |
| ذهب (Gold) | غنائم، تجارة | عادي |
| جلود (Leather) | صيد، غنائم | عادي |
| خشب (Wood) | قطع الأشجار | عادي |
| حرير (Silk) | تجارة، غنائم من البيزنطيين | نادر |
| جوهرة (Gem) | غنائم نادرة، كهوف | نادر |
| نادر (Relic) | مهام خاصة، حفر | ملحمي |

**مستويات ورشة الحدادة:**
| المستوى | التكلفة | الأسلحة القابلة | الدروع القابلة | الإكسسوارات القابلة |
|---------|---------|----------------|----------------|-------------------|
| 1 | 100 ذهب | جيد (ثم نادر بخبرة) | جيد | — |
| 2 | 250 ذهب + 10 حديد | نادر | نادر | جيد |
| 3 | 500 ذهب + 25 حديد + 5 ذهب خام | ملحمي | ملحمي | نادر |

**مثال وصفة تصنيع:**
```
سيف دمشقي (نادر):
  المواد: حديد ×10، ذهب ×5
  الوقت: 60 ثانية (حقيقي)
  خبرة الحداد المطلوبة: مستوى ورشة 2

فأس القبيلة (ملحمي):
  المواد: حديد ×25، ذهب ×15، جلود ×5
  الوقت: 180 ثانية
  خبرة الحداد المطلوبة: مستوى ورشة 3
```

| المهمة | المكافأة المضمونة |
|--------|------------------|
| م1: فجر السيادة | سيف محزوز (عثمان) |
| م2: تثبيت السيادة | فأس ثقيل (تورغوت) |

| م5: معركة دومانيتش | درع نوردي (تورغوت) |
| م6: الاستيلاء على يني شهير | فأس أرطغرل (أسطوري — تورغوت) |
