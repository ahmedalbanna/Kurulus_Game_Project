# شجرة مهارات فاطمة — Fatma Skill Tree

> شجرة مهارات فاطمة خاتون — 3 فروع، 12 قدرة. مقاتلة خفيفة — كمائن، استطلاع، غارات.

---

## 1. نظرة عامة (Overview)

| البعد | القيمة |
|-------|--------|
| **الاسم** | فاطمة خاتون بنت عثمان |
| **اللقب** | ابنة السيف — غارة الكايي |
| **نقاط المهارات** | +1 SP لكل مستوى (المستوى 1 → 10 = 9 SP إجمالاً) |
| **أقصى مستوى** | 10 |
