# شجرة مهارات أورخان — Orhan Skill Tree

> شجرة مهارات أورخان بك — 3 فروع، 12 قدرة. الفتح عبر نقاط المهارات (SP) المكتسبة من رفع المستوى.

---

## 1. نظرة عامة (Overview)

| البعد | القيمة |
|-------|--------|
| **الاسم** | أورخان بن عثمان غازي |
| **اللقب** | ولي العهد — قائد الفرسان |
| **نقاط المهارات** | +1 SP لكل مستوى (المستوى 1 → 12 = 11 SP إجمالاً) |
| **أقصى مستوى** | 12 |
