# نظام التآزر — Synergy System

> مكافآت تواجد أبطال متعددين في نفس المهمة — شروط الفتح والتأثيرات.

---

## 1. نظرة عامة (Overview)

عندما يكون بطلان أو أكثر في نفس المهمة، يتم تفعيل مكافآت تآزر جماعية. المكافآت تتراكم — كلما زاد عدد الأبطال، زادت الفوائد.

### القواعد الأساسية
1. **التواجد المشترك**: الأبطال يجب أن يكونوا في المهمة نفسها (ليسوا في الاحتياط).
2. **التفعيل التلقائي**: المكافآت تُفعل فور بدء المهمة.
3. **التراكم**: مكافآت متعددة تعمل معاً في وقت واحد.
4. **الحد الأقصى**: 4 أبطال = جميع المكافآت مفعلة.

## 2. مكافآت الأزواج (Pair Bonuses)

### عثمان + أورخان (الأب والابن)
| الشرط | المكافأة |
|-------|---------|
| **التفعيل الافتراضي** | +30% معنويات للجيش بأكمله |
| **إذا أورخان المستوى > 5** | +15% ضرر إضافي للفرسان |
| **إذا م47 (الوصية) أُكملت** | +50% معنويات (الإرث) |

### أورخان + علاء الدين (الأخوان — السيف والقلم)
| الشرط | المكافأة |
|-------|---------|
| **التفعيل الافتراضي** | +25% ذكاء استخباراتي (يكشف خطة العدو مسبقاً) |
| **إذا علاء الدين المستوى > 5** | +2 خيار حوار إضافي في الأحداث الدبلوماسية |
| **إذا م41 (العرسان) أُكملت بنجاح** | رابطة دائمة: +20% لجميع المكافآت |

### أورخان + فاطمة (الأخ والأخت في السلاح)
| الشرط | المكافأة |
|-------|---------|
| **التفعيل الافتراضي** | +20% سرعة هجوم لجميع الأبطال |
| **إذا فاطمة المستوى > 4** | +10% فرصة ضربة حاسمة (Critical Hit) |
| **إذا م40 (غارة فاطمة) أُكملت بنجاح** | فاطمة تكتسب +1 مستوى إضافي |

### فاطمة + علاء الدين (القوة والحكمة)
| الشرط | المكافأة |
|-------|---------|
| **التفعيل الافتراضي** | +30% فعالية القرارات الدبلوماسية |
| **إذا كانا في نفس المهمة القتالية** | فاطمة تحمي علاء الدين — -20% ضرر يتلقاه علاء الدين |

## 3. مكافآت المجموعة (Group Bonuses)

### ثلاثي الأبطال (3 Heroes)
| التشكيلة | المكافأة |
|---------|----------|
| عثمان + أورخان + علاء الدين | +20% ذهب من المهمة |
| عثمان + أورخان + فاطمة | +30% سرعة إنجاز المهمة |
| أورخان + علاء الدين + فاطمة | +25% خبرة إضافية للجميع |

### الرباعي الكامل (All 4 Heroes)
| المكافأة |
|----------|
| +40% معنويات |
| +30% ضرر |
| +30% خبرة |
| فتح قدرة خاصة: **إرث الكايي** — جميع الأبطال يهاجمون معاً مرة واحدة كل مهمة (500% ضرر إجمالي) |
