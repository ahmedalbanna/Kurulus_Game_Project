## 2. Line Types

| Type | Length | Emotion | Recording Priority |
|------|--------|---------|-------------------|
| **Story Dialogue** | 1-4 sentences | Varied | 1 (highest) |
| **Combat Bark** | 1-3 words | Aggressive/fear | 2 |
| **Selection Line** | 1-2 words | Neutral/ready | 3 |
| **Ability Line** | 1-3 words | Powerful | 2 |
| **Ambient/Chatter** | 1-5 words | Casual | 4 (lowest) |

---

## 3. Recording Technical Specs

| Specification | Requirement |
|--------------|-------------|
| File Format | WAV (uncompressed), 48 kHz, 24-bit |
| Channels | Mono |
| Room Tone | 10 seconds of silence per session |
| Naming Convention | `VO_{CHARACTER}_{MISSION}_{SCENE}_{LINE#}.wav` |
| Peak Level | -3 dB (no clipping) |
| Noise Floor | Below -60 dB |
| Distance from Mic | 6-12 inches |
| Mic Type | Large diaphragm condenser |
| Pop Filter | Required |

## 5. Voice Direction Notes

### 5.1 Dialect Notes

- **Arabic (primary)**: Modern Standard Arabic for narration, Levantine dialect for casual dialogue
- **English (fallback)**: Neutral American or British English
- **Avoid**: Overly theatrical or cartoonish delivery

### 5.2 Emotional Directions

| Emotion | Direction |
|---------|-----------|
| Determined | Strong, steady, unwavering |
| Angry | Raised volume, clipped words |
| Fearful | Tremor, higher pitch, faster |
| Sad | Slower, breathy, lower volume |
| Joyful | Brighter, faster, smiling |
| Suspicious | Lower volume, drawn-out words |
| Surprised | Sharp intake, higher pitch |
