# واجهة المستخدم وتجربة اللعب — UI/UX System Specification

> مواصفات واجهة المستخدم: تخطيط HUD، القوائم، تعيين الإدخال، واللغة البصرية.

---

## 1. نظرة عامة (Overview)

- **الغرض**: واجهة مستخدم واضحة وغامرة تنقل المعلومات الأساسية بدون إزعاج اللاعب أو تشتيت انتباهه عن المعركة.
- **تجربة اللاعب**: كل ما تحتاج لتعرفه في لمحة — مواردك، أبطالك، تهديداتك — دون الحاجة لفتح قوائم منبثقة متعددة.
- **المبادئ الأساسية**:
  1. **المعلومات الأساسية على الشاشة الرئيسية** — لا قوائم لا نهائية.
  2. **الألوان تحكي القصة** — الأزرق لحلفائك، الأحمر لأعدائك، الأخضر للصحة.
  3. **وضوح في لمحة** — كل أيقونة مفهومة ولو بدون نص.

### تفاصيل كل عنصر

#### شريط الموارد العلوي (Top Resource Bar)
| العنصر | اللون | الحجم | شرح |
|--------|-------|-------|------|
| 🪵 الخشب | بني | 40×40px | المورد الأساسي الأول |
| ⛏️ الحديد | رمادي | 40×40px | المورد الأساسي الثاني |
| 🌾 الطعام | أخضر | 40×40px | المورد الاستهلاكي |
| 💰 الذهب | أصفر | 40×40px | العملة النادرة |
| 👑 نقاط السيادة | ذهبي | 40×40px | عملة التطوير |
| ⏰ الوقت | أبيض | نص | وقت اللعبة الحالي |

**حالات خاصة**:
- إذا كان المورد أقل من 10% من السعة القصوى → يظهر باللون البرتقالي
- إذا كان المورد 0 → يظهر باللون الأحمر مع علامة تحذير
- إذا كان المورد في ازدياد → سهم أخضر صغير بجانب الرقم
- إذا كان المورد في تناقص → سهم أحمر صغير بجانب الرقم

#### شريط الأبطال السفلي (Hero Bar)
| العنصر | التفاصيل |
|--------|---------|
| **صورة البطل** | أيقونة دائرية 64×64px بخلفية حسب فصيله |
| **👤 اسم البطل** | نص صغير تحت الصورة |
| **❤️ شريط الصحة** | خط رفيع ملون تحت الصورة (أخضر ← أصفر ← أحمر) |
| **🔵 شريط الطاقة** | خط رفيع أزرق تحت الصحة |
| **أزرار القدرات (Q/W/E/R)** | أيقونات 32×32px تظهر عند تحديد البطل |
| **حالة البطل** | شارة صغيرة: 🟢 متاح، 🟠 بعيد، 🔴 ميت للمهمة |

**إذا كان البطل غير متاح** (لم يُفتح بعد):
- الصورة رمادية مع قفل
- نص: "يُفتح في المهمة [رقم]"

#### شريط الأوامر السفلي (Command Bar)
| الأمر | الاختصار | الوظيفة |
|-------|---------|---------|
| ⚔️ هجوم | A | هجوم على هدف/موقع |
| 🏃 حركة | M | حركة إلى موقع |
| ⏹ توقف | S | توقف فوري |
| 📯 تشكيلات | F | فتح قائمة التشكيلات (L/C/Q/R) |
| 🎯 هجوم أرض | G | تقدم مع هجوم تلقائي |
| 🔧 بناء | B | فتح قائمة البناء |

#### الخريطة المصغرة (Minimap)
| العنصر | التفاصيل |
|--------|---------|
| **الموقع** | الزاوية السفلية اليمنى |
| **الحجم** | دائرة قطرها 180px |
| **الأسلوب** | خريطة جلدية قديمة، زوايا محروقة |
| **الألوان** | أخضر = أرض، أزرق = ماء، رمادي = ضباب، أسود = غير مكشوف |
| **الرموز** | نقاط زرقاء = حلفاء، نقاط حمراء = أعداء (بحدود 50م من الرؤية) |
| **التفاعل** | نقر ← تنتقل الكاميرا إلى الموقع |

## 3. قائمة البناء (Build Menu)

### التصميم
```
عند الضغط على B ← تظهر شبكة المباني على شكل دائري أو شبكي:

┌────────────────────────────────────────────┐
│             قائمة البناء                    │
│                                             │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐       │
│ │ 🏕️   │ │ 🔧   │ │ 👷   │ │ 🛡️   │       │
│ │سيادة │ │حدادة│ │تدريب│ │برج   │       │
│ │  ✅  │ │  ✅  │ │  ✅  │ │  ❌  │       │
│ │ 100خشب│ │ 150خش│ │ 120خش│ │ 80خش+│      │
│ └──────┘ └──────┘ └──────┘ └──────┘       │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐       │
│ │ 🏪   │ │ ⚙️   │ │ 🏥   │ │ 🐎   │       │
│ │سوق   │ │ حصار │ │علاج  │ │اسطبل │       │
│ │  ❌  │ │  ❌  │ │  ❌  │ │  ❌  │       │
│ │ 200خش│ │ 400خش│ │ 100خش│ │ 180خش│       │
│ └──────┘ └──────┘ └──────┘ └──────┘       │
│                                             │
│ ✅ = متاح للبناء (موارد كافية + متطلبات)    │
│ ❌ = غير متاح (موارد غير كافية)                │
│ 🔒 = مقفل (لم تُفتح بعد)                    │
│                                             │
│ [X] إغلاق                                   │
└────────────────────────────────────────────┘
```

### تفاصيل كل بطاقة مبنى:
- **الأيقونة**: 64×64px تمثل المبنى بأسلوب Low-Poly
- **الاسم**: تحت الأيقونة
- **الحالة**: ✅ (متاح)، ❌ (غير كافي)، 🔒 (مقفل)
- **التكلفة**: تظهر تحت الاسم
- **الوصف المختصر**: يظهر عند التمرير — "خيمة الحدادة: تطلق الأسلحة والدروع"

## 5. الإشعارات والتنبيهات (Notifications)

### أنواع الإشعارات
| النوع | الظهور | المدة | مثال |
|-------|--------|-------|------|
| **تنبيه عسكري** | وميض أحمر على حافة الشاشة | حتى الرد | "غارة على الأوبا!" |
| **إشعار مهمة** | وسط الشاشة، يختفي بعد القراءة | 4 ثوانٍ | "هدف ثانوي مكتمل!" |
| **إشعار بناء** | فوق المبنى الجديد | 5 ثوانٍ | "اكتمل بناء خيمة الحدادة" |
| **تلميح** | زاوية يسار سفلي | 8 ثوانٍ | "جرب استخدام التشكيلات" |
| **تحذير** | وميض برتقالي | حتى الزوال | "الموارد في تناقص!" |

### نظام التنبيه الذكي:
```
إذا كان اللاعب مشغولاً بمعركة → تأجيل الإشعارات غير العاجلة (مثل اكتمال بناء)
إذا كان اللاعب في حالة هدوء → عرض الإشعارات بشكل طبيعي
إذا لم يرد اللاعب على تحذير عسكري لمدة 10 ثوانٍ → تكبير التحذير وإصدار صوت إنذار
```

## 7. اللغة البصرية (Visual Language)

### نظام الألوان الوظيفي
| اللون | الاستخدام | مثال |
|-------|----------|------|
| #2B5EA7 (أزرق كايي) | حلفاء، صديق، تفاعل إيجابي | راية الكايي، تظليل الحلفاء |
| #C62828 (أحمر عدو) | أعداء، خطر، تحذير حرج | أعداء، ناقوس خطر |
| #2E7D32 (أخضر صحة) | صحة، نجاح، مكتمل | شريط الصحة، بناء مكتمل |
| #1565C0 (أزرق طاقة) | طاقة، مانا، قدرة جاهزة | شريط الطاقة، أيقونة قدرة جاهزة |
| #F9A825 (أصفر ذهب) | موارد ثمينة، نقاط سيادة | أيقونة الذهب، نقاط سيادة |
| #EF6C00 (برتقالي تحذير) | تحذير، وشيك، متوسط | مورد منخفض، عدو قريب |
| #757575 (رمادي) | غير متاح، مقفل، معطل | مباني مقفلة، قدرات في تبريد |

### أسلوب الأيقونات
- **الأسلوب**: مرسومة باليد بأسلوب Low-Poly مطابق لنماذج اللعبة
- **الحجم**: 64×64px للأيقونات الرئيسية، 32×32px للأيقونات الثانوية
- **الاتساق**: كل عائلة أيقونات تشترك في شكل أساسي
  - المباني: مربعة بزوايا دائرية
  - الوحدات: دائرية
  - الأوامر: سداسية
  - الموارد: معينية

### نظام الخطوط
- **الخط الرئيسي (للنصوص العربية)**: خط عربي بسيط وواضح بحجم 14px للواجهة، 18px للحوارات
- **الأرقام**: أرقام واضحة sans-serif داخل الواجهة
- **عناوين**: خط أكبر بحجم 24-32px للقوائم
