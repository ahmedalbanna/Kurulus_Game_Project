# نظام التحكم — Control Scheme (Detailed)

> تفصيل كامل لنظام التحكم: اختصارات لوحة المفاتيح، أزرار الفأرة، الواجهة، والتخصيص.

---

## 1. أزرار الفأرة (Mouse Controls)

### 1.1. الفأرة — الوضع العادي
| الزر | الوظيفة |
|------|---------|
| **زر أيسر** (نقر) | تحديد وحدة/مبنى |
| **زر أيسر** (سحب) | تحديد متعدد — مربع اختيار |
| **زر أيمن** (نقر على أرض) | تحرك إلى الموقع |
| **زر أيمن** (نقر على عدو) | هجوم على الهدف |
| **زر أيمن** (نقر على مبنى صديق) | دخول المبنى (حامية) / جمع الموارد |
| **عجلة التمرير** | تكبير/تصغير الكاميرا |
| **نقر العجلة** (Middle Click) | تدوير الكاميرا (إذا كانت Isometric Perspective قابلة للدوران) |

### 1.2. الفأرة — مع المفاتيح المساعدة
| الزر + المفتاح | الوظيفة |
|---------------|---------|
| **Shift + زر أيسر** (نقر على وحدة) | إضافة وحدة للتحديد / إزالتها |
| **Shift + زر أيمن** (نقر) | إنشاء سلسلة أوامر (Queue Orders) |
| **Shift + زر أيمن** (على عدو) | إضافة عدو لقائمة الأهداف (توزيع الهجمات) |
| **Ctrl + زر أيسر** | إنشاء مجموعة تحكم (1-9) |
| **Ctrl + Shift + زر أيسر** | إضافة إلى مجموعة تحكم موجودة |
| **Alt + زر أيمن** (نقر) | حركة قسرية (تجاهل التحذيرات، امش فوق كل شيء) |
| **Alt + زر أيسر** (سحب) | تحديد وحدات من نفس النوع فقط |
| **Tab + نقر** | تدوير التشكيل نحو المؤشر |

## 2. اختصارات لوحة المفاتيح (Keyboard Shortcuts)

### 2.1. التحكم العام
| المفتاح | الوظيفة |
|---------|---------|
| **Esc** | إلغاء الأمر الحالي / فتح قائمة الإيقاف المؤقت |
| **Tab** | تبديل وضع التشكيل (يظهر تظليل التشكيل) |
| **Space** | تفعيل الكمين (عندما تكون الوحدات في وضع استعداد كمين) |
| **F1** | تحديد عثمان |
| **F2** | تحديد تورغوت |
| **F3** | تحديد بوران |
| **F4** | تحديد كل الأبطال |
| **F5-F8** | حافظة كاميرا سريعة |

### 2.2. الأوامر القتالية
| المفتاح | الوظيفة |
|---------|---------|
| **A + نقر أيسر على أرض** | هجوم أرض (Attack Move) — تقدم مع مهاجمة كل عدو في الطريق |
| **S** | توقف (Hold Position) |
| **H** | توقف مع دفاع عن الموقع |
| **P** | دورية (Patrol) — تسلك طريقاً بين نقطتين |
| **X** | تفريق (Scatter) — تنتشر الوحدات في كل الاتجاهات |
| **G** | حامية (Garrison) — دخول أقرب مبنى صديق |

### 2.3. التشكيلات
| المفتاح | التشكيل |
|---------|---------|
| **L** | خط (Line) |
| **C** | عمود (Column) |
| **R** | هلال (Crescent) |
| **Q** | مربع (Square) |
| **W** | وتد (Wedge/Military) |
| **S** | مبعثر (Scatter) |
| **A** | كمين (Ambush) — نصف دائرة جانبية |

### 2.4. التحكم في الكاميرا
| المفتاح | الوظيفة |
|---------|---------|
| **W / ↑** | تحريك الكاميرا للأمام |
| **S / ↓** | تحريك الكاميرا للخلف |
| **A / ←** | تحريك الكاميرا لليسار |
| **D / →** | تحريك الكاميرا لليمين |
| **Q** | تدوير الكاميرا لليسار (15°) |
| **E** | تدوير الكاميرا لليمين (15°) |
| **Z** | تكبير (Zoom In) |
| **X** | تصغير (Zoom Out) |
| **C** | تركيز الكاميرا على التحديد الحالي |
| **نقر مزدوج على بطاقة وحدة** | الانتقال الفوري للوحدة |

### 2.5. الاقتصاد والبناء
| المفتاح | الوظيفة |
|---------|---------|
| **B** | فتح قائمة البناء |
| **B → B** (سريع) | بناء آخر مبنى تم بناؤه |
| **V** | فتح شجرة التطوير (نقاط السيادة) |
| **T** | فتح قائمة تدريب الوحدات (الخيمة المحددة) |
| **Y** | ترقية المبنى المحدد (إذا كان ممكناً) |
| **U** | فتح قائمة القدرات الخاصة / البحث |

### 2.6. الخريطة والواجهة
| المفتاح | الوظيفة |
|---------|---------|
| **M** / **Tab** | فتح/إغلاق الخريطة المصغرة الموسعة |
| **F9** | عرض إحصائيات المهمة (الوقت، الخسائر، الغنائم) |
| **F10** | عرض قائمة الإنجازات في المهمة |
| **F11** | لقطة شاشة |
| **F12** | حفظ/تحميل سريع (إذا مسموح) |

## 3. مجموعات التحكم (Control Groups)

### 3.1. التوصيات
| المجموعة | الاقتراح الافتراضي |
|---------|-------------------|
| **1** | الأبطال (عثمان + تورغوت + بوران) |
| **2** | جيش المشاة الرئيسي |
| **3** | الرماة |
| **4** | فرسان المناورة |
| **5** | الأوبا (خيمة السيادة) |
| **6-9** | مخصصة حسب الحاجة |

### 3.2. الاستخدام المتقدم
| الميزة | الطريقة |
|--------|---------|
| إضافة إلى المجموعة | Ctrl + Shift + [رقم] |
| استدعاء المجموعة (مركز) | ضغط [رقم] مرة واحدة ← تنتقل الكاميرا إلى المجموعة |
| استدعاء المجموعة (تحديد) | ضغط [رقم] مرتين ← تحدد المجموعة |
| إضافة وحدة مؤقتة (بدون حفظ) | Shift + نقر على وحدة ← إضافة مؤقتة للتحديد الحالي |
| دمج مجموعتين | حدد الأولى ← Shift+نقر خلفي ← ادمج مع الثانية |

## 4. سلسلة الأوامر (Command Queue)

### 4.1. إنشاء سلسلة
```
1. اختر وحدة/مجموعة
2. Shift + زر أيمن على النقطة 1 (الأمر 1)
3. Shift + زر أيمن على النقطة 2 (الأمر 2)
4. Shift + زر أيمن على النقطة 3 (الأمر 3)
5. حرر Shift ← الوحدة تنفذ الأوامر بالترتيب

مثال: فارس يستكشف:
  Shift + انطلق إلى نقطة التل ← Shift + عُد إلى الأوبا ← Shift + توقف
```

### 4.2. أنواع الأوامر في السلسلة
| الأمر | يمكن وضعه في سلسلة؟ | ملاحظات |
|-------|-------------------|---------|
| تحرك | ✅ نعم | |
| هجوم | ✅ نعم | يهاجم الهدف ثم ينتقل للأمر التالي |
| هجوم أرض | ✅ نعم | |
| دورية | ✅ نعم | نقطتان تتكرران |
| توقف | ✅ نعم | نقطة نهاية السلسلة |
| بناء | ❌ لا | الأمر الوحيد الذي لا يمكن تضمينه |
| تدريب | ❌ لا | |

### 4.3. إلغاء السلسلة
- **Esc** ← يلغي الأمر الحالي فقط (تستمر السلسلة من الأمر التالي)
- **S** ← يوقف التنفيذ فوراً (تلغى السلسلة بالكامل)
- **أمر جديد (يمين)** ← يلغي السلسلة وينفذ الأمر الجديد فوراً

## 5. ردود فعل التحكم (Control Feedback)

### 5.1. مرئية (Visual)
| الموقف | المؤشر |
|--------|--------|
| أمر صالح (حركة) | مؤشر الفأرة → علم أصفر |
| أمر صالح (هجوم على عدو) | مؤشر الفأرة → سيف متقاطع |
| أمر صالح (هجوم أرض) | مؤشر الفأرة → سيف + علم |
| أمر غير صالح | مؤشر الفأرة → X أحمر |
| تحديد وحيدة | هالة زرقاء تحت الوحدة |
| تحديد متعدد | هالات زرقاء تحت جميع الوحدات المحددة |
| تلقيت أمراً | سهم اتجاهي سريع فوق الوحدة |
| سلسلة أوامر | نقاط متصلة بخطوط منقطة صفراء |

### 5.2. صوتية (Audio)
| الحدث | الصوت |
|-------|-------|
| تحديد ناجح | صوت تأكيد قصير (click) |
| أمر حركة | هتاف قصير للوحدة |
| أمر هجوم | هتاف حربي |
| أمر غير صالح | صوت خطأ (buzz) |
| اكتمال سلسلة أوامر | صوت صفير خفيف |
| بدء البناء | صوت مطرقة/نشر |

## 6. تخصيص التحكم (Control Customization)

| الميزة | مدعومة؟ | التفاصيل |
|--------|---------|---------|
| إعادة تعيين المفاتيح | ✅ نعم | كل المفاتيح قابلة للتخصيص في قائمة الإعدادات |
| ملفات التكوين | ✅ نعم | `controls.cfg` في مجلد الإعدادات |
| حساسية الفأرة | ✅ نعم | 1-10 (الافتراضي: 5) |
| سرعة الكاميرا | ✅ نعم | 1-10 (الافتراضي: 5) |
| مقلوب الكاميرا (Y) | ✅ نعم | تفعيل/تعطيل |
| وضع التمرير عند الحافة | ✅ نعم | تفعيل/تعطيل — حساسية الحافة (5-50 بكسل) |
| وحدات تحكم (Gamepad) | ❌ لا (v1) | مخطط للإصدارات المستقبلية |
