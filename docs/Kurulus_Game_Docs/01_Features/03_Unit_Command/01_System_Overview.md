# قيادة الوحدات — Unit Command System Specification

> مواصفات نظام التحكم بالوحدات: التحديد، الأوامر، التشكيلات، وسلوكيات الذكاء الاصطناعي للأوامر.

---

## 1. نظرة عامة (Overview)

- **الغرض**: توفير نظام تحكم سلس وبديهي يسمح للاعب بإدارة جيشه بكفاءة في ساحة المعركة.
- **تجربة اللاعب**: شعور بالسيطرة الكاملة — كل وحدة تستجيب بسرعة، كل أمر ينفذ بدقة.
- **المبادئ الأساسية**:
  1. استجابة فورية (أقل من 200ms بين الأمر والتنفيذ)
  2. وضوح الأوامر — الوحدة تظهر نيتها فور تلقي الأمر (هتاف، تغيير اتجاه)
  3. التحكم الجماعي متاح دائماً — يمكن تحديد 1 أو 100 وحدة بنفس السهولة

## 2. نظام التحديد (Selection System)

### أنواع التحديد
| النوع | الطريقة | الوصف |
|-------|---------|-------|
| فردي | نقر على وحدة | يحدد وحدة واحدة، يظهر شريط معلوماتها |
| متعدد (مربع) | سحب الماوس (Drag) | يحدد كل الوحدات داخل المربع المرسوم |
| متعدد (يدوي) | Shift+نقر | يضيف وحدة للتحديد الحالي أو يزيلها |
| كل الوحدات | Ctrl+A (أو زر) | يحدد كل الوحدات القابلة للتحكم على الخريطة |
| كل النوع | نقر مزدوج على وحدة | يحدد كل الوحدات من نفس النوع في الشاشة |
| كل الأبطال | زر مخصص | يحدد جميع الأبطال المتاحين |
| بطاقة مسبقة (Control Group) | 1-9 | مجموعات تحكم مسبقة التعريف |

### معلومات الوحدة المحددة
عند تحديد وحدة واحدة:
```
┌─────────────────────────────────────────┐
│ [أيقونة النوع] [اسم النوع]  [♥️ HP Bar] │
│ [شريط الطاقة]  [♠️ مستوى الخبرة]        │
│ [●] صيحة الحرب (جاهزة)                  │
│ [●] ضربة الأرض (في تبريد: 12 ث)         │
│                                         │
│ أوامر: [هجوم] [حركة] [توقف] [قدرات]    │
└─────────────────────────────────────────┘
```

عند تحديد عدة وحدات:
```
┌─────────────────────────────────────────┐
│ 15 وحدة محددة:                          │
│ [8] ألب مشاة  ♥️♥️♥️♥️♥️                  │
│ [4] رماة      ♥️♥️♥️♥️                    │
│ [2] فارس      ♥️♥️♥️                      │
│ [1] عثمان     ♥️♥️♥️♥️♥️  [قدرات ↓]       │
│                                         │
│ أوامر: [⚔️ هجوم] [🏃 حركة] [⏹ توقف]    │
│ [🎯 توجيه] [📯 تشكيلات]                  │
└─────────────────────────────────────────┘
```

## 3. أنواع الأوامر (Command Types)

### الأمر: حركة (Move)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | نقر بزر الفأرة الأيمن على أي نقطة في الخريطة |
| **سلوك الوحدة** | تسلك أقصر طريق (تجنب العوائق)، لا تهاجم الأعداء في الطريق |
| **مؤشر مرئي** | علم أصفر صغير في نقطة الوصول، خط منقط يربط الوحدة بالنقطة |
| **هتاف تأكيد** | "نعم!"، "انطلقوا!"، "إلى الأمام!" |
| **تعديلات** | Alt+نقر ← حركة قسرية (تتجاهل التحذيرات) |

### الأمر: هجوم (Attack)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | نقر بزر الفأرة الأيمن على وحدة/مبنى عدو |
| **سلوك الوحدة** | تسلك أقصر طريق، تهاجم الهدف عند الوصول |
| **سلوك الهجوم** | تتابع الهدف حتى الموت أو تغيير الأمر |
| **هتاف تأكيد** | "للموت!"، "الله أكبر!"، "هيا!" |

### الأمر: هجوم أرض (Attack Move)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | A + نقر أيسر (أو زر مخصص) على نقطة |
| **سلوك الوحدة** | تسلك الطريق، تهاجم أي عدو يصادفها في الطريق، ثم تواصل إلى النقطة |
| **الاستخدام الموصى** | التقدم في مناطق غير مكشوفة، الدخول إلى غابات مشبوهة |

### الأمر: توقف (Stop / Hold Position)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | S (أو زر مخصص) |
| **سلوك الوحدة** | تتوقف فوراً، تدافع عن موقعها (تهاجم أي عدو يقترب) |

### الأمر: حامية (Garrison)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | نقر يمين على مبنى صديق قابل للحامية |
| **سلوك الوحدة** | تدخل المبنى، ترمي من فوقه (للرماة)، تزيد دفاع المبنى |
| **خروج** | نقر على المبنى + زر الخروج، أو تدمير المبنى |

### الأمر: تفريق (Unpack / Scatter)
| التفصيل | القيمة |
|---------|-------|
| **طريقة التنفيذ** | X (أو زر مخصص) |
| **سلوك الوحدة** | تنتشر بسرعة في كل الاتجاهات (مفيد ضد الرماة أو القصف) |

## 4. التشكيلات (Formation System)

### التشكيلات المتاحة
| التشكيل | رمز الاختصار | مسار الوحدات | الاستخدام الأفضل |
|---------|-------------|-------------|-----------------|
| **خط (Line)** | L | صف واحد متساوٍ، مشاة في المقدمة، رماة في الخلف | مواجهة مباشرة منظمة |
| **عمود (Column)** | C | ضيق طويل | اختراق سريع في ممرات ضيقة |
| **هلال (Crescent)** | R | محدب مع أجنحة متقدمة | تطويق العدو |
| **مربع (Square)** | Q | مربع دفاعي، رماة في الوسط | دفاع ضد الفرسان |
| **مبعثر (Scatter)** | S | بدون ترتيب، مسافات عشوائية | تحت قصف/رماية ثقيلة |
| **مثلث (Wedge)** | W | تشكيل هجومي مثلثي | اختراق خط العدو |
| **كمين (Ambush)** | A | نصف دائرة على جانبي نقطة الالتقاء | نصب كمين في ممر |

### آلية التشكيل
```
1. اللاعب يحدد وحدات متعددة
2. يضغط زر التشكيل (L/C/R/Q/S/W/A)
3. يظهر تظليل شفاف للتشكيل على الأرض
4. اللاعب يدير التشكيل بالماوس (تغيير الاتجاه)
5. نقر أيسر ← الوحدات تتخذ مواقعها في التشكيل
6. عند الحركة، الوحدات تحافظ على التشكيل
```

### قواعد التشكيل
- **الأنواع مختلطة**: الرماة دائماً في الخلف/الوسط، المشاة في الأمام، الفرسان على الأجنحة.
- **عوائق التضاريس**: التشكيل ينكسر مؤقتاً عند المرور في ممر ضيق (يتحول إلى عمود).
- **سرعة الحركة**: التشكيل يتحرك بسرعة أبطأ وحدة فيه.
- **معنويات**: التشكيل المنظم يمنح +10 درع (معنوي)، +5% ضرر.

## 5. الأوامر التكتيكية الذكية (Smart Tactical Commands)

### أوامر سياقية تظهر عند الحاجة:
| الأمر | الشرط | التأثير |
|-------|-------|---------|
| **انسحاب (Retreat)** | وحدات محددة + اقتراب عدو | تتراجع الوحدات بسرعة إلى نقطة آمنة (خيمة السيادة أو أقرب حليف) |
| **تشكيل هجومي (Charge)** | فرسان + أمر هجوم على مشاة | الفرسان يشحنون بسرعة متزايدة، أول ضربة ×2 ضرر |
| **إطلاق دفعة (Volley)** | 4+ رماة + أمر هجوم على منطقة | يطلقون 3 دفعات متتالية على المنطقة المحددة |
| **إصلاح (Repair)** | عمال + أمر على مبنى متضرر | يصلحون المبنى (يستهلك موارد) |
| **جمع غنائم (Loot)** | وحدات + أمر على موقع معركة | تجمع الموارد المتبقية من الأعداء الموتى |

## 6. الحافظات (Control Groups)

| الميزة | التفاصيل |
|--------|---------|
| إنشاء مجموعة | حدد وحدات ← Ctrl+1..9 |
| استدعاء مجموعة | 1..9 (نقلة واحدة) |
| إضافة إلى مجموعة | Shift+1..9 |
| إعادة تعيين مجموعة | Ctrl+Shift+1..9 |
| التحديد المؤقت | 1..9 (ضغط ← تحرير ← ضغط مرة أخرى ← الكاميرا تنتقل إلى المجموعة) |

### توصيات الحافظات للمبتدئين:
```
1 → الأبطال (عثمان + تورغوت)
2 → جيش المشاة الرئيسي
3 → الرماة
4 → فرسان المناورة
5 → الأوبا (خيمة السيادة)
```

## 7. سلوك الوحدات الذكي (Smart Unit Behaviors)

### السلوك الافتراضي
| السلوك | الوصف | يمكن تغييره؟ |
|--------|-------|-------------|
| الاشتباك التلقائي | تهاجم أي عدو في مدى رؤيتها | نعم (تبديل بين هجومي/دفاعي/سلبي) |
| المطاردة | تطارد العدو الهارب حتى 30 م | نعم (تحديد مسافة المطاردة) |
| الحماية الذاتية | إذا هوجمت، ترد الهجوم | لا (دائماً نشط) |

### أنماط السلوك (Behavior Modes)
| النمط | التأثير |
|-------|---------|
| **عدواني (Aggressive)** | تهاجم أي عدو في مدى الرؤية، تطارد لمسافة أطول (50 م) |
| **دفاعي (Defensive)** | تبقى في مكانها، تهاجم فقط الأعداء الذين يقتربون كثيراً (15 م) |
| **سلبي (Passive)** | لا تهاجم أبداً تلقائياً، تنتظر أوامر اللاعب |
| **انسحاب عند الخطر (Flee at 30%)** | إذا انخفضت الصحة تحت 30%، تتراجع تلقائياً |

## 8. ردود فعل الوحدات (Unit Feedback)

### سمعية (Audio Barks)
| الأمر | الذكر | الأنثى (إن وجدت) |
|-------|-------|-----------------|
| تحدد | "أمرك!" | "أمرك!" |
| حركة | "نعم!" | "نعم!" |
| هجوم | "الله أكبر!" | "باسم القبيلة!" |
| توقف | "في مكاني!" | "وقفت!" |
| قدرة | "الآن!" | "حان الوقت!" |

### بصرية (Visual Feedback)
| الحدث | المؤشر البصري |
|-------|--------------|
| تحديد ناجح | وميض أيقونة الوحدة، هالة زرقاء تحت القدمين |
| أمر صالح | تغير مؤشر الفأرة (سيف للهجوم، قدم للحركة) |
| أمر غير صالح | مؤشر X أحمر، رسالة "لا يمكن" |
| وحدة تتلقى أمراً | وميض سهم اتجاهي فوقها |
| وحدة تموت | تلاشي بطيء مع جزيئات تراب |
