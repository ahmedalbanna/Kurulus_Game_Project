# ذكاء اصطناعي الخصوم — AI Opponents System Specification

> مواصفات الذكاء الاصطناعي للفصائل المعادية: شخصيات القتال، السلوك الاستراتيجي والتكتيكي، وتدريج الصعوبة.

---

## 1. نظرة عامة (Overview)

- **الغرض**: تقديم خصوم أذكياء ومتنوعين يجعلون كل مهمة تحدياً فريداً — البيزنطيون يتحصنون، المغول يناورون.
- **تجربة اللاعب**: الأعداء ليسوا مجرد أهداف — لهم شخصيات قتالية واضحة. تعرف أنك تواجه بيزنطياً قبل أن ترى ألوانه.
- **المبادئ الأساسية**:
  1. **العدو يعكس ثقافته**: البيزنطي نظامي متحصن، المغولي مناور سريع.
  2. **الذكاء الاصطناعي لا يغش** (باستثناء تدريج الصعوبة): يرى فقط ما تراه وحداته.
  3. **الأنماط السلوكية مفهومة**: يمكن للاعب أن "يتعلم" العدو ويخطط ضده.

## 2. شخصيات الذكاء الاصطناعي (AI Personalities)

### الشخصية 1: البيزنطي — النظامي المدرّع (The Imperial)

| البعد | القيمة |
|-------|--------|
| **الفصيل** | بيزنطة (الإمبراطورية الرومانية الشرقية) |
| **اللقب التصميمي** | "القلعة الحية" — بطيء لكن لا يمكن كسره بسهولة |
| **الشعار التكتيكي** | "التحصين أولاً، التدمير ثانياً" |

#### السمات الأساسية
| السمة | القيمة | الشرح |
|-------|-------|-------|
| **العدوانية** | 4/10 | لا يهاجم أولاً إلا في مهمات محددة (غارات) |
| **الدفاعية** | 9/10 | ممتاز — يحمي مواقعه وقلاعه |
| **المناورة** | 3/10 | بطيء في إعادة التموضع |
| **رد الفعل** | 5/10 | متوسط — يستجيب للتهديدات لكن بتأخير |
| **التعاون** | 7/10 | وحداته تبقى في تشكيلات مترابطة |
| **استخدام التضاريس** | 8/10 | يفضل الأرض المرتفعة والأسوار |
| **الصبر** | 9/10 | ينتظر — لا يندفع إلى كمائن بسهولة |

#### السلوك الدفاعي (الافتراضي)
```
1. التمركز: الوحدات الثقيلة في الأمام، الرماة خلف الأسوار
2. تشكيل: خط دفاعي مستمر، لا فجوات
3. إصلاح: إذا تضرر سور أو مبنى، يرسل عمالاً لإصلاحه فوراً
4. استدعاء: إذا تعرضت نقطة لهجوم، يستدعي دعماً من أقرب موقع
5. كمين مضاد: إذا اشتبه بكمين، يرسل كشافاً لاستكشاف الغابات أولاً
6. لا مطاردة: لا يطارد الوحدات المنسحبة لأكثر من 30 م (خوفاً من الكمائن)
```

#### السلوك الهجومي (في مهمات الغارة فقط)
```
1. تشكيل: عمود ضيق — سريع في التقدم، قوي في الاختراق
2. الهدف الأساسي: تدمير خيمة السيادة أو المخازن (الشلل الاقتصادي)
3. الحماية: يحمي آلات الحصار (إذا معه) بشكل صارم
4. التراجع: إذا خسر أكثر من 40% من قواته، يبدأ انسحاباً منظماً
5. الاستنجاد: عند الهجوم على قلعة، يرسل رسولاً لطلب التعزيزات بعد 3 دقائق
```

#### نقاط الضعف القابلة للاستغلال:
- 🟠 **الخوف من الغابات**: يتحقق من الغابات قبل الدخول — إذا رأى حركة، يدور حولها
- 🟠 **بطء إعادة التنظيم**: إذا كسر تشكيله، يستغرق 15-20 ثانية لإعادة التنظيم
- 🟠 **الاعتماد على القائد**: إذا قُتل قائد الفرقة، الذعر ينتشر (+30% فرصة ذعر لكل وحدة)

### الشخصية 2: المغولي — سهم الريح (The Nomad)

| البعد | القيمة |
|-------|--------|
| **الفصيل** | الإلخانات المغولية |
| **اللقب التصميمي** | "برق السهوب" — سريع، مميت، لا يمكن الإمساك به |
| **الشعار التكتيكي** | "اضرب، اهرب، عُد من حيث لا تتوقع" |

#### السمات الأساسية
| السمة | القيمة | الشرح |
|-------|-------|-------|
| **العدوانية** | 9/10 | يهاجم باستمرار — هجومه مستمر |
| **الدفاعية** | 3/10 | لا يبني تحصينات، معسكره مؤقت |
| **المناورة** | 10/10 | ممتاز — يعيد تموضعه بسرعة البرق |
| **رد الفعل** | 8/10 | سريع جداً في الاستجابة للتهديدات |
| **التعاون** | 6/10 | وحداته تناور بشكل فردي لكن متناسق |
| **استخدام التضاريس** | 7/10 | ماهر في المناورة حول العوائق |
| **الصبر** | 2/10 | عديم الصبر — يريد القتال فوراً |

#### السلوك الدفاعي (دفاع معسكره فقط)
```
1. دوريات: فرسان رماة يدورون حول محيط المعسكر باستمرار
2. أبراج مراقبة مؤقتة: أبراج خشبية سريعة البناء برماة
3. كمائن مضادة: يخفي فرساناً في محيط المعسكر (هل تعلمت منه؟)
4. لا تحصينات حجرية: كل شيء مؤقت وقابل للتفكيك
5. إشارات نارية: إذا تعرض للهجوم، يشعل ناراً لاستدعاء التعزيزات
```

#### السلوك الهجومي (الافتراضي — الحالة الأكثر شيوعاً)
```
1. المناورة: يدخل من اتجاه، يطلق وابلاً من السهام، يخرج من اتجاه آخر
2. التطويق: يرسل مجموعتين لتطويق العدو من الجانبين
3. إرباك: يستهدف الرماة أولاً (لتحييد التهديد البعيد)
4. تراجع وهمي: يتراجع كأنه يهرب، ثم ينعطف فجأة ويهاجم المطاردين
5. قنص القادة: إذا رأى بطلاً (عثمان، تورغوت)، يركز 3-4 فرسان رماة عليه
6. عدم الاشتباك المباشر: لا يدخل في قتال مباشر إلا إذا كان متفوقاً 3:1
```

#### نقاط الضعف القابلة للاستغلال:
- 🟠 **معنويات متقلبة**: إذا قُتل 30% منهم، يبدأ الباقون بالتردد
- 🟠 **لا دفاع**: إذا اقتحمت معسكرهم، لا يوجد تحصينات حقيقية
- 🟠 **الليل**: المغول يخافون الليل — رؤيتهم في الليل أقل من البيزنطيين (خرافة)
- 🟠 **الغابات الكثيفة**: فرسانهم عديمو الفائدة في الغابات الكثيفة

## 3. الذكاء الاستراتيجي (Strategic AI — على مستوى المهمة)

### نظام اتخاذ القرار
```
كل X ثانية (حسب الصعوبة)، الذكاء الاصطناعي يقيّم:
  1. أين قوات اللاعب؟
  2. ما حالة قواتي؟ (الصحة، التموضع، التشكيل)
  3. ما أهداف المهمة للاعب؟
  4. ما الموارد المتاحة لي؟

ثم يختار إجراءً بناءً على شخصيته:
  - البيزنطي: هل أدافع أم أهاجم أم أصلح؟
  - المغولي: هل أطوق أم أتراجع أم أغير اتجاه الهجوم؟
```

### أنماط الذكاء الاصطناعي العامة
| النمط | متى يستخدم | الوصف |
|-------|-----------|-------|
| **دفاعي (Hold)** | القوات متساوية أو اللاعب أقوى | يبقى في مكانه، يتحصن، ينتظر |
| **عدواني (Push)** | العدو متفوق أو الهدف وشيك | يتقدم، يضغط، يهاجم |
| **استدراج (Bait)** | البيزنطي (في كمين)، المغولي (طعوم) | يحاول إيقاع اللاعب في فخ |
| **تطويق (Flank)** | المغولي دائماً، البيزنطي إذا كان متفوقاً | يرسل قوات من الخلف أو الجانبين |
| **تراجع (Retreat)** | خسائر كبيرة جداً | ينسحب إلى موقع آمن (قلعة/معسكر) |
| **استنجاد (Reinforce)** | هجوم كبير على موقع مهم | يرسل رسولاً أو إشارة لاستدعاء تعزيزات |

## 4. تدريج الصعوبة (Difficulty Scaling)

### المبادئ
- **لا مضاعفات أرقام فقط**: الصعوبة الأعلى تغير السلوك، ليس فقط الأرقام.
- **مكافآت أعلى = مخاطرة أعلى**: اللاعب في الصعوبة العليا يكافأ بموارد أكثر، لكن الخطر أكبر.
- **متوازن للتجربة الأولى**: الصعوبة "العادية" مصممة للاعب العادي الذي يفهم أساسيات RTS.

### جداول الصعوبة

#### سردي (Story) — للمبتدئين أو من يريد القصة فقط
| المعلمة | القيمة |
|---------|-------|
| ضرر العدو | ×0.6 |
| صحة العدو | ×0.7 |
| وقت رد فعل العدو | أبطأ بـ 50% |
| مورد البداية الإضافي | +50% |
| فرصة ذعر العدو | +30% |
| التعزيزات | لا تأتي أبداً |
| **التقييم**: لا يُحتسب (دائماً 3 نجوم) |

#### عادي (Normal) — التجربة المقصودة
| المعلمة | القيمة |
|---------|-------|
| ضرر العدو | ×1.0 |
| صحة العدو | ×1.0 |
| وقت رد فعل العدو | عادي |
| مورد البداية الإضافي | +0% |
| فرصة ذعر العدو | عادية |
| التعزيزات | تأتي بعد 8 دقائق من بدء الهجوم |
| **التقييم**: يُحتسب كاملاً |

#### صعب (Hard) — للتحدي
| المعلمة | القيمة |
|---------|-------|
| ضرر العدو | ×1.3 |
| صحة العدو | ×1.3 |
| وقت رد فعل العدو | أسرع بـ 25% |
| مورد البداية الإضافي | -20% |
| فرصة ذعر العدو | -15% |
| التعزيزات | تأتي بعد 5 دقائق |
| **الذكاء**: يستخدم تكتيكات متقدمة (تطويق، استدراج) |

#### ملحمي (Epic) — التحدي الحقيقي
| المعلمة | القيمة |
|---------|-------|
| ضرر العدو | ×1.6 |
| صحة العدو | ×1.6 |
| وقت رد فعل العدو | أسرع بـ 40% |
| مورد البداية الإضافي | -40% |
| فرصة ذعر العدو | -30% |
| التعزيزات | تأتي بعد 3 دقائق |
| **الذكاء**: كشف الكمائن مضمون تقريباً (إلا في الليل)، يستخدم كل التكتيكات |

## 5. سيناريوهات الذكاء الاصطناعي المصممة (Scripted AI Behaviors)

### لكل مهمة، للعدو سيناريوهات محددة إضافية:

| المهمة | العدو | السلوك المبرمج |
|--------|-------|---------------|
| **م1** | بيزنطي (غارة) | هجوم مباشر على خيمة السيادة، الأولوية للحرق ثم القتل |
| **م2** | متمردون (بشر) | يدافعون عن معسكراتهم، يهاجمون إذا اقتربت. المتمردون يقاتلون حتى النهاية |
| **م3** | بيزنطي (قافلة) | القافلة تتبع المسار بدقة. الحراس يتفقدون الغابات عند الممرات الضيقة. إذا شعر بكمين، يرسل رسولاً فوراً |
| **م4** | مغولي (معسكر) | دوريات 360 درجة. إذا اكتشف التسلل، يدق ناقوس الخطر. الليل يخفض اليقظة بنسبة 40% |
| **م5** | بيزنطي (قلعة) | يدافع عن كل مرحلة بإحكام. المرحلة 1: أسوار + رماة. المرحلة 2: حامية داخلية. المرحلة 3: التكفور + حرسه |
| **م6** | تحالف (بيزنطي + مغولي) | مغولي يناور على الأجنحة، بيزنطي في الوسط. إذا انهزم أحدهما، الآخر يتراجع بتغطية |
