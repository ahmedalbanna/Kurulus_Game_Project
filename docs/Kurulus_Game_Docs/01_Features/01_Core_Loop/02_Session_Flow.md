# نمط اللعب وأنماطه — Game Modes & Session Flow

> توثيق أنماط اللعب المتاحة وتدفق الجلسة النموذجية من لحظة تشغيل اللعبة إلى الخروج.

---

## 1. أنماط اللعب (Game Modes)

### النمط الأساسي: الحملة (Campaign) — متاح من البداية
| البعد | القيمة |
|-------|--------|
| **الوصف** | طور القصة الرئيسي. 6 مهام متسلسلة عبر 3 فصول. |
| **المدة التقديرية** | 6-10 ساعات للاعب العادي |
| **الحفظ** | تلقائي بعد كل مهمة + يدوي (نقطة تفتيش أثناء المهمة) |

### النمط الإضافي: تجربة (Skirmish) — يُفتح بعد إكمال الحملة
| البعد | القيمة |
|-------|--------|
| **الوصف** | معركة سريعة عشوائية. لا قصة. اختيار الفصيل والخريطة. |
| **حالة التطوير** | خارج النطاق (توسع مستقبلي) |

### النمط الإضافي: ساندبوكس (Free Build) — يُفتح بعد إكمال الحملة
| البعد | القيمة |
|-------|--------|
| **الوصف** | أوبا خالية من الأعداء. بناء وتطوير حر. استكشاف خريطة كاملة. |
| **حالة التطوير** | خارج النطاق (توسع مستقبلي) |

## 2. تدفق الجلسة (Session Flow)

### من تشغيل اللعبة إلى أول مهمة

```
تشغيل اللعبة
    │
    ▼
┌──────────────────────┐
│ شاشة البداية         │
│ Start Screen         │
│                      │
│ • شعار اللعبة        │
│ • موسيقى افتتاحية    │
│ • زر بدء جديد        │
│ • زر تحميل           │
│ • زر إعدادات         │
└──────────┬───────────┘
           │ (بدء جديد)
           ▼
┌──────────────────────┐
│ مشهد افتتاحي         │
│ Opening Cinematic    │
│                      │
│ • السياق التاريخي    │
│ • حلم عثمان (الشجرة) │
│ • وفاة أرطغرل        │
│ • الخلاف مع دوندار   │
└──────────┬───────────┘
           │ (النهاية أو التخطي)
           ▼
┌──────────────────────┐
│ شاشة ما قبل المهمة 1 │
│ Pre-Mission Screen   │
│                      │
│ • معاينة الخريطة     │
│ • الأهداف            │
│ • نصائح              │
│ • زر البدء           │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ المهمة 1: فجر السيادة│
│ • إعداد ~2 دقيقة     │
│ • تعقيد ~4-6 دقائق   │
│ • ذروة ~3-5 دقائق    │
│ • حصاد ~2 دقيقة      │
└──────────┬───────────┘
           │
           ▼
    (تتكرر الحلقة الصغرى)
```

### تدفق جلسة نموذجية (45-60 دقيقة)

```
┌─────────────────────────────────────────────────────────┐
│  جلسة نموذجية: "لعب مهمة واحدة" (45-60 دقيقة)           │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  [5 min]  تشغيل ← شاشة بداية ← تحميل آخر حفظ            │
│                                                          │
│  [3 min]  شاشة ما قبل المهمة ← اختيار الصعوبة ← بدء     │
│                                                          │
│  [25-35 min]  المهمة نفسها (4 مراحل)                     │
│      • إعداد: 5 دقائق                                    │
│      • تعقيد: 10-12 دقيقة                                │
│      • ذروة: 8-10 دقائق                                  │
│      • حصاد: 3-5 دقائق                                   │
│                                                          │
│  [5 min]  شاشة ما بعد المهمة ← نتائج ← مكافآت            │
│                                                          │
│  [5-10 min]  شجرة التطوير ← ترقية أبطال ← قرارات         │
│                                                          │
│  [5 min]  استعراض المهمة التالية ← حفظ                    │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 3. نظام الحفظ (Save System)

### أنواع الحفظ
| النوع | الموقع | التكرار | ملاحظات |
|-------|-------|---------|---------|
| تلقائي (Auto-save) | نقطة بداية كل مهمة | عند بدء المهمة | سحوب واحد — يُعاد الكتابة |
| يدوي (Manual Save) | أثناء المهمة | متى أراد اللاعب | 10 فتحات حفظ |
| نقطة تفتيش (Checkpoint) | أثناء المهمة | في منتصف المهمة | عند إكمال مرحلة (إعداد ← تعقيد، تعقيد ← ذروة) |

### ماذا يُحفظ؟
```
حالة الحملة:
  ● آخر مهمة مكتملة
  ● الأهداف الثانوية المنجزة لكل مهمة
  ● التقييمات (عدد النجوم/النقاط)

حالة الأبطال:
  ● مستوياتهم، نقاط خبرتهم
  ● قدراتهم المفتوحة
  ● معداتهم (إن وجدت)

شجرة التطوير:
  ● التقنيات المفتوحة
  ● نقاط السيادة المتبقية

المصير السردي:
  ● القرارات الرئيسية التي اتخذها اللاعب
  ● أي شخصيات تم إنقاذها أو فقدانها
  ● مسار الحوارات المختارة (إن وجدت)

الإعدادات:
  ● الصعوبة
  ● الصوت والرسومات
  ● تخصيص الواجهة (إن وجد)
```
