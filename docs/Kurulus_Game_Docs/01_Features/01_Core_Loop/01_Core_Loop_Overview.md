# الحلقة الأساسية — Core Loop System Specification

> مواصفات الحلقة الأساسية للعبة: دورة اللعب المتكررة، تدفق الجلسة، ومراحل المهمة.

---

## 1. نظرة عامة (Overview)

- **الغرض**: تعريف الهيكل الأساسي لكيفية لعب اللاعب للعبة — دورة متكررة من التخطيط والتنفيذ والنتائج.
- **تجربة اللاعب المستهدفة**: شعور بالتقدم المستمر، قرارات ذات مغزى، وإيقاع متوازن بين البناء والتكتيك.
- **المبادئ الأساسية**:
  1. كل دورة تنتج تقدماً ملموساً
  2. البناء والقتال يكملان بعضهما — لا يمكن إهمال أحدهما
  3. الفشل ليس بداية النهاية — استرداد ممكن

## 3. تدفق المهمة (Mission Flow)

كل مهمة في اللعبة تتبع هيكلاً من 4 مراحل:

### المرحلة 1: الإعداد (Setup) — ~2 دقيقة
```
اللاعب يبدأ بـ:
  ● موارد ابتدائية (حسب المهمة)
  ● وحدات أولية
  ● أوبا في حالة معينة
  ● معلومات استخباراتية محدودة

يقوم اللاعب بـ:
  ● استكشاف المنطقة المكشوفة
  ● جمع الموارد الأولية
  ● تحديد أولويات البناء/التدريب
  ● فهم أهداف المهمة

النهاية: عندما يبني اللاعب قاعدة أولية مستقرة
```

### المرحلة 2: التعقيد (Complication) — ~4-6 دقائق
```
يحدث التالي:
  ● دخول عدو/قافلة/حدث إلى الخريطة
  ● ظهور هدف ثانوي اختياري
  ● مهاجمة العدو لموقع اللاعب أو نقطة اهتمام

يقوم اللاعب بـ:
  ● الموازنة بين الرد على التهديد والاستمرار في البناء
  ● اتخاذ قرارات تكتيكية (أين أرسل أبطالي؟)
  ● استغلال التضاريس للكمائن

النهاية: عندما يتم تحييد التهديد الأول أو الوصول إلى نقطة تحول
```

### المرحلة 3: الذروة (Climax) — ~3-5 دقائق
```
يحدث التالي:
  ● الهدف الرئيسي يصبح متاحاً/ملحاً
  ● كثافة العدو تبلغ ذروتها
  ● الموارد تصبح شحيحة (اختبار إدارة اللاعب)

يقوم اللاعب بـ:
  ● دفع كل ما لديه نحو الهدف الرئيسي
  ● استخدام القدرات الألتميت للأبطال في اللحظة الحاسمة
  ● اتخاذ القرار النهائي (التضحية/المخاطرة/الحذر)

النهاية: إما إكمال الهدف الرئيسي أو فشل المهمة
```

### المرحلة 4: الحصاد (Resolution) — ~2 دقيقة
```
● توقف إرسال الأعداء الجدد
● اللاعب يجمع ما تبقى من موارد
● مشاهد سينمائية ختامية (حسب الأداء)
● شاشة إحصائيات المهمة:
  - الوقت، الوحدات المفقودة، الوحدات المقتولة
  - الموارد المجموعة، الغنائم
  - المكافآت: نقاط الخبرة، نقاط السيادة، الفتح
  - تقييم أداء (عدد الأهداف المنجزة)

● تحديث شجرة التطوير
● إعلان المهمة التالية (معاينة)
```

## 4. شاشة ما قبل المهمة (Pre-Mission Screen)

### العناصر
| العنصر | الوظيفة |
|--------|---------|
| معاينة الخريطة | نبذة عن تضاريس المهمة، الأعداء المتوقعين، والموارد |
| الأهداف | قائمة الأهداف الرئيسية والثانوية |
| حالتك الحالية | الأبطال المتاحون، الموارد المتراكمة، الترقيات المفعّلة |
| نصائح ذكية | تلميحات استراتيجية مخصصة لهذه المهمة |
| اختيار الصعوبة | سردي / عادي / صعب / ملحمي |
| زر البدء | بدء المهمة |

### اختيار الأبطال
```
إذا كان لدى اللاعب أكثر من بطل متاح → نافذة اختيار:
  ● عثمان: متاح دائماً (إلزامي)
  ● تورغوت: متاح بعد فتحه (اختياري)
  ● بوران: متاح بعد فتحه (اختياري)
  ● حد أقصى بطلين لكل مهمة (+ عثمان = 3)
```

## 5. شاشة ما بعد المهمة (Post-Mission Screen)

### عناصر التقييم
| المعيار | التأثير |
|---------|---------|
| الأهداف الرئيسية المنجزة | مكافأة كاملة / جزئية / لا شيء |
| الأهداف الثانوية | مكافآت إضافية: موارد، نقاط سيادة، فتح عناصر حصرية |
| الوحدات المفقودة | عقوبة بسيطة على المكافآت النقدية (وليس على نقاط السيادة) |
| الوقت المستغرق | لا عقوبة زمنية مباشرة — لكن إنجاز أسرع يمنح تقييماً أعلى |
| الاكتشافات | نقاط اهتمام مكتشفة تمنح مكافآت إضافية |

### المكافآت الأساسية
| نوع المكافأة | المصدر | الاستخدام |
|-------------|--------|-----------|
| الخبرة (Experience) | كل المصادر | ترقية الأبطال |
| نقاط السيادة (SP) | الأهداف الرئيسية، الإنجازات الكبرى | شجرة التطوير |
| الموارد الفائضة | الغنائم، الكشوفات | البناء والتدريب (مرحلة ما قبل المهمة) |
| الفتح (Unlocks) | أهداف خاصة، إنجازات | مباني جديدة، وحدات، قدرات، مهام جانبية |

## 6. المهام الجانبية (Side Missions / Optional Content)

### الأنواع
| النوع | الوصف | المكافأة النموذجية |
|-------|-------|-------------------|
| إنقاذ | أنقذ شخصية محاصرة قبل فوات الأوان | فتح حليف/مورد دائم |
| تدمير | دمر موقعاً استراتيجياً للعدو | إضعاف العدو في المهمة التالية |
| جمع | اجمع كمية محددة من مورد نادر قبل مهلة | فتح ترقية خاصة |
| كشف | استكشف 3 مواقع غامضة على الخريطة | معلومات استخباراتية دائمة |
| تحالف | اثبت قوتك لقبيلة محايدة | دعم عسكري في مهمة مستقبلية |
| تحدي | أكمل هدفاً بشروط خاصة (لا خسائر، وقت محدد) | نقطة سيادة إضافية |

## 9. لحظات البطل (Hero Moments) — أحداث مصممة

في كل مهمة، هناك **لحظة بطل** مصممة مسبقاً — حدث درامي حيث يجب على اللاعب استخدام قدرة بطل في توقيت معين لتحقيق تفوق حاسم.

| المهمة | البطل | اللحظة |
|--------|-------|--------|
| م1 — فجر السيادة | عثمان | صيحة الحرب أثناء الغارة على الأوبا: يلهم الألبا للصمود |
| م2 — تثبيت السيادة | عثمان | ضربة السيادة لتحطيم باب المعقل الأخير للمتمردين |
| م3 — كمين الممر | بوران | السهم المشتعل لكشف نقطة ضعف القافلة |
| م4 — إنقاذ الأسرى | بوران | خطف البصر لكشف حراس المعسكر المغولي في الليل |
| م5 — فتح القلعة | تورغوت | زلزال التحدي لفتح البوابة الرئيسية بعد فشل آلات الحصار |
| م6 — معركة الميدان | جميع الأبطال | كل بطل يستخدم ألتميت في وقت متقارب لتوليد موجة هائلة |
