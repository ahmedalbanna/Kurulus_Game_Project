## 🎯 وظائف المباني المفتاحية

| المبنى | الوظيفة الأساسية |
|--------|-----------------|
| الحدادة | ترقية أسلحة + دروع (كل مستوى يفتح ترقية جديدة) |
| التدريب | تدريب المشاة والرماة (كل مستوى يفتح نوع وحدة جديد) |
| الإسطبل | تدريب الفرسان (كل مستوى يحسن جودة الفرسان) |
| ورشة الحصار | صناعة سلالم + منجنيق + كبش ضرب + برج حصار |
| العلاج | استشفاء الجنود الجرحى بين المعارك (م1: 5/دقيقة، م2: 10/دقيقة) |
| المسجد | +10% معنويات، +10% سرعة تدريب (م1) / +20% (م2) |
| السوق | شراء/بيع موارد بأسعار متفاوتة |
