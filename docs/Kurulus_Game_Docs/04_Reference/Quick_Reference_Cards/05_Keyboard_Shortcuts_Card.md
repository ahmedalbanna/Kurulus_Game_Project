# بطاقة اختصارات لوحة المفاتيح — Keyboard Shortcuts Reference

## 🎮 أوامر أساسية

| المفتاح | الأمر | بديل (فأرة) |
|---------|-------|------------|
| **نقر أيسر** | تحديد وحدة/مبنى | — |
| **سحب أيسر** | تحديد متعدد (مربع) | — |
| **نقر أيمن** | أمر حركة (أرض)/هجوم (عدو) | — |
| **Shift+نقر** | إضافة/إزالة من التحديد | — |
| **نقر مزدوج** | تحديد كل الوحدات من نفس النوع | — |

## ⚔️ أوامر قتالية

| المفتاح | الأمر | الوظيفة |
|---------|-------|---------|
| **A** | هجوم | نقر أيمن على هدف |
| **G** | هجوم أرض | تقدم مع هجوم تلقائي |
| **S** | توقف | توقف فوري + دفاع عن النفس |
| **X** | تفريق | انتشار سريع ضد القصف |
| **H** | حصن | دخول مبنى قريب |

## 🏗️ بناء وإدارة

| المفتاح | الأمر |
|---------|-------|
| **B** | قائمة البناء |
| **U** | ترقية مبنى محدد |
| **R** | إصلاح مبنى متضرر (عمال) |
| **Delete** | هدم مبنى (تأكيد مزدوج) |

## 📯 تشكيلات

| المفتاح | التشكيل | الأفضل لـ |
|---------|---------|----------|
| **L** | خط (Line) | مواجهة مباشرة |
| **C** | عمود (Column) | اختراق ممر ضيق |
| **Q** | مربع (Square) | دفاع ضد الفرسان |
| **R** | هلال (Crescent) | تطويق العدو |
| **S** | مبعثر (Scatter) | تحت قصف |
| **W** | مثلث (Wedge) | اختراق خط العدو |
| **A** | كمين (Ambush) | نصب كمين في ممر |

## 👑 قدرات الأبطال

| المفتاح | الوظيفة |
|---------|---------|
| **Q** | القدرة الأولى (صيحة الحرب/ضربة الأرض/سهم مشتعل) |
| **W** | القدرة الثانية (ضربة السيادة/جدار حديد/خطف البصر) |
| **R** | الألتميت (حلم الشجرة/زلزال/وابل الموت) |
| **Tab** | تحديد الأبطال فقط |
| **F1** | تحديد عثمان |
| **F2** | تحديد تورغوت |
| **F3** | تحديد بوران |

## 🎯 مجموعات التحكم

| المفتاح | الوظيفة |
|---------|---------|
| **Ctrl+1..9** | إنشاء مجموعة تحكم |
| **1..9** | استدعاء مجموعة |
| **Shift+1..9** | إضافة للمجموعة |
| **Ctrl+Shift+1..9** | إعادة تعيين مجموعة |

## 📷 كاميرا

| المفتاح/الحركة | الوظيفة |
|---------------|---------|
| **عجلة الفأرة** | تكبير/تصغير |
| **أسهم/ WASD** | تحريك الكاميرا |
| **Space** | الانتقال إلى آخر حدث |
| **Home** | العودة إلى الأوبا |

## ⚙️ عام

| المفتاح | الوظيفة |
|---------|---------|
| **P / Space** | إيقاف/استئناف |
| **Ctrl+A** | تحديد كل الوحدات |
| **Ctrl+S** | حفظ سريع |
| **F5** | تحميل سريع |
| **F10** | القائمة الرئيسية |
| **Esc** | إلغاء/رجوع |

## 🧠 توصيات الحافظات للمبتدئين
```
1 → الأبطال (عثمان + تورغوت + بوران)
2 → جيش المشاة الرئيسي
3 → الرماة
4 → فرسان المناورة
5 → الأوبا (خيمة السيادة)
``
