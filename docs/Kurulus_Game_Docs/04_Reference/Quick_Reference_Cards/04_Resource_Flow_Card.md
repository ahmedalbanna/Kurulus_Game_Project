# بطاقة سريان الموارد — Resource Flow Reference

## 📊 جدول الموارد (دخل/استهلاك)

| المورد | مصادر الدخل | معدل الإنتاج | الاستهلاكات | السعة (م1) |
|--------|------------|-------------|------------|-----------|
| 🪵 خشب | منشرة، قطع يدوي، غنائم | 15/د (يدوي)، 25/د (منشرة) | بناء، تطوير، سلالم | 500 |
| ⛏️ حديد | منجم، غنائم، تجارة | 8/د (يدوي)، 15/د (منجم) | ترقيات، أسلحة، آلات | 300 |
| 🌾 طعام | مزرعة، مرعى، صيد | 12/د (يدوي)، 20/د (مزرعة) | تدريب، صيانة جيش (2/وحدة/د) | 400 |
| 💰 ذهب | سوق، غنائم، مكافآت | متغير (التجارة) | ترقيات نادرة، مباني خاصة | 100 |
| 👑 نقاط سيادة | أهداف رئيسية (2-4)، ثانوية (1-2) | ~35-45 إجمالي في الحملة | شجرة التطوير (2-4 لكل تقنية) | — |

## 🔄 تدفق الموارد

```
منتجون ← مخازن ← مستهلكون
    │                  │
    │   ┌──────────────┤
    ▼   ▼              ▼
  منشرة   بناء
  منجم    تدريب
  مزرعة   صيانة جيش
  سوق     ترقيات
          تجارة
```

## ⚖️ معادلة التوازن الأساسية

```
دخل الموارد/د = (عمال × معدل) × (1 + ترقية%)  +  غنائم  -  صيانة
صيانة الجيش/د = (عدد الوحدات × 2)  +  (مستوى المباني × 1)
```
