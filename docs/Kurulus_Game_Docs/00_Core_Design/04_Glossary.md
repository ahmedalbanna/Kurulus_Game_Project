# قاموس المصطلحات — Glossary

> مرجع موحد للمصطلحات العربية والإنجليزية المستخدمة في جميع مستندات اللعبة.
> يجب استخدام هذه المصطلحات باستمرار لتجنب الالتباس.

---

## 🏛️ مصطلحات القبيلة والمجتمع (Tribe & Society)

| المصطلح العربي | المصطلح الإنجليزي | التعريف | ملاحظات |
|----------------|-------------------|---------|---------|
| الأوبا | Oba / Camp | معسكر القبيلة الرئيسي، مركز العمليات والتطوير | 3 مستويات ترقية بصرية |
| السيد / السيادة | Bey / Sovereignty | لقب قائد القبيلة، ومصطلح يصف الاستقلالية السياسية | نقاط السيادة = عملة التطوير |
| القبيلة | Tribe | التنظيم الاجتماعي والعسكري الأساسي | كايي هي قبيلة اللاعب |
| العشيرة | Clan / Sub-tribe | تقسيم فرعي داخل القبيلة | تستخدم في العلاقات الدبلوماسية |
| الديوان | Council / Divan | مجلس شورى القبيلة لاتخاذ القرارات الكبرى | آلية لعب استراتيجية |
| الألب (ج: الألبا) | Alp (pl: Alps) | محارب نخبة في القبيلة | الوحدة الأساسية القابلة للتدريب |
| الغازي | Ghazi | محارب مغوار يشارك في الفتوحات | لقب فخري للوحدات المتمرسة |
| التكفور | Tekfur | حاكم قلعة بيزنطي | رئيس مرحلة (Boss) في سياق المهمة |
| الشيخ | Sheikh | زعيم ديني وروحي | شخصية توجيهية غير قتالية |
| النفوذ | Influence | مقياس تأثير القبيلة على المناطق والقبائل الأخرى | |
| الولاء | Loyalty / Allegiance | مدى التزام القبائل والعشائر بسيادة اللاعب | يؤثر على القدرة على التجنيد وجمع الضرائب |

## ⚔️ مصطلحات القتال والعسكر (Combat & Military)

| المصطلح العربي | المصطلح الإنجليزي | التعريف |
|----------------|-------------------|---------|
| المشاة | Infantry | وحدات قتال راجلة، أساس الجيش |
| الفرسان | Cavalry | وحدات راكبة، أسرع وأقوى لكن أغلى |
| الرماة | Archers / Skirmishers | وحدات قتال عن بعد |
| المنجنيق | Catapult / Siege Engine | آلة حصار لتحطيم الأسوار |
| التشكيل | Formation | ترتيب تكتيكي للوحدات (خط، عمود، مربع) |
| الكمين | Ambush | هجوم مباغت من مواقع التخفي |
| الاستدراج | Luring / Decoy | تكتيك جذب العدو إلى كمين |
| المفاجأة | Surprise | حالة تصيب العدو عند التعرض لكمين (ضرر مزدوج + ذعر) |
| الذعر | Panic / Rout | حالة تصيب الوحدات عند كسر المعنويات (تهرب عشوائي) |
| المعنويات | Morale | مقياس رغبة الوحدة في القتال، تنخفض عند الخسائر وتعلو عند الانتصار |
| خط الرؤية | Line of Sight (LoS) | مدى رؤية الوحدة، يتأثر بالتضاريس والغطاء النباتي |
| ضباب الحرب | Fog of War | مناطق الخريطة غير المرئية للاعب |
| الموجة | Wave | مجموعة أعداء تظهر/تهاجم في وقت محدد |
| الحامية | Garrison | جنود متمركزون في قلعة أو موقع دفاعي |
| الإمدادات | Supplies | الموارد اللوجستية اللازمة لاستمرار الجيش في الميدان |
| التطويق | Encirclement | تكتيك حصار شامل يمنع الإمدادات والانسحاب |

## 📖 مصطلحات السرد والمحتوى (Narrative & Content)

| المصطلح العربي | المصطلح الإنجليزي | التعريف |
|----------------|-------------------|---------|
| الفصل | Chapter | قسم رئيسي من القصة (اللعبة مقسمة إلى 3 فصول) |
| المهمة | Mission / Level | وحدة لعب فردية ضمن الفصل |
| بطاقة المهمة | Mission Card | مستوصف يصف المهمة بالكامل |
| الحوار | Dialogue | نص محادثة بين الشخصيات |
| المشهد السينمائي | Cutscene | مشهد قصصي يتحكم به المحرك |
| المحفز | Trigger | حدث يطلق مشهداً أو مرحلة جديدة |
| الهدف الرئيسي | Primary Objective | شرط ضروري لإكمال المهمة |
| الهدف الثانوي | Secondary Objective | شرط اختياري لمكافآت إضافية |
| الهدف المخفي | Hidden Objective | شرط سري يكتشفه اللاعب بنفسه |
| الفوز | Victory Condition | شرط إكمال المهمة بنجاح |
| الخسارة | Failure Condition | شرط فشل المهمة |
| شجرة التطوير | Tech Tree / Progression Tree | مسارات ترقية القبيلة والتقنيات |
| القوس السردي | Narrative Arc | مسار القصة العام لفصل أو الموسم الكامل |

## 🗺️ مصطلحات الخريطة والعالم (Map & World)

| المصطلح العربي | المصطلح الإنجليزي | التعريف |
|----------------|-------------------|---------|
| الخريطة التكتيكية | Tactical Map | خريطة المهمة حيث تدور المعارك |
| الخريطة الاستراتيجية | Strategic Map | خريطة العالم بين المهام |
| المنطقة | Region | تقسيم جغرافي له موارد وتهديدات خاصة |
| الموقع الرئيسي | Key Location | نقطة اهتمام على الخريطة (قلعة، قرية، معبر) |
| نقطة الالتقاء | Chokepoint | ممر ضيق إستراتيجي للكمائن |
| الغابة الكثيفة | Dense Forest | منطقة تخفي للوحدات (للتمويه) |
| نقطة الاختناق | Bottleneck | ممر إجباري يمكن الدفاع عنه بسهولة |
| التل | Hill / High Ground | موقع مرتفع يمنح أفضلية للرماة ومدى رؤية أوسع |
| المخيم المتحرك | Mobile Camp | معسكر مغولي متنقل |
| القلعة | Castle / Fortress | حصن بيزنطي محصن |
| قرية | Village | مستوطنة صغيرة يمكن احتلالها أو حمايتها |

## 👤 مصطلحات الشخصيات (Characters)

| المصطلح العربي | المصطلح الإنجليزي | التعريف |
|----------------|-------------------|---------|
| البطل | Hero | شخصية فريدة بقدرات خاصة وقصة درامية |
| الشخصية التوجيهية | Mentor NPC | شخصية غير قتالية تقدم النصح والمهام |
| الوحدة العامة | Generic Unit | جندي عادي بدون اسم أو قصة خاصة |
| رئيس المرحلة | Boss | عدو قوي في نهاية مهمة أو فصل |
| الحليف | Ally | فصيل أو شخصية متحالفة مع اللاعب |
| العدو | Enemy | فصيل أو شخصية معادية |
| المحايد | Neutral | ليس عدواً ولا حليفاً بعد، يمكن استمالته أو محاربته |

## ⚙️ مصطلحات المعمارية التقنية (Technical Architecture)

| المصطلح العربي | المصطلح الإنجليزي | التعريف |
|----------------|-------------------|---------|
| الحلقة الأساسية | Core Loop | دورة اللعب المتكررة: تخطيط ← تنفيذ ← حصاد |
| آلة الحالة | State Machine | نموذج لإدارة حالات الكيان (سكون، حركة، قتال) |
| ناقل الأحداث | Event Bus | نظام تواصل بين الأنظمة دون اقتران مباشر |
| النظام المبني على البيانات | Data-Driven System | نظام يقرأ معلماته من جداول بيانات وليس من كود صلب |
| المكون | Component | وحدة بيانات تصف جانباً من كيان (مثل: الصحة، الموقع) |
| الكيان | Entity | أي شيء في اللعبة له وجود (وحدة، مبنى، مورد) |
| المحاكاة | Simulation | حساب منطق اللعبة بشكل دوري (تيك/Tick) |
| ميزانية الأداء | Performance Budget | الحد الأقصى للموارد الحاسوبية المسموح بها لنظام معين |
| الحتمية | Determinism | خصائص تجعل المحاكاة تنتج نفس النتيجة عند نفس المدخلات |
| الطبقة | Layer | فاصل منطقي يفصل بين أنظمة اللعبة (مثلاً: طبقة العرض وطبقة المنطق) |

| المصطلح | السبب | البديل الموصى به |
|---------|-------|------------------|
